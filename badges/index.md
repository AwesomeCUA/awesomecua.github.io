## Add a badge to your README

Replace `YOUR_RESOURCE_URL` with the link to your listed resource. The image is hosted here; no third-party image service is required.

```
[![Featured by AwesomeCUA](https://awesomecua.com/badges/featured-by-awesomecua-laurel.svg)](YOUR_RESOURCE_URL)
```

“Featured” indicates a catalog listing. Each listing shows its review state and primary evidence. The original SVG artwork is available under the [MIT license](https://github.com/reacher-z/Awesome-CUA/blob/main/LICENSE).
