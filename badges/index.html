Featured by AwesomeCUA

SVG badges for project pages, GitHub READMEs, and release notes. Link a badge to your resource’s AwesomeCUA entry so readers can inspect its sources.

Add a badge to your README

Replace YOUR_RESOURCE_URL with the link to your listed resource. The image is hosted here; no third-party image service is required.

[![Featured by AwesomeCUA](https://awesomecua.github.io/badges/featured-by-awesomecua-laurel.svg)](YOUR_RESOURCE_URL)

“Featured” indicates a catalog listing, not certification of performance, security, or reuse rights. Check the resource’s review state and primary evidence. The original SVG artwork is available under the MIT license.
