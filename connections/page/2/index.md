# Computer-use papers, code, and datasets, page 2

Find the implementations, benchmarks, and datasets connected to reviewed research papers. Every relationship below has a primary-source evidence link.

Connections describe publication documentation or introduction.

## [ColorAgent: Building A Robust, Personalized, and Interactive OS Agent](https://awesomecua.com/resources/arxiv-2510-19386/)

Presents ColorAgent, an operating system agent for long-horizon user instructions, trained with step-wise RL and self-evolving training and evaluated on AndroidWorld and AndroidLab.

- [ColorGUI-32B](https://awesomecua.com/resources/url-38672ac9af2e25fbfb58/) — Models and checkpoints · [source evidence](https://huggingface.co/api/models/MadeAgents/ColorGUI-32B)

## [VideoAgentTrek: Computer Use Pretraining from Unlabeled Videos](https://awesomecua.com/resources/arxiv-2510-19488/)

Extracts structured GUI actions from screen-recorded tutorials using inverse dynamics, then uses the inferred trajectories for computer-use training.

- [VideoAgentTrek-IDM-s1-7B](https://awesomecua.com/resources/url-280f2ab56bbc0b630d81/) — Models and checkpoints · [source evidence](https://huggingface.co/api/models/xlangai/VideoAgentTrek-IDM-s1-7B)
- [VideoAgentTrek-IDM-s2-7B](https://awesomecua.com/resources/url-2e88b52ca1717a28fd32/) — Models and checkpoints · [source evidence](https://huggingface.co/api/models/xlangai/VideoAgentTrek-IDM-s2-7B)

## [AndroidControl-Curated: Revealing the True Potential of GUI Agents through Benchmark Purification](https://awesomecua.com/resources/arxiv-2510-18488/)

AndroidControl-Curated audits ambiguities and factual errors in AndroidControl and produces a refined evaluation dataset. The paper also studies post-training a small Magma-R1 model on a curated subset to examine the effect of data quality on GUI action assessment.

- [AndroidControl-Curated](https://awesomecua.com/resources/url-dda8a0f1413a6bc7c26f/) — Benchmarks · [source evidence](https://huggingface.co/datasets/batwBMW/AndroidControl_Curated/raw/62aeecdcafa4097d340c5a4389690a5f14e938ed/README.md)

## [WebAggregator: Enhancing Compositional Reasoning Capabilities of Deep Research Agent Foundation Models](https://awesomecua.com/resources/arxiv-2510-14438/)

Introduces WebAggregator, a pipeline for synthesizing compositional questions from websites to train deep-research agents, plus the WebAggregatorQA testbed.

- [WebAggregator](https://awesomecua.com/resources/github-tencent-webaggregator/) — Frameworks · [source evidence](https://raw.githubusercontent.com/Tencent/WebAggregator/0e4f4d1583431abb838895267f925c018b0df510/readme.md)

## [ColorBench: Benchmarking Mobile Agents with Graph-Structured Framework for Complex Long-Horizon Tasks](https://awesomecua.com/resources/arxiv-2510-14621/)

ColorBench represents mobile tasks as graphs of states collected from real devices, providing a quasi-dynamic environment with multiple valid paths and error paths. It evaluates single-app and cross-app tasks using completion, subtask progress, and atomic diagnostics.

- [ColorBench](https://awesomecua.com/resources/github-madeagents-colorbench/) — Benchmarks · [source evidence](https://raw.githubusercontent.com/MadeAgents/ColorBench/HEAD/README.md)

## [LLMs as Scalable, General-Purpose Simulators For Evolving Digital Agent Training](https://awesomecua.com/resources/arxiv-2510-14969/)

## [GUIrilla: A Scalable Framework for Automated Desktop UI Exploration](https://awesomecua.com/resources/arxiv-2510-16051/)

## [\textsc{GUI-Spotlight}: Adaptive Iterative Focus Refinement for Enhanced GUI Visual Grounding](https://awesomecua.com/resources/arxiv-2510-04039/)
