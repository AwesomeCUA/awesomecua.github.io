What does a record contain?

Stable identifier, resource name, kind, platform and topic facets, concise annotation, review state, bibliographic dates and authors where available, separate code/data/weights/document licenses, source URLs, retrieval times, content fingerprints, and reviewed relationships.

Archive and scope decisions

The active catalog excludes records with completed out-of-scope decisions. The raw arXiv metadata archive preserves ingestion snapshots, including excluded candidates; it does not represent current editorial approval. The scope ledger records the rationale and evidence for each decision.

What does this download exclude?

It does not contain upstream model weights, training datasets, paper PDFs, or copied full abstracts. Follow each resource’s original source for those assets and their licensing terms.

License and attribution

Original catalog code and annotations use MIT. Third-party titles, bibliographic facts, and linked assets retain their original attribution and applicable terms; the catalog does not relicense the underlying papers, data, or weights.

Quality and reuse

Retain review status and provenance when redistributing or analyzing records. Missing data is unknown, not zero. Do not interpret metadata-only papers as editorially confirmed CUA research or combine scores across incompatible experiment protocols.

Paper citation downloads

Reviewed papers — BibTeX · Reviewed papers — CSL JSON · Citation export manifest

Metadata-only bibliography entries are available explicitly in all-record BibTeX and all-record CSL JSON. Review states and known alternate identities remain recorded. Each active resource page has a record.json file; scope-excluded pages return an explicit exclusion decision.

Publication editions and date precision

Reviewed publication editions — BibTeX · Reviewed publication editions — CSL JSON

These exports select records with source-backed publication metadata. Default arXiv citations retain their preprint facts; publication citations use the publication edition’s own authors, date, title, venue and identifiers. A year-only or month-only date is never padded with an invented day.

Publication observations — JSONL · Observation schema · Resource schema. Publisher-only observations create metadata records, while known arXiv matches enrich the existing identity. Bibliographic metadata does not itself approve relevance.

Topic subsets

Browse the topic directory or read the topic export manifest. Each topic provides complete reviewed records as JSONL and a matching paper bibliography. Topic memberships overlap, so do not add their counts together. The JSONL subsets work directly with the standard RAG and citation exporters.
