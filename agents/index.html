Use the complete catalog with your agent

Clone once, search locally, and build retrieval workflows from source-backed records. The full catalog is available without an account or API key.

AGENTS.md · 中文指南

1. Clone the data

git clone https://github.com/reacher-z/Awesome-CUA.git
cd Awesome-CUA
git rev-parse HEAD

Read data/catalog.jsonl directly, or use the commands below with Python 3.11+. Search and export use the standard library; no model service or dependency installation is needed. Keep the Git commit as your source snapshot identifier.

2. Ask a focused question

python3 scripts/catalog.py search "grounding" --kind model --status curated --json
python3 scripts/catalog.py search --kind dataset --environment android --status curated --limit 0 --json
python3 scripts/catalog.py search --kind paper --status curated --topic reinforcement-learning --limit 0 --json

Search is literal and uses AND across terms. Use aliases when a query is too narrow; --limit 0 returns all matches. Review status and platform/topic tags describe what the catalog has checked.

3. Connect a RAG pipeline

python3 scripts/export_rag.py --output dist/rag-documents.jsonl
python3 scripts/export_rag.py --include-metadata --output dist/rag-all-records.jsonl
python3 scripts/catalog.py build

Ingest the text field and retain the metadata object. Use id as the stable upsert key. Start with the reviewed export; the full export also includes bibliography entries awaiting relevance review. SQLite is generated at dist/catalog.sqlite.

FieldPurpose
id / metadata.resource_idStable resource identity
textTitle, original annotation, context, and source links
review_status / scopeFilter and explain the evidence boundary
citation_url / source_urlCatalog permalink and primary source, including the recorded arXiv version when known
evidence / last_verified_atSource receipts, fingerprints, and verification dates
licenses / relationsSeparate license scopes and reviewed resource relationships
record_sha256Detect changes to the exact source record

Ready-to-use downloads

  • Complete catalog — Every active resource and its full source record.
  • SQLite database — Resources, facets, relations, and full-text search.
  • Reviewed retrieval documents — One document per reviewed resource, including citations and provenance.
  • All retrieval documents — Includes metadata-only entries with their review state intact.
  • RAG export manifest — Counts, SHA-256 fingerprints, and the catalog snapshot fingerprint.

Keep answers traceable

Curated means AI-assisted editorial review against a primary source. Metadata verified means bibliographic identity was checked; it does not establish relevance or validate findings. Cite the primary resource and catalog permalink, retain dates and recorded versions, and preserve unknown values. Papers, code, datasets, and checkpoints can be related records rather than independent projects.

The exports contain catalog metadata and original annotations. Paper full text, model weights, and training examples remain with their publishers. Code, data, weights, and document licenses are separate.

Update and reconcile

Pull a newer Git commit or fetch a new manifest. Compare record_sha256 for changes and reconcile missing IDs against the complete catalog and scope-exclusion ledger. An absent ID may represent a reviewed scope decision; do not leave stale retrieval documents silently active. Discovery is scheduled twice a day, with actual outcomes and gaps recorded on the updates page.
