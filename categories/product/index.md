## Ace

General Agents' desktop autopilot, trained on recorded expert behavior, that predicts clicks, keystrokes and other actions from screenshots; its API client ships a macOS controller that executes them.

- Catalog URL: https://awesomecua.com/resources/url-7a35f44787f99834f13e/
- Original source: https://generalagents.com/ace
- Kind: product
- Review: curated

- Topics: automation, grounding, imitation-learning
- Evidence checked: 2026-10-19T06:24:22Z
- ID: url:7a35f44787f99834f13e

### Limitations

The Ace page describes a computer autopilot that uses the mouse and keyboard on the user's desktop, says it was trained by software specialists and domain experts on over a million tasks, and charts publisher figures for click-prediction accuracy for ace-control-medium and ace-control-small against Operator, Claude 3.7 Sonnet, UI-TARS-72B-SFT and other models, plus action latency. The About page says Ace learns from experts' screen recordings with mouse and keyboard logs, and that General Agents is developing video-language-action models. The official Python client (generalagents-python 0.1.1 at commit d36f6a8) posts a WebP screenshot, the instruction and recent actions to /v1/control/predict on api.generalagents.com; its macOS Computer class captures the screen with screencapture and performs clicks, drags, scrolls, key presses and typing through pyautogui. The client's Apache-2.0 code license does not cover the hosted models. At review time api.generalagents.com and docs.generalagents.com had DNS resolution failures; the reviewed pages leave pricing, download and sign-up paths unspecified, so current availability remains unknown.

### Limitations

Webfuse serves an existing website through a configurable proxy session and injects Extensions on the client side without changes to the site's code. Its Automation API, callable from an Extension, provides perception (DOM snapshot, Base64 screenshot of the page, accessibility tree, text selection) and actuation (click, type, scroll, select, key press, mouse move, text selection), targeting an element, CSS selector, point coordinate or Webfuse element ID across shadow DOM and iframes; the screenshot method is documented for Chromium-based browsers only. ### Limitations

Yutori was founded by Abhishek Das, Devi Parikh and Dhruv Batra and announced its seed round in March 2025. Navigator models are called through an OpenAI Chat Completions-compatible endpoint: the caller sends a screenshot and a task, the model returns actions as tool calls, and the caller executes them and sends a fresh screenshot in an agent loop. n1.5 drives browsers in a normalized 1000x1000 coordinate space with a core set of 18 coordinate-based tools or an expanded set that adds element extraction, find, set_element_value and JavaScript execution, and can return JSON matching a caller schema. n2 operates a full desktop through batched GUI actions plus bash and file tools; the SDK ships local Docker and Daytona examples, and Yutori MCP runs it on the visible macOS desktop, sending screen contents to Yutori. A Python SDK wraps the APIs, a CLI runs research, browsing and Scout tasks, and an MCP server with workflow skills exposes these tasks and computer use to coding agents. Scouts monitor the web on a schedule, and Delegate is a consumer agent meant to complete handed-off tasks independently. Yutori also publishes a computer-use leaderboards page compiling reported results for six benchmarks. The publisher describes its Online-Mind2Web figure as independently verified and its Navi-Bench v2 and Westworld figures as its own evaluations.
