Computer-use agent tools

Tools are utilities that an agent or developer calls to control, observe or inspect an interface: MCP servers, browser and device controllers, screen parsers and recorders. The catalog lists 1,162 reviewed tools, each linked to its primary evidence.

Questions

Which tools are mentioned most in the catalog?

Playwright MCP (33 records), OmniParser (23 records) and agent-browser (19 records) are mentioned in the reviewed sources of the most other catalog records.

Which platforms do these tools cover?

Of 1,162 reviewed tools, 681 are tagged web, 577 desktop, 176 cross-platform and 106 mobile; 21 have no platform recorded. An entry tagged with several platforms counts under each.

Which tools come with a research paper?

18 of 1,162 link the arXiv paper that introduces or documents them, for example OmniParser, activity-frames and DesignRepair.

Which licenses do tools declare?

The most common declared licenses are MIT (770), Apache-2.0 (137) and AGPL-3.0 (26). 194 of 1,162 have no declared license in their record.

How is this list ordered?

By the number of catalog records whose reviewed sources mention each entry, most first, then by name. The sort menu above the list switches to A–Z.
