Computer-use agents

Computer-use agents are complete systems that observe a screen or web page, plan, and act through clicks, typing, browser commands or shell tools to finish a user task. The catalog lists 479 reviewed agents, each linked to its primary evidence.

Questions

Which agents are mentioned most in the catalog?

Hermes Agent (28 records), Mobile-Agent (27 records) and OpenClaw (17 records) are mentioned in the reviewed sources of the most other catalog records.

Which platforms do these agents cover?

Of 479 reviewed agents, 247 are tagged web, 227 desktop, 95 mobile and 60 cross-platform; 3 have no platform recorded. An entry tagged with several platforms counts under each.

Which agents come with a research paper?

70 of 479 link the arXiv paper that introduces or documents them, for example Mobile-Agent, Agent S and SeeAct.

Which licenses do agents declare?

The most common declared licenses are MIT (209), Apache-2.0 (89) and AGPL-3.0 (13). 146 of 479 have no declared license in their record.

How is this list ordered?

By the number of catalog records whose reviewed sources mention each entry, most first, then by name. The sort menu above the list switches to A–Z.
