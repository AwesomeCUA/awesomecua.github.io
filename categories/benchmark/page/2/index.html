Computer-use agent benchmarks

Computer-use benchmarks are task suites and environments that score agents operating web browsers, desktop applications or mobile devices. Each pairs a fixed set of tasks with an evaluator, such as execution-based state checks, answer matching or target localization. The catalog lists 309 reviewed benchmarks, each linked to its primary evidence.
