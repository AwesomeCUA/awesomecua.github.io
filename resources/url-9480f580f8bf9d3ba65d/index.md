# Wuying Cloud Phone

Alibaba Cloud service of virtual Android phones run on ARM servers and streamed to users' devices, sold with a built-in Mobile Use Agent and an Agentic Mobile option that runs Qwen-driven agents in the phones.

## Limitations

The product page presents the cloud phone as a virtual phone with an integrated AI agent: a Mobile Use Agent built on AgentBay and Tongyi models, and an Agentic Mobile release (announced 16 April 2026) that adds Android agents to the OpenClaw ecosystem with Qwen3-VL. It supports Android 10, 12 and 14 images, an API and SDK for custom development, and instance and matrix editions sold by subscription, with pay-as-you-go billing for the instance edition only. The page also lists mobile office, gaming and marketing uses unrelated to agents.
