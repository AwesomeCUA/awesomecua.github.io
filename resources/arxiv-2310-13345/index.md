# An LLM can Fool Itself: A Prompt-Based Adversarial Attack

Status: excluded from the active CUA catalog after scope review.

Uses attack prompts that make an LLM produce adversarial examples against itself to audit robustness on GLUE-style tasks. This LLM robustness work has no agent-interaction or GUI component.
