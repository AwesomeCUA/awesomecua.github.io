# RoboBRIDGE: A Modular Framework for Bridging Policies to Robust Real-World Robotic Agents

Status: excluded from the active CUA catalog after scope review.

RoboBRIDGE orchestrates pretrained robot policies for manipulation, physical failure recovery and embodiment transfer. Its evaluations use robotics simulators and robot platforms rather than graphical software environments.
