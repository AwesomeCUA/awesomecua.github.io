# Starizon AI

Chrome side-panel agent that researches across tabs, bookmarks and a local knowledge base, and hands click-and-type tasks on signed-in sites to its Agent S6 browser agent, with replays, schedules and page monitors.

## Limitations

The terms of service name Starizon Ltd as the provider of the website, browser extension and related services. Agent S6 navigates, clicks, types and fills in forms in the browser session the user is already signed in to; it stops for confirmations, sign-ins, choices between options and pages it cannot get past, and actions that cannot be undone, such as submitting or paying, wait for the user. Chat history, the Knowledge Base and Spaces are stored in the browser profile, while prompts and task context, including page screenshots when browser actions need them, go to the chosen model service or to the user's own API key. The about page claims over 70% on Online-Mind2Web with visual understanding and DOM preprocessing; that score, reliability and pricing terms are publisher statements and were not independently tested.
