# rabbit r1

Pocket voice-and-touch AI device that serves as a physical channel into rabbit OS3, whose DLAM capability can drive applications on a computer the user connects, with permission.

## Limitations

rabbit inc. lists r1 at $199 USD with no subscription. The r1 page and user guide place computer use in OS3: OS3 works on computers where the rabbit agent is installed, through their terminal, and DLAM, which the guide calls rabbit's computer-use capability, drives an application's screen with the user's permission. The updates log dates a DLAM early-access preview for desktop control via r1 on Windows and Mac to 29 January 2026, BYOK support for DLAM with Anthropic and OpenAI keys to rabbitOS 2.3 (10 July 2026), and OS3 general availability to 22 September 2026. Earlier r1 releases shipped LAM playground, a web agent acting through a webdriver from visual and structured input (1 October 2024), and teach mode, which learned website tasks from demonstrations (21 November 2024); the current user guide describes neither.
