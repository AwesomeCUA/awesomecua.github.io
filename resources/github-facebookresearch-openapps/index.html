Evaluation protocol

Focus
UI-agent reliability under environment variation, state-based browser task evaluation
Setting
interactive
Observations
screenshots, accessibility trees, set-of-marks and coordinates (configurable)
Actions / outputs
click, type, scroll, configured BrowserGym/AgentLab actions
Evaluation
Tasks define check_if_task_is_complete(initial_state,current_state); app-specific reward logic evaluates underlying state, with custom checks for code-editor file contents. Observation/history flags are configurable. No universal single fixed task total or published-run reproduction is implied.

The environments run as browser apps; phone/tablet viewports are not native Android/iOS environments.

Scope and limitations

Public code includes app/task/configuration and agent-launching implementations. README distinguishes moving main from v1.0-paper and explicitly says even that tag is not a byte-exact snapshot of the published runs. CC-BY-NC-4.0 is the repository’s declared code license; third-party WebShop, map and icon content retain separate terms. No commercial-use permission or fixed downloadable task total is inferred.
