# ROS2SmolVLA: Enabling Small Vision-Language-Action Models for Integration into Industrial-Grade Lightweight Robots

Status: excluded from the active CUA catalog after scope review.

ROS2SmolVLA integrates a vision-language-action policy with an industrial robot and validates a physical pick-and-place task. The described interface is ROS 2 robot control, outside the software-interface agent scope.
