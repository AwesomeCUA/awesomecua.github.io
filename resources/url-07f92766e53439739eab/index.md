## Limitations

Recorded as adjacent: the publisher presents Accio Work, powered by Alibaba, as an agent team for small and medium businesses covering market research, sourcing, storefront operation and marketing, and browser control is one of its tool sets. The Agent Tools Guide lists browser operations (clicks, navigation, screenshots and scripts) in the Full capability preset used by the Coder and Shopify Dropshipper templates, marked as requiring authorization; browser operations need user approval by default. The Browser Use Guide connects agents to the user's own logged-in browser either through the Accio Browser Relay extension, loaded unpacked from the Accio Work installation into any Chromium browser, or through Direct CDP (beta) on Chrome, over a local 127.0.0.1 connection with token authentication. Other tools cover files, terminal commands, web search and fetch, image generation and analysis, scheduled tasks and multi-agent group chats. The /work landing page is a client-rendered app whose HTML changes on every request, so the receipts are the publisher's static help documents.
