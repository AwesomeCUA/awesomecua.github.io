# IterCAD: An Iterative Multimodal Agent for Visually-Grounded CAD Generation and Editing

Status: excluded from the active CUA catalog after scope review.

The abstract trains a multimodal agent that writes and edits CAD code in an executable sandbox from drawings or text. This CAD code-generation work does not involve operating graphical interfaces, web pages or devices.
