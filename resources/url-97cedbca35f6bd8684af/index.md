# Fellou

Fellou's agentic browser, which drafts a step-by-step plan for review and then browses, fills forms and runs scheduled or parallel tasks; a Computer Use mode extends it to local apps and files.

## Limitations

Publisher claims. The homepage describes Deep Action (plan, then execute multi-step web and desktop tasks across apps, with the user able to edit, approve or intervene at any step), Deep Search across sites including logged-in accounts, background tasks in a shadow workspace, scheduled tasks and an agentic memory built from browser history and notes; its FAQ says it handles logins and CAPTCHA challenges. Granting Computer Use permission lets it operate local apps and manage files. The homepage points developers to Fellou's open-source Eko 2.0 framework for building agents that run inside the browser. The download page offers Mac builds for Intel and Apple silicon; no other platform build is listed there. The pricing page lists a free plan and paid plans metered in Sparks, all with Browser Use and Computer Use.
