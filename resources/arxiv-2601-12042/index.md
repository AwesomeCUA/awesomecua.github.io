# Less Is More -- Until It Breaks: Security Pitfalls of Vision Token Compression in Large Vision-Language Models

Status: excluded from the active CUA catalog after scope review.

Shows that visual token compression makes vision-language models vulnerable and proposes a compression-aware attack. This model-robustness work does not involve agents operating graphical interfaces or web pages.
