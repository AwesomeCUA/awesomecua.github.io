# Z3D: Zero-Shot 3D Visual Grounding from Images

Status: excluded from the active CUA catalog after scope review.

Z3D localizes objects in 3D scenes from multi-view images, optionally using camera poses and depth maps. Its ScanRefer/Nr3D evaluations concern 3D scene grounding rather than GUI element grounding or software-interface control.
