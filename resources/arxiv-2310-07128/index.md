# CrashTranslator: Automatically Reproducing Mobile Application Crashes Directly from Stack Trace

Introduces CrashTranslator, which predicts GUI exploration steps from stack traces with an LLM and uses RL-guided search to reproduce crashes in Android apps.

## Limitations

The annotation and scope were reviewed against the complete retained arXiv abstract (v1). The reported evaluation uses 75 crash reports involving 58 Android apps. Experiments, reported performance and artifact availability have not been independently reproduced.
