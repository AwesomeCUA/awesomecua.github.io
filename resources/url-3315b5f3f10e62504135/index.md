# webagent.cloud

Hosted browser-agent service that carries out web tasks from natural-language prompts, billed per second of execution, with a REST API, Make, n8n and Zapier integrations and a self-hostable open-source version.

## Limitations

The homepage lists a free trial of 5 prompts and pay-as-you-go pricing from EUR 0.002 per second of execution, and claims proxy management and CAPTCHA solving. The documentation's How it works page says the platform is built on Browser-use and Steel.dev. The homepage mentions an MCP server, while the documentation's MCP integration page reads "Coming soon". The self-hostable version is the GitHub repository webagent-cloud/webagent, whose MIT license covers that repository rather than the hosted service. No task was run.
