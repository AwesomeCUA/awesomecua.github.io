Research tooling for query-inference pivot tasks that connect screenshot grounding with GUI action reasoning, including preprocessing, query refinement and mobile-agent evaluation.

## Limitations

The repository releases preprocessing/refinement/evaluation code and packaged ShareGPT-format JSON training annotations. It instructs users to obtain original UIBERT/OS-Atlas, AITZ and AndroidControl images separately and train their own model. This entry does not claim a released trained checkpoint or transfer the repository GPL-3.0 code license to third-party datasets and images.
