# RetryRoute: Retry-Aware Model Routing for Agentic Image Editing Services

Status: excluded from the active CUA catalog after scope review.

The abstract routes retries among open image-editing models using failure history, tested on editing benchmarks and a GPU serving testbed. This model-serving work involves no agent operating web pages or GUIs.
