Evaluation protocol

Focus
Android control across visual/device variation, generalization across environment snapshots
Setting
interactive
Observations
screenshot pixels, XML view hierarchy, goal instruction
Actions / outputs
normalized touch/lift coordinate pairs for tap or swipe
Evaluation
Task success is detected using Appium; positive task reward terminates the episode. Environment variants change device/locale/wallpaper/DPI/dark mode and are loaded as snapshots. The numeric action interface is (touch_y, touch_x, lift_y, lift_x); wrapper/tanh transformations must be kept with the evaluated agent.

Scale and counting units

  • 131 task-definition files — asset/tasks/**/*.textproto in retained release/ver.3 tree; not a paper test-task total (computed) source
  • 35 environment configuration rows — environments_train.csv, retained release/ver.3 snapshot (computed) source
  • 10 environment configuration rows — environments_test.csv, retained release/ver.3 snapshot (computed) source

Current source inventory differs in grain from published experiment subsets: do not multiply 131 definitions by 35/10 configuration rows or label the product as evaluated tasks. Setup requires Android API 29, Appium, external app versions and generated AVD snapshots. No apps/snapshots were downloaded or run. Code Apache-2.0 does not establish data or app rights.
