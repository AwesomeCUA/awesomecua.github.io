# CADFather: Autonomous CAD Reconstruction through Coordinated Tool Use

Status: excluded from the active CUA catalog after scope review.

Agentic system that recovers parametric CAD programs from 3D meshes by coordinating proposal tools and a VLM that inspects renders. This CAD program-synthesis work does not operate graphical interfaces, web pages or devices.
