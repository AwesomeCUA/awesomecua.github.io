## 论文与综述

- [Build or Adopt? Custom-Built vs. General-Purpose LLM Agent Harnesses for Automotive GUI Testing](https://awesomecua.com/zh/resources/arxiv-2610-33636/) — 2026-10-24
  Compares a custom harness with general-purpose LLM agent harnesses for GUI testing of Android-based vehicle interfaces and tasks in public apps.
- [WaitLens: Temporal VLM-Based Adaptive Waiting for Industrial GUI Testing Agents](https://awesomecua.com/zh/resources/arxiv-2610-32482/) — 2026-10-23
  Introduces WaitLens, a vision-language model trained on GUI loading trajectories to decide when testing agents can stop waiting for an interface to load.
- [FinCUABuild: Can Agents Build Reliable Benchmarks for Dynamic Financial Computer Use?](https://awesomecua.com/zh/resources/arxiv-2609-07603/) — 2026-09-07
  Introduces FinCUABuildBench for assessing financial computer-use task construction and FinCUABuildAgent for generating tasks, environments, and validators.
- [OmegaUse-OfficeVal: Benchmarking LLM Agents on Long-Horizon Office-Suite Tasks with Economic Grounding](https://awesomecua.com/zh/resources/arxiv-2607-27155/) — 2026-07-29
  Introduces OmegaUse-OfficeVal, a benchmark for long-horizon office-suite agent tasks with labor-time and price signals, plus rubric-based code verifiers.
- [SpreadsheetBench 2: Evaluating Agents on End-to-End Business Spreadsheet Workflows](https://awesomecua.com/zh/resources/arxiv-2606-29955/) — 2026-06-29
  Introduces SpreadsheetBench 2, a benchmark of multi-sheet business spreadsheet workflows for agents, covering generation, debugging, and visualization tasks.
- [BlueFin: Benchmarking LLM Agents on Financial Spreadsheets](https://awesomecua.com/zh/resources/arxiv-2605-30907/) — 2026-05-29
  Introduces BlueFin, a benchmark and evaluation framework for agents handling professional finance spreadsheet workbooks through synthesis, manipulation, and comprehension tasks.
- [Anchor: Preventing Artifact Drift for Reliable Agent Verification](https://awesomecua.com/zh/resources/arxiv-2605-26321/) — 2026-05-25
  Anchor builds ERP-Bench by generating procurement and manufacturing tasks with shared state verifiers for evaluating browser and computer-use agents.
- [RiskWebWorld: A Realistic Interactive Benchmark for GUI Agents in E-commerce Risk Management](https://awesomecua.com/zh/resources/arxiv-2604-13531/) — 2026-04-15
  Introduces RiskWebWorld, an interactive benchmark of e-commerce risk-management tasks for GUI agents on websites, with Gymnasium infrastructure for evaluation and agentic RL.
- [HealthAdminBench: Evaluating Computer-Use Agents on Healthcare Administration Tasks](https://awesomecua.com/zh/resources/arxiv-2604-09937/) — 2026-04-10
  Introduces HealthAdminBench with GUI environments for an electronic health record, payer portals and fax handling. Expert-defined administrative tasks are decomposed into verifiable subtasks to compare local progress with end-to-end workflow completion.
- [Terminal Agents Suffice for Enterprise Automation](https://awesomecua.com/zh/resources/arxiv-2604-00073/) — 2026-03-31
  Studies enterprise automation by terminal agents that call platform APIs, comparing their task results and cost with other agent approaches, including web agents using graphical interfaces.
- [EntWorld: A Holistic Environment and Benchmark for Verifiable Enterprise GUI Agents](https://awesomecua.com/zh/resources/arxiv-2601-17722/) — 2026-01-25
  Introduces EntWorld, an enterprise GUI benchmark built by deriving task logic from database schemas. Long workflows across enterprise domains are assessed with deterministic SQL-based state checks.
- [ProSoftArena: Benchmarking Hierarchical Capabilities of Multimodal Agents in Professional Software Environments](https://awesomecua.com/zh/resources/arxiv-2601-02399/) — 2025-12-30
  ProSoftArena evaluates 436 professional-software tasks across six disciplines and 13 applications in a Windows 11 virtual-machine environment. Its capability hierarchy, execution-based checks, and human-in-the-loop evaluation cover precise GUI operations and multi-software workflows.
- [Using GUI Agent for Electronic Design Automation](https://awesomecua.com/zh/resources/arxiv-2512-11611/) — 2025-12-12
  GUI-EDA collects more than 2,000 screenshot-answer-action pairs from engineers working across five CAD tools and five physical domains. The accompanying benchmark evaluates more than 30 GUI agents on specialized electronic-design workflows.
- [LegalWebAgent: Empowering Access to Justice via LLM-Based Web Agents](https://awesomecua.com/zh/resources/arxiv-2512-04105/) — 2025-11-28
  LegalWebAgent separates user-needs clarification, webpage browsing, and actions such as form completion or scheduling. A 15-task evaluation studies legal-service workflows relevant to Québec civil-law users, using HTML and screenshot observations.
- [UI-CUBE: Enterprise-Grade Computer Use Agent Benchmarking Beyond Task Accuracy to Operational Reliability](https://awesomecua.com/zh/resources/arxiv-2511-17131/) — 2025-11-21
  UI-CUBE evaluates 226 tasks ranging from individual controls to copy-paste and enterprise workflows. Interface variations, multiple resolutions, and application-state validation support diagnosis of operational reliability beyond task accuracy alone.
- [SCUBA: Salesforce Computer Use Benchmark](https://awesomecua.com/zh/resources/arxiv-2509-26506/) — 2025-09-30
  SCUBA evaluates enterprise UI navigation and CRM workflows with 300 task instances derived from Salesforce user interviews. Salesforce sandbox execution and milestone-based assessment support comparisons between zero-shot agents and agents given demonstrations.
- [RISK: A Framework for GUI Agents in E-commerce Risk Management](https://awesomecua.com/zh/resources/arxiv-2509-21982/) — 2025-09-26
  RISK combines browser-interaction training data, a benchmark, and reinforcement fine-tuning for e-commerce risk-management workflows. Its trajectories and rewards distinguish individual actions from multi-step stateful tasks involving deeply embedded web content.
- [InfraMind: A Novel Exploration-based GUI Agentic Framework for Mission-critical Industrial Management](https://awesomecua.com/zh/resources/arxiv-2509-13704/) — 2025-09-17
  InfraMind explores industrial management GUIs using virtual-machine snapshots and builds memory for planning and hierarchical state recognition. Its framework also studies knowledge distillation and safety checks on open-source and commercial data-center management platforms.
- [Are LLM Agents the New RPA? A Comparative Study with RPA Across Enterprise Workflows](https://awesomecua.com/zh/resources/arxiv-2509-04198/) — 2025-09-04
  Compares an agent using computer interfaces with UiPath RPA on enterprise data entry, monitoring, and document extraction, measuring speed, reliability, and development effort.
- [BIMgent: Towards Autonomous Building Modeling via Computer-use Agents](https://awesomecua.com/zh/resources/arxiv-2506-07217/) — 2025-06-08
  BIMgent plans software-specific workflows and executes GUI actions for building-information modeling. It evaluates multimodal building design and reconstruction tasks in professional authoring software.
- [Beyond Pass or Fail: Multi-Dimensional Benchmarking of Foundation Models for Goal-based Mobile UI Navigation](https://awesomecua.com/zh/resources/arxiv-2501-02863/) — 2025-01-06
  Sphinx benchmarks foundation models on goal-based mobile UI navigation, using app test cases and a toolkit that identifies different failure modes.
- [IDA: Breaking Barriers in No-code UI Automation Through Large Language Models and Human-Centric Design](https://awesomecua.com/zh/resources/arxiv-2407-15673/) — 2024-07-22
  IDA helps business users create web UI automation through guided demonstrations, a semantic programming model, and a teaching-oriented interface. A prototype user study examines automation creation with enterprise applications by users without programming backgrounds.
- [Automating the Enterprise with Foundation Models](https://awesomecua.com/zh/resources/arxiv-2405-03710/) — 2024-05-03
  ECLAIR uses multimodal foundation models to automate enterprise workflows from natural-language descriptions, with initial studies of workflow understanding and completion.
- [Robotic Process Automation and Artificial Intelligence in Industry 4.0 – A Literature review](https://awesomecua.com/zh/resources/url-b230a6700386b7e2744c/) — 2021
  A literature review examines how robotic process automation tools combine with AI for organizational workflows in Industry 4.0, including information extraction and process optimization.
- [From Robotic Process Automation to Intelligent Process Automation: Emerging Trends](https://awesomecua.com/zh/resources/arxiv-2007-13257/) — 2020-07-27
  A survey of robotic and intelligent process automation traces the use of machine learning and AI in business workflows and identifies open research challenges.
- [Robotic Process Automation: Contemporary themes and challenges](https://awesomecua.com/zh/resources/url-2574c6eeee264762a990/) — 2020-02
  A structured review of robotic process automation examines software bots that mimic user actions and identifies research themes and challenges for organizational use.
