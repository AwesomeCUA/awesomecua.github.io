## 评测基准

- [Browser AI Agent — live-web benchmark audit](https://awesomecua.com/zh/resources/github-saarthak-yadav-browser-agent-webvoyager/) — Date not recorded

## 工程与产业

- [agent-computer-use](https://awesomecua.com/zh/resources/github-kortix-ai-agent-computer-use/) — Date not recorded
  Rust CLI (agent-cu) that lets agents snapshot desktop app accessibility trees into element refs or selectors and click, type, scroll or drag through AX on macOS, UI Automation on Windows and AT-SPI2 on Linux.
- [android-uiautomator-server](https://awesomecua.com/zh/resources/github-openatx-android-uiautomator-server/) — Date not recorded
  An Android instrumentation app that runs a JSON-RPC server for UIAutomator on the device so PC-side scripts can write UI tests; its README points to a successor repository.
- [appium-adb](https://awesomecua.com/zh/resources/github-appium-appium-adb/) — Date not recorded
  An Android Debug Bridge wrapper that exposes device operations for Appium. The repository points to the appium-android monorepo for continuing development.
- [appium-ios-device](https://awesomecua.com/zh/resources/github-appium-appium-ios-device/) — Date not recorded
  A deprecated Node.js device-control library that lets Appium communicate with iOS devices and access device services and XCTest.
- [CasperJS](https://awesomecua.com/zh/resources/github-casperjs-casperjs/) — Date not recorded
  CasperJS is a browser navigation scripting and testing utility for PhantomJS and SlimerJS, with helpers for forms, links, screenshots and assertions.
- [CDP-Patches](https://awesomecua.com/zh/resources/github-kaliiiiiiiiii-vinyzu-cdp-patches/) — Date not recorded
  Python package that sends clicks, mouse moves, scrolling and typing to a headful Chrome window as OS-level input events, avoiding the input-domain leaks of CDP-dispatched events.
- [computer-use](https://awesomecua.com/zh/resources/github-leeguooooo-computer-use/) — Date not recorded
  An archived macOS broker that lets MCP clients delegate computer-use tasks to the official Codex runtime and receive the nested agent's final response.
- [Droidrun iOS Portal](https://awesomecua.com/zh/resources/github-droidrun-ios-portal/) — Date not recorded
  An archived iOS automation portal that exposes screenshots, accessibility trees, app launch, gestures, and text input through an XCTest HTTP server.
- [Index](https://awesomecua.com/zh/resources/github-lmnr-ai-index/) — Date not recorded
  Archived Laminar browser agent in Python that drives Playwright Chromium with vision-capable LLMs, returns Pydantic-structured results and offers an interactive CLI with optional Laminar tracing.
- [macOS-use](https://awesomecua.com/zh/resources/github-browser-use-macos-use/) — Date not recorded
  An archived Browser Use project that lets an LLM operate macOS apps by reading their accessibility trees and pressing, typing into and opening elements through the macOS Accessibility API.
- [MCP-B](https://awesomecua.com/zh/resources/github-miguelspizza-webmcp/) — Date not recorded
  The earlier MCP-B codebase: a Chrome extension that discovers and calls tools websites expose as MCP servers, a Cloudflare Workers backend and a native server that relays those tools to desktop MCP clients.
- [Mobile JSON Wire Protocol Specification](https://awesomecua.com/zh/resources/github-seleniumhq-mobile-spec/) — Date not recorded
  A draft WebDriver extension for automating native and hybrid mobile apps, defining sessions, capabilities, locator strategies, touch gestures, orientation, rotation, network modes and webview contexts.
- [NotebookLM Claude Code Skill](https://awesomecua.com/zh/resources/github-pleaseprompto-notebooklm-skill/) — Date not recorded
  A Claude Code skill automates browser-based questions to NotebookLM and returns answers from uploaded documents. It includes scripts for authentication and notebook management.
- [openadapt-flow](https://awesomecua.com/zh/resources/github-openadaptai-openadapt-flow/) — Date not recorded
  openadapt-flow turns recorded web or desktop tasks into reusable programs, replays them locally, and verifies saved records. Its standalone repository is archived.
- [openadapt-grounding](https://awesomecua.com/zh/resources/github-openadaptai-openadapt-grounding/) — Date not recorded
  An archived GUI element localization package that anchors targets to OCR text and stabilizes detections across frames, with optional model-based fallbacks.
- [openadapt-retrieval](https://awesomecua.com/zh/resources/github-openadaptai-openadapt-retrieval/) — Date not recorded
  Archived retrieval tool that indexes GUI demonstrations from task text and screenshots, then finds similar examples through a Python API or CLI.
- [openadapt-types](https://awesomecua.com/zh/resources/github-openadaptai-openadapt-types/) — Date not recorded
  openadapt-types supplies validated Python models and JSON schemas for computer-use screens, actions, results, and interaction trajectories.
- [Operator](https://awesomecua.com/zh/resources/url-f0584842138a52158f51/) — Date not recorded
  Historical OpenAI browser-agent research preview.
- [Project Mariner](https://awesomecua.com/zh/resources/url-12d789d450207bd6d5da/) — Date not recorded
  Discontinued Google browser-agent research prototype built with Gemini 2.0 that read screen pixels and page elements and acted in the active Chrome tab through an extension, asking before sensitive actions.
- [Puppeteer Real Browser](https://awesomecua.com/zh/resources/github-zfcsoftware-puppeteer-real-browser/) — Date not recorded
  Node.js package that launches Chrome and connects Puppeteer for browsing with fewer automation signals, with Turnstile clicking and cursor-driven clicks. Its maintainers have ended updates.
- [Selenium-Driverless](https://awesomecua.com/zh/resources/github-kaliiiiiiiiii-selenium-driverless/) — Date not recorded
  A Python browser automation library for Google Chrome that runs without chromedriver, offering element lookup, pointer clicks, multiple tabs, isolated incognito contexts and network interception.
- [Serpent.AI](https://awesomecua.com/zh/resources/github-serpentai-serpentai/) — Date not recorded
  A Python framework for building agents that interact with native video games, using plugins and support modules to turn games into research environments.
- [Sikuli legacy research implementation](https://awesomecua.com/zh/resources/github-sikuli-sikuli/) — Date not recorded
  The original Sikuli source distribution combines screenshot targets with a Jython scripting library and IDE for visual GUI automation and testing.
- [SikuliX1](https://awesomecua.com/zh/resources/github-raiman-sikulix1/) — Date not recorded
  An archived desktop automation codebase that locates on-screen elements through image recognition and controls them with simulated mouse and keyboard input.
- [Universe legacy GUI interaction client](https://awesomecua.com/zh/resources/github-openai-universe/) — Date not recorded
  An archived Gym-compatible client that exposes screen observations and keyboard/mouse actions over VNC for remote application and browser environments, including the historical World of Bits integration.
- [universe-starter-agent](https://awesomecua.com/zh/resources/github-openai-universe-starter-agent/) — Date not recorded
  A deprecated starter agent trains with A3C to play Universe games, including games operated through VNC remote desktops with delayed observations and actions.
- [WebDriverAgent](https://awesomecua.com/zh/resources/github-appium-webdriveragent/) — Date not recorded
  WebDriverAgent is an iOS WebDriver server for remote app control, including launching apps, tapping, scrolling, and checking views. Development has moved to appium-ios.
- [WebMCP](https://awesomecua.com/zh/resources/github-jasonjmcghee-webmcp/) — Date not recorded
  An early WebMCP proposal and code: a script widget on a website registers its tools, resources and prompts, which MCP clients reach through a token-secured localhost WebSocket server.
- [Workflow-Guided Exploration research code](https://awesomecua.com/zh/resources/github-stanfordnlp-wge/) — Date not recorded
  Research code that learns browser-control policies by constraining exploration with workflows induced from demonstrations, with a Selenium-based MiniWoB environment and experiment harness.
