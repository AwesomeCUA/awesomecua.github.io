# 界面设计

Reviewed topic membership; resources can appear in multiple topics.

Full source records: https://awesomecua.com/downloads/topics/ui-design/records.jsonl

## 论文与综述

- [Interface Quilt: Modifying Applications with Computer Use Agents and Generative UI](https://awesomecua.com/zh/resources/arxiv-2611-01891/) — 2026-11-01
  Introduces Interface Quilt, which uses computer-use agents and generated UI overlays to modify how existing applications look and behave without source access.
- [UI-UG 2: Advancing Mobile UI Understanding and Generation with Fine-Grained Supervision and Reinforcement Learning](https://awesomecua.com/zh/resources/arxiv-2611-00926/) — 2026-10-31
  Introduces UI-UG 2, a mobile UI model trained for component understanding, GUI grounding, and structured interface generation with render-aware RL.
- [Co-Design Bench: Multimodal Collaborative Coding Evaluation for Agentic Models](https://awesomecua.com/zh/resources/arxiv-2610-35138/) — 2026-10-26
  Introduces Co-Design Bench to evaluate coding agents that revise applications from multimodal user requests, including UI changes assessed with browser evidence.
- [InterWebCoder: Learning Interactive Webpage Generation from Executable Tests via Reinforcement Learning](https://awesomecua.com/zh/resources/arxiv-2610-28610/) — 2026-10-20
  InterWebCoder trains models to generate interactive webpage code using recorded interactions, executable tests and repair feedback, an adjacent web interface task.
- [A Decade in a Day: Synthesizing Agent-Native Interfaces from Human-Oriented Software Evolution](https://awesomecua.com/zh/resources/arxiv-2610-15765/) — 2026-10-11
  Introduces DeskIF-Bench to study how desktop application interfaces affect agents, and ANIS to synthesize interfaces from installed application capabilities.
- [WebUIProof: Benchmarking WebUI Code Generators with UI-Agent Execution Harness](https://awesomecua.com/zh/resources/arxiv-2610-02617/) — 2026-10-02
  Introduces an execution-based benchmark for generated web interfaces, with a headless-browser UI-agent harness that checks DOM interactions and functional assertions.
- [OpenVAM: Open-World Visual Attention Modeling with VLMs](https://awesomecua.com/zh/resources/arxiv-2609-31364/) — 2026-09-25
  Combines dense saliency prediction with explanations of attended elements, including webpage layouts; evaluates human-attention agreement and textual rationales on static inputs.
- [A Dual-Process Perspective on Nudge Susceptibility in LLM-Based GUI Agents](https://awesomecua.com/zh/resources/arxiv-2609-19843/) — 2026-09-17
  Studies how automatic defaults and reflective social-influence cues affect GUI-agent shopping decisions under different reasoning configurations. A randomized simulated-shopping experiment finds that reasoning changes the type of susceptibility.
- [Affora: A Design System for Agent-Friendly Interfaces](https://awesomecua.com/zh/resources/arxiv-2609-19125/) — 2026-09-16
  Presents Affora, a design system with reusable components and executable checks for interfaces used by computer-use agents, informed by studies of components and visual variation.
- [WebGrader: Training LLMs for Web Development with Self-Evolving Programmatic Grader](https://awesomecua.com/zh/resources/arxiv-2608-06474/) — 2026-08-06
  Introduces WebGrader, a programmatic grader for website generation that plans interaction flows, runs them in a live browser, and uses observed outcomes as RL rewards.
- [From Blind Edits to Verified Repair: Building Trustworthy User-Side LLM Agents for Web Accessibility](https://awesomecua.com/zh/resources/arxiv-2608-24913/) — 2026-07-26
  Builds a local browser-extension agent that generates and verifies additive CSS repairs for WCAG web accessibility violations.
- [Designing Agent-Ready Websites for AI Web Agents: A Framework for Machine Readability, Actionability, and Decision Reliability](https://awesomecua.com/zh/resources/arxiv-2607-12056/) — 2026-07-13
  Proposes an agent-ready website design framework for e-commerce browser agents and compares it with a human-oriented site on shopping tasks, outcomes, steps, and token use.
- [AOHP: An Open-Source OS-Level Agent Harness for Personalized, Efficient and Secure Interaction](https://awesomecua.com/zh/resources/arxiv-2606-23449/) — 2026-06-22
  Introduces AOHP, an Android OS-level harness that treats agents as system actors and provides adaptive interfaces, agent interfaces, and information-flow controls.
- [Reasoning for Mobile User Experience with Multimodal LLMs: Task, Benchmark, and Approach](https://awesomecua.com/zh/resources/arxiv-2606-13192/) — 2026-06-11
  Introduces UXBench for diagnosing usability issues from UI screenshots and UI-UX, a reinforcement-trained model for reasoning about those interface problems.
- [PerceptUI: LLM Agents as Human-Aligned Synthetic Users for UI/UX Evaluation](https://awesomecua.com/zh/resources/arxiv-2606-05697/) — 2026-06-04
  Introduces PerceptUI, a persona-conditioned model for predicting how particular users answer questions about interfaces, supporting synthetic UI/UX evaluation.
- [VISTA: An End-to-End Benchmark for Visual Spec-to-Web-App Coding Agents](https://awesomecua.com/zh/resources/arxiv-2605-26144/) — 2026-05-22
  VISTA evaluates coding agents that turn design handoffs into working web and Android applications. Its evaluator locates annotated interactive components and probes their behavior, keeping visual localization distinct from functional correctness.
- [Augmenting Interface Usability Heuristics for Reliable Computer-Use Agents](https://awesomecua.com/zh/resources/arxiv-2605-02729/) — 2026-05-04
  A study adapts interface usability heuristics for computer-use agents and evaluates augmented designs in UI-Verse, a suite of controlled interface environments.
- [Beyond Screenshots: Evaluating VLMs' Understanding of UI Animations](https://awesomecua.com/zh/resources/arxiv-2604-26148/) — 2026-04-28
  AniMINT evaluates how VLMs perceive, explain and interpret UI animations using densely annotated videos. The study distinguishes basic motion recognition from higher-level animation meaning and probes motion, context and perceptual cues.
- [Training Computer Use Agents to Assess the Usability of Graphical User Interfaces](https://awesomecua.com/zh/resources/arxiv-2604-26020/) — 2026-04-28
  uxCUA learns to assess interface usability by choosing interaction flows, executing them and predicting a numerical usability score. Training uses interactive UIs with usability labels and human preferences, with evaluations on synthetic and real interfaces.
- [AgentLens: Adaptive Visual Modalities for Human-Agent Interaction in Mobile GUI Agents](https://awesomecua.com/zh/resources/arxiv-2604-20279/) — 2026-04-22
  Introduces AgentLens, a mobile GUI agent that shows full, partial, or generated interface views during background task execution to support user interaction.
- [PlayCoder: Making LLM-Generated GUI Code Playable](https://awesomecua.com/zh/resources/arxiv-2604-19742/) — 2026-04-21
  PlayEval measures whether generated GUI applications remain logically playable, using PlayTester to execute task-oriented GUI playthroughs. PlayCoder closes the loop between repository-aware generation, interactive testing and targeted code repair.
- [Beyond Chat and Clicks: GUI Agents for In-Situ Assistance via Live Interface Transformation](https://awesomecua.com/zh/resources/arxiv-2604-14668/) — 2026-04-16
  DOMSteer translates help requests and live page context into reversible DOM changes such as control highlighting, contextual tooltips and layout reorganization. The work evaluates in-place GUI assistance with interface tests, use cases and a comparative user study.
- [MAESTRO: Adapting GUIs and Guiding Navigation with User Preferences in Conversational Agents with GUIs](https://awesomecua.com/zh/resources/arxiv-2604-06134/) — 2026-04-07
  Introduces MAESTRO, a conversational GUI system that remembers user preferences, adapts interface options, and guides backtracking in multistep booking decisions.
- ["What Did It Actually Do?": Understanding Risk Awareness and Traceability for Computer-Use Agents](https://awesomecua.com/zh/resources/arxiv-2603-28551/) — 2026-03-30
  Presents an interview study of computer-use agent risks and AgentTrace, a prototype interface showing agent actions, resource access, permission history, and lasting changes.
- [Vision2Web: A Hierarchical Benchmark for Visual Website Development with Agent Verification](https://awesomecua.com/zh/resources/arxiv-2603-26648/) — 2026-03-27
  Introduces Vision2Web, a benchmark for website development from images, spanning UI-to-code, multi-page frontend and full-stack tasks, with a GUI agent verifier and VLM-based judge.
- [IntentWeave: A Progressive Entry Ladder for Multi-Surface Browser Agents in Cloud Portals](https://awesomecua.com/zh/resources/arxiv-2603-22917/) — 2026-03-24
  Introduces IntentWeave, a design space and browser-extension prototype for placing web-agent assistance across browser surfaces, evaluated through a study of three entry strategies.
- [Terminal Is All You Need: Design Properties for Human-AI Agent Collaboration](https://awesomecua.com/zh/resources/arxiv-2603-10664/) — 2026-03-11
  This position paper derives interface design principles from terminal-based human-agent collaboration: representational compatibility, transparent actions and low participation barriers. It argues that graphical and other agent-facing modalities should provide these properties explicitly.
- [Avenir-UX: Automated UX Evaluation via Simulated Human Web Interaction with GUI Grounding](https://awesomecua.com/zh/resources/arxiv-2604-09581/) — 2026-02-25
  Avenir-UX combines grounded web interaction with simulated user profiles and structured usability measures to produce evaluations of website journeys. The paper describes its architecture and use of SUS, step-wise ease questions and think-aloud traces for automated UX reporting.
- [Mapping the Design Space of User Experience for Computer Use Agents](https://awesomecua.com/zh/resources/arxiv-2602-07283/) — 2026-02-07
  Develops a taxonomy of computer-use-agent interaction design through system review and practitioner interviews. A Wizard-of-Oz study then examines how users respond to normal, erroneous, and risky web-based execution, focusing on control, explanation, prompts, and mental models.
- [SimGym: Traffic-Grounded Browser Agents for Offline A/B Testing in E-Commerce](https://awesomecua.com/zh/resources/arxiv-2602-01443/) — 2026-02-01
  SimGym runs traffic-grounded synthetic buyers as browser agents to compare e-commerce storefront variants offline, using buyer profiles derived from production interactions.
- [How do Visual Attributes Influence Web Agents? A Comprehensive Evaluation of User Interface Design Factors](https://awesomecua.com/zh/resources/arxiv-2601-21961/) — 2026-01-29
  Introduces VAF, a controlled pipeline that varies webpage appearance while retaining item semantics. It measures both agent clicks and reasoning references to study which visual design factors change browsing decisions.
- [The Behavioral Fabric of LLM-Powered GUI Agents: Human Values and Interaction Outcomes](https://awesomecua.com/zh/resources/arxiv-2601-16356/) — 2026-01-22
  Introduces a controlled web-task testbed for studying how stated preferences and human values influence GUI-agent decisions. It analyzes how personas alter navigation and how prominent interface cues can override the intended preference guidance.
- [It's a TRAP! Task-Redirecting Agent Persuasion Benchmark for Web Agents](https://awesomecua.com/zh/resources/arxiv-2512-23128/) — 2025-12-29
  Introduces TRAP, which evaluates task-redirection attacks embedded in realistic web interfaces. Controlled website clones and a modular injection framework support comparisons of persuasion techniques and contextual changes across agents.
- [DECEPTICON: How Dark Patterns Manipulate Web Agents](https://awesomecua.com/zh/resources/arxiv-2512-22894/) — 2025-12-28
  DECEPTICON is an environment of 700 web navigation tasks that isolates dark patterns to measure how deceptive interface designs steer agent actions.
- [FronTalk: Benchmarking Front-End Development as Conversational Code Generation with Multi-Modal Feedback](https://awesomecua.com/zh/resources/arxiv-2601-04203/) — 2025-12-05
  FronTalk benchmarks multi-turn front-end code generation from text and visual feedback; a web agent explores generated sites for evaluation and in AceCoder.
- [Computer-Use Agents as Judges for Generative User Interface](https://awesomecua.com/zh/resources/arxiv-2511-15567/) — 2025-11-19
  AUI-Gym evaluates generated websites by having computer-use agents attempt tasks whose executability is checked programmatically. A feedback dashboard condenses navigation histories into visual summaries that a coding agent can use to revise an interface.
- [WebVIA: A Web-based Vision-Language Agentic Framework for Interactive and Verifiable UI-to-Code Generation](https://awesomecua.com/zh/resources/arxiv-2511-06251/) — 2025-11-09
  WebVIA combines a web UI exploration agent, interactive UI-to-Code generation, and validation of generated code's interactivity.
- [Investigating the Impact of Dark Patterns on LLM-Based Web Agents](https://awesomecua.com/zh/resources/arxiv-2510-18113/) — 2025-10-20
  Presents LiteAgent for recording web-agent interactions and TrickyArena for enabling or disabling dark patterns in controlled websites. Experiments compare how individual patterns, combined patterns and visual or HTML changes affect agent decisions.
- [SusBench: An Online Benchmark for Evaluating Dark Pattern Susceptibility of Computer-Use Agents](https://awesomecua.com/zh/resources/arxiv-2510-11035/) — 2025-10-13
  Introduces SusBench, an online benchmark that inserts dark-pattern designs into consumer websites for agent evaluation. A human study checks the realism of the interventions, and agent trials compare susceptibility across pattern types.
- [Understanding User Experiences of Computer Use Agents: Design Space and Opportunities for Building Agent UX Prototypes](https://awesomecua.com/zh/resources/arxiv-2510-04452/) — 2025-10-06
  Maps design considerations for computer-use agent experiences and introduces AgentUXlab, a browser-based probe for prototyping and evaluating agent UX on a website.
- [WebGen-Agent: Enhancing Interactive Website Generation with Multi-Level Feedback and Step-Level Reinforcement Learning](https://awesomecua.com/zh/resources/arxiv-2509-22644/) — 2025-09-26
  Introduces WebGen-Agent for website code generation, using screenshot critiques and GUI-agent tests to refine code and provide step-level training rewards.
- [A Multimodal GUI Architecture for Interfacing with LLM-Based Conversational Assistants](https://awesomecua.com/zh/resources/arxiv-2510-06223/) — 2025-08-31
  Presents an MCP architecture that exposes an application's GUI navigation graph and view-specific tools to speech-enabled LLM assistants for voice interaction.
- [WebMMU: A Benchmark for Multimodal Multilingual Website Understanding and Code Generation](https://awesomecua.com/zh/resources/arxiv-2508-16763/) — 2025-08-22
  Introduces WebMMU, a multilingual benchmark for website visual question answering, element grounding, code editing, and mockup-to-code generation.
- [Machine-Readable Ads: Accessibility and Trust Patterns for AI Web Agents interacting with Online Advertisements](https://awesomecua.com/zh/resources/arxiv-2507-12844/) — 2025-07-17
  Compares DOM-based and pixel-based web agents on a cloned news site containing advertisements, consent dialogs and paywalls. The study examines how interface presentation affects ad interaction and consequential subscription choices.
- [Build the web for agents, not agents for the web](https://awesomecua.com/zh/resources/arxiv-2506-10953/) — 2025-06-12
  Proposes Agentic Web Interface (AWI), a website interface intended for agent navigation, and sets out six design principles for web-agent use.
- [Automated Testing of the GUI of a Real-Life Engineering Software using Large Language Models](https://awesomecua.com/zh/resources/arxiv-2505-17839/) — 2025-05-23
  GERALLT uses LLMs to explore the GUI of engineering software and produce a list of confusing or inconsistent interface areas for developers to inspect.
- [Leveraging Vision-Language Models for Visual Grounding and Analysis of Automotive UI](https://awesomecua.com/zh/resources/arxiv-2505-05895/) — 2025-05-09
  Introduces AutomotiveUI-Bench-4K and a fine-tuned vision-language model for locating elements and evaluating automotive infotainment interfaces.
- [Do MLLMs Capture How Interfaces Guide User Behavior? A Benchmark for Multimodal UI/UX Design Understanding](https://awesomecua.com/zh/resources/arxiv-2505-05026/) — 2025-05-08
  Introduces WiserUI-Bench, pairing real UI variants from industry A/B tests with observed behavioral winners and expert explanations. It evaluates models’ ability to predict the more effective interface and explain its effect on user behavior.
- [WebGen-Bench: Evaluating LLMs on Generating Interactive and Functional Websites from Scratch](https://awesomecua.com/zh/resources/arxiv-2505-03733/) — 2025-05-06
  Introduces WebGen-Bench for evaluating agents that generate multi-file websites, using a web-navigation agent to check whether the resulting pages pass interaction tests.
- [AgentA/B: Automated and Scalable Web A/BTesting with Interactive LLM Agents](https://awesomecua.com/zh/resources/arxiv-2504-09723/) — 2025-04-13
  Introduces AgentA/B, which uses persona-based LLM agents to navigate real webpages and perform shopping interactions for simulated web A/B tests.
- [UXAgent: An LLM Agent-Based Usability Testing Framework for Web Design](https://awesomecua.com/zh/resources/arxiv-2502-12561/) — 2025-02-18
  Introduces UXAgent, which uses simulated users and a browser connector to test website usability and present their actions, responses, and recordings to UX researchers.
- [Inferring Alt-text For UI Icons With Large Language Models During App Development](https://awesomecua.com/zh/resources/arxiv-2409-18060/) — 2024-09-26
  Introduces IconDesc, which generates mobile icon alt-text from partial UI context such as element identifiers, bounds, nearby text and hierarchy. Model evaluation and a user study examine the resulting accessibility descriptions.
- [UIClip: A Data-driven Model for Assessing User Interface Design](https://awesomecua.com/zh/resources/arxiv-2404-12500/) — 2024-04-18
  UIClip assesses UI design quality and visual relevance from screenshots and descriptions, using crawled, augmented and human-rated interfaces for training.
- [Unveiling the Tricks: Automated Detection of Dark Patterns in Mobile Applications](https://awesomecua.com/zh/resources/arxiv-2308-05898/) — 2023-08-11
  Introduces UIGuard, a system that examines mobile UI visuals and text to detect dark patterns, together with a labeled dataset of benign and malicious interfaces.
- [Task Automation Intelligent Agents: A Review](https://awesomecua.com/zh/resources/url-eb791c465f47690ade31/) — 2023-05-29
  A literature review examines mobile phone task automation agents, including programming by demonstration and usability heuristics for recurring user tasks.
- [Rico: A Mobile App Dataset for Building Data-Driven Design Applications](https://awesomecua.com/zh/resources/url-b560b5d6abaab98483f6/) — 2017-10-20
  Introduces Rico, collecting Android interface designs and interaction traces through crowdsourced use followed by automated exploration. The paper demonstrates UI-layout retrieval using learned representations and describes visual, textual, structural, and interaction data.

## 评测基准

- [Agent-friendly UI](https://awesomecua.com/zh/resources/github-showlab-aui/) — Date not recorded
  An evaluation and revision pipeline tests generated websites with computer-use agents, checks task completion against rules, and summarizes navigation failures.
- [AgentReady](https://awesomecua.com/zh/resources/github-williehems-agentready/) — Date not recorded
  Cloud-browser evaluation harness that tests whether an autonomous AI agent can complete a website's primary conversion action.
- [Co-Design Bench](https://awesomecua.com/zh/resources/github-wiselnn570-co-design-bench/) — Date not recorded
  Co-Design Bench evaluates application revisions made by coding agents from multimodal requests, checking requirements against source code and browser evidence.
- [Co-Design Bench](https://awesomecua.com/zh/resources/url-7cfe1cd1a61d7ebfd083/) — Date not recorded
  Co-Design Bench evaluates application revisions from multimodal requests using 96 editing tasks with annotated screenshots and 521 criteria checked against source and browser evidence.
- [FronTalk](https://awesomecua.com/zh/resources/github-shirley-wu-frontalk/) — Date not recorded
  FronTalk benchmarks multi-turn website coding from text and visual instructions. It supplies dialogue tasks and test cases, with a web agent used to evaluate generated sites.
- [HumanQA](https://awesomecua.com/zh/resources/github-hotragn-humanqa/) — Date not recorded
  Evidence-first product quality and UX evaluation harness for testing web applications with browser agents.
- [Open User](https://awesomecua.com/zh/resources/github-tiacoo-open-user/) — Date not recorded
  Black-box UX audit harness that dispatches AI browser personas to test web products and record friction points.
- [Persona UX Test](https://awesomecua.com/zh/resources/github-ericwong5021-persona-ux-test/) — Date not recorded
  Blind-tests web and desktop user interfaces using isolated AI personas that interact strictly through rendered screens.
- [REFRACT-PPTX](https://awesomecua.com/zh/resources/github-haikong-lu1206-refract-pptx/) — Date not recorded
  Agent-guided generation and multi-dimensional visual evaluation benchmark for editable PowerPoint presentation decks.
- [UserZero](https://awesomecua.com/zh/resources/github-aafre-userzero/) — Date not recorded
  Synthetic first-user evaluation harness that verifies web applications by attempting onboarding and core flows with AI browser agents.
- [WebGen-Bench](https://awesomecua.com/zh/resources/github-mnluzimu-webgen-bench/) — Date not recorded
  WebGen-Bench evaluates generated websites with automated tests, including a UI agent that carries out interactions and checks outcomes. The repository supplies evaluation code and data.
- [WebsiteBench](https://awesomecua.com/zh/resources/github-tiger-ai-lab-websitebench/) — Date not recorded
  Website reconstruction benchmark: agents explore a production-level site through a browser, rebuild a full-stack version, and are scored by hidden functional and visual test cases across 70 tasks.
- [WebUIProof](https://awesomecua.com/zh/resources/github-yunyuntsai-webuiproof-benchmark/) — Date not recorded
  A benchmark of 149 web UI generation tasks with structured test cases and a vision-language agent that tests generated interfaces in a browser.

## 数据集

- [luzimu/WebGen-Bench](https://awesomecua.com/zh/resources/url-405959de004b6e32c911/) — Date not recorded
  A dataset of website-generation instructions and UI test cases for evaluating interactive sites, with separate training and test splits.
- [luzimu/WebGen-Bench_train_data](https://awesomecua.com/zh/resources/url-c47b5927fc41eb9a24d4/) — Date not recorded
  WebGen-Instruct is a training dataset of 6,667 website generation instructions, including 600 trajectories and fields describing expected UI tasks.
- [Rico Dataset](https://awesomecua.com/zh/resources/url-0c845d69c9498dd4e20c/) — Date not recorded
  Rico Dataset is a collection of mobile app interaction and design data presented through Interaction Mining, with 70k screens and 10k user flows across 5k apps.
- [RICO-Screen2Words](https://awesomecua.com/zh/resources/url-cf7c132c9a988d3a6ec4/) — Date not recorded
  RICO-Screen2Words pairs Android app screenshots with human screen summaries, app metadata and view hierarchies for mobile interface understanding.
- [UEyes](https://awesomecua.com/zh/resources/github-yuejiang-nj-ueyes-chi2023/) — Date not recorded
  UEyes is an eye-tracking dataset of 62 participants viewing 1,980 UI screenshots across webpages, desktop interfaces, mobile apps, and posters.
- [UICrit](https://awesomecua.com/zh/resources/github-google-research-datasets-uicrit/) — Date not recorded
  Mobile-interface critiques and quality ratings with region coordinates and RICO screen references, including a larger three-annotator release than the original paper dataset.

  GLM-4.6V-Flash is a vision-language checkpoint that accepts screenshots in tool calls and can reconstruct and edit web interfaces from UI images.
- [GLM-4.6V-FP8](https://awesomecua.com/zh/resources/url-2a99aab63fc1fe65610d/) — Date not recorded
  An FP8 multimodal model checkpoint supports tool calls using screenshots as inputs and generates or edits frontend code from images of interfaces.
- [UI2Code_N](https://awesomecua.com/zh/resources/url-b04608609a8c392d110b/) — Date not recorded
  A visual language model that turns UI screenshots into code and supports iterative interface editing and polishing. Its card includes a screenshot-to-HTML inference example.

  The 7B Step-GRPO checkpoint of WebGen-Agent, which writes website code from instructions; training used screenshot scores and GUI-agent test scores as step-level rewards.
- [WebGenAgent-LM-8B-SFT](https://awesomecua.com/zh/resources/url-b3dd615ebfe977392f90/) — Date not recorded
  The 8B supervised fine-tuned checkpoint of WebGen-Agent, which writes website code from instructions and refines it with screenshot critiques and GUI-agent functional tests.
- [WebGenAgent-LM-8B-Step-GRPO](https://awesomecua.com/zh/resources/url-7ebba507c0df876c6113/) — Date not recorded
  The 8B Step-GRPO checkpoint of WebGen-Agent, which writes website code from instructions; training used screenshot scores and GUI-agent test scores as step-level rewards.
- [WebVIA-Agent](https://awesomecua.com/zh/resources/url-62724cba1b5814215cf7/) — Date not recorded
  GLM-4.1V-9B-based web exploration agent from WebVIA that reads a page screenshot and DOM tree and picks click, type or select actions to reach each interactive UI state for UI-to-code work.
