## 在 README 中添加徽章

把 `YOUR_RESOURCE_URL` 替换为你的资源条目链接。图片由本站托管。

```
[![Featured by AwesomeCUA](https://awesomecua.com/badges/featured-by-awesomecua-laurel.svg)](YOUR_RESOURCE_URL)
```

“精选”表示该资源已收录在目录中。每个条目都会显示审阅状态与一手证据。原创 SVG 图稿采用 [MIT 许可证](https://github.com/reacher-z/Awesome-CUA/blob/main/LICENSE)。
