# DragOn: A Benchmark and Dataset for Drag-Based GUI Interactions

DragOn 提供拖拽定位训练数据及留出的基准，涵盖文本高亮、单元格选择、元素缩放和滑块移动，并评估现有视觉语言模型及在拖拽任务上微调的模型。
