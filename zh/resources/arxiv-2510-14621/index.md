# ColorBench: Benchmarking Mobile Agents with Graph-Structured Framework for Complex Long-Horizon Tasks

ColorBench 用从真实设备采集的状态图表示移动端任务，提供包含多条有效路径和错误路径的准动态环境。它以完成情况、子任务进度和原子级诊断评估单应用及跨应用任务。
