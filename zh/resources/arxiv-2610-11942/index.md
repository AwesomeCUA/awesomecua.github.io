# Right Screen, Wrong Transition: World Models as Verifiers for GUI Agents

提出 LGWM，一种无解码器的 GUI 世界模型，根据动作预测下一屏幕表征，并与观察到的状态比较以验证状态转移。其成对诊断区分通往同一凭据页面的正常转移与被劫持的转移。
