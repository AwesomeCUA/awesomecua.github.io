# ComponentBench: Diagnosing Component-Level Failures in Computer-Use Agents

ComponentBench 利用已核验的任务和匹配的人类参考轨迹，评估与标准网页 UI 组件的短程交互；其诊断流程比较观察和动作的表示方式，并分析结构性难度、失败模式与交互效率。
