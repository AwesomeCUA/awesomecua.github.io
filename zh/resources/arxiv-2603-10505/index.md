# Safe and Scalable Web Agent Learning via Recreated Websites

VeriEnv 将网站重建为可执行的训练环境，并通过 Python SDK 暴露内部状态，用于生成任务和确定性地检查奖励。实验考察 Web 智能体在新建及扩展的网站环境中的学习情况。
