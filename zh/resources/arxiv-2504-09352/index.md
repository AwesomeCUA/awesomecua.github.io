# Explorer: Robust Collection of Interactable GUI Elements

Explorer 从运行中的目标应用收集可交互 GUI 元素，并记录用户会话，用于训练应用专用模型。它将重复出现的界面状态关联成导航图，支持路径规划和语音指令交互。
