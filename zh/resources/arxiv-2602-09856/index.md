# Code2World: A GUI World Model via Renderable Code Generation

Code2World 通过生成可渲染代码预测未来 GUI 画面，并使用 AndroidCode 轨迹进行监督学习和渲染感知强化学习；论文评估视觉预测，以及利用所学世界模型完成 AndroidWorld 导航的效果。
