# Learning from Failure: Inference-Time Self-Improvement for Computer-Use Agents

该方法利用失败的计算机使用轨迹诊断失败模式，并在推理时生成智能体代码补丁，辅以少量人工核验。OSWorld 研究评估了这一由失败驱动、无需额外模型训练的改进循环。
