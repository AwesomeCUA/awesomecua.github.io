# Agent Data Injection Attacks are Realistic Threats to AI Agents

研究考察智能体数据注入：不可信内容冒充可信元数据或工具上下文数据。除单独的编程智能体攻击外，研究还报告了 Web 智能体中的任意点击漏洞，指出指令注入之外的信任边界失效问题。
