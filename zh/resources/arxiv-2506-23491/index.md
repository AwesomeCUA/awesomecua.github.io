# ZonUI-3B: A Lightweight Vision-Language Model for Cross-Resolution GUI Grounding

ZonUI-3B 使用精选的 24,000 个移动端、桌面端和网页截图样例训练 GUI 定位；先进行跨平台学习，再针对高分辨率图像训练，并对数据多样性和冗余样例进行消融分析。
