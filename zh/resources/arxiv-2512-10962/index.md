# WebSTAR: Scalable Data Synthesis for Computer Use Agents with Step-Level Filtering

论文提出一条训练流程，从含噪的计算机操作智能体运行轨迹中筛选单个步骤，并为其补充推理信息。WebSTAR 和 WebSCORE 支持 GUI 策略监督训练及蒸馏出的过程奖励模型 StepRM。
