# Benchmarking Living-Screen-Native GUI Agents on Short-Video Platforms

LivingScreen 在基于浏览器的短视频环境中评估智能体，观看内容会消耗时间并影响后续操作。其任务集同时衡量准确率和信息效率，以诊断智能体在持续变化的屏幕上观察过多或不足的问题。
