# Enhancing Visual Grounding for GUI Agents via Self-Evolutionary Reinforcement Learning

提出结合精选种子示例、随位置连续变化的策略反馈及注意力图引导的迭代改进的 GUI 定位训练方法，并在包括 ScreenSpot-Pro 在内的 3 个定位基准上评估这一强化学习流程。
