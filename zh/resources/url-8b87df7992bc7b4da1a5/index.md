# Trace2Ground: Scenario, Disambiguation, and Relation Traces for Web GUI Grounding

Trace2Ground 从 HTML/DOM 元素和模拟交互轨迹构建网页 GUI 定位数据集，评估场景描述、重名标签和关系描述指令。
