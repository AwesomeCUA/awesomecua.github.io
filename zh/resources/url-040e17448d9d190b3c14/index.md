## 范围记录

Omnify Labs of San Francisco builds dassi. The documentation says the agent identifies elements by role, text and position, can run JavaScript in the page, uses screenshots to verify its work and to handle coordinate-based interfaces, and asks the user to approve a plan before visiting new domains or acting on sensitive pages; passwords, payment details and CAPTCHA solving are outside its stated actions. The homepage describes teaching a job once, scheduled runs in the user's open browser, an editable memory of corrections and per-site JavaScript helpers the agent writes for itself, while the documentation's limitations page still says it does not run tasks in the background or on a schedule. Models include Claude, GPT, Gemini and local models, through managed credits or the user's own key. The documentation source, omnify-labs/dassi-docs, is CC-BY-4.0 per the GitHub API; the license applies to documentation alone.
