# Web-Shepherd: Advancing PRMs for Reinforcing Web Agents

Web-Shepherd 是评估网页导航轨迹各步骤的过程奖励模型；工作构建了含检查清单的 40,000 对步骤级偏好数据及独立的奖励模型比较基准，并评估其在 WebArena-lite 导航中的验证作用。
