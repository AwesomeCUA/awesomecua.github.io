# LegacyWorld: Atomicity-Aware Evaluation of GUI Agents for Legacy Workflows

LegacyWorld 按原子性标准评估 Windows GUI 工作流：要么正确完成，要么失败且不留下持久的非预期更改；比较专家提示与从记录的标准路径生成的提示，并区分有效完成、安全失败和非原子性副作用。
