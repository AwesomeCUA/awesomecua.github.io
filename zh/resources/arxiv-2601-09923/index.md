# CaMeLs Can Use Computers Too: System-level Security for Computer Use Agents

NOVA 在执行前生成分支计划，将可信的任务规划与屏幕观察分开，并通过感知确定运行时取值。其 OSWorld 研究考察安全性和任务效果，指出感知结果引导分支选择仍有风险。
