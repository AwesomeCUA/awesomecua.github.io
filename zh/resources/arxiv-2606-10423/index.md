# WebChallenger: A Reliable and Efficient Generalist Web Agent

WebChallenger 构建源自 DOM 的分层页面表示，用于选择性观察、复用网站地图及执行复合操作。框架无需微调模型即可结合这些机制，并在多个网页智能体基准上评估泛化能力。
