# STaR-KV: Spatio-Temporal Adaptive Re-weighting for KV Cache Compression in GUI Vision-Language Models

STaR-KV 根据注意力子空间和交互时间校准视觉 token 的重要性，以压缩 GUI 智能体的 KV 缓存。其免训练评分结合空间专门化、时间冗余和自适应温度，并在相同缓存预算下评估。
