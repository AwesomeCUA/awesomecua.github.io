# KnowAct-GUIClaw: Know Deeply, Act Perfectly, Personal GUI Assistant with Self-Evolving Memory and Skill

KnowAct-GUIClaw 结合主规划器、可插拔 GUI 子智能体、可追溯的经验记忆和持续演化的技能库。它利用用户画像和反馈分解任务，并评估在 Android、iOS、HarmonyOS 和 Windows 之间的迁移。
