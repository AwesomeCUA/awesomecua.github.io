# Mapping the Design Space of User Experience for Computer Use Agents

通过系统综述和从业者访谈，构建计算机使用智能体交互设计的分类体系；再以巫师式实验研究用户对正常、出错及有风险的网页操作的反应，关注控制、解释、提示和心智模型。
