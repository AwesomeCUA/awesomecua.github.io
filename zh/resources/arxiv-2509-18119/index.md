# MobileRL: Online Agentic Reinforcement Learning for Mobile GUI Agents

MobileRL 通过按难度重放成功经验、筛选失败课程，将 GRPO 用于移动 GUI 训练；还用最短路径奖励调整处理任务长度，并在 AndroidWorld 和 AndroidLab 上评估。
