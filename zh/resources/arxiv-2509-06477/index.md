# MAS-Bench: A Unified Benchmark for Shortcut-Augmented Hybrid Mobile GUI Agents

MAS-Bench 评估结合 GUI 操作、API、深层链接和可复用脚本的移动智能体；覆盖 11 款应用的 139 项任务，测试其使用 88 个预定义快捷方式及生成新可复用流程的能力。
