# RedTeamCUA: Realistic Adversarial Testing of Computer-Use Agents in Hybrid Web-OS Environments

RedTeamCUA 结合虚拟机操作系统环境和容器化网站，开展跨两类界面的受控提示注入测试。RTC-Bench 包含 864 个样例，可让智能体从注入点开始执行，以区分受攻击影响与导航失败。
