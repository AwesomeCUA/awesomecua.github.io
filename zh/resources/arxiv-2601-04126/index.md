# InfiniteWeb: Scalable Web Environment Synthesis for GUI Agent Training

InfiniteWeb 依据共享规格和任务驱动开发，生成可运行且相互连接的网站及任务评估器。论文评估网站构建，并考察在这些合成网页环境中训练的 GUI 策略向 OSWorld 和 Online-Mind2Web 迁移的效果。
