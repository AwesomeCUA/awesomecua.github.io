# CADWorld: Computer-Use Benchmark for Long-Horizon Computer-Aided Design

CADWorld 评估通过截图和 GUI 操作完成 FreeCAD 长流程任务的智能体，涵盖建模、装配、制造和仿真。可执行检查从几何形状、约束、构建结构和后续状态等方面检验保存的工程成果。
