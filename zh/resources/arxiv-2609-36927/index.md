# Neuro-Symbolic Computer Use: Learning Reusable Policies for Reliable and Efficient Execution

该方法学习可复用的计算机使用策略，用程序编码稳定的工作流程逻辑，由神经模型负责定位和状态检查。策略迭代通过执行变体、诊断失败、修改程序，并在改变状态的操作前加入核验。
