# ScaleTrack: Scaling and back-tracking Automated GUI Agents

ScaleTrack 结合统一收集的 GUI 定位样本与规划目标，在预测下一步动作时重建先前动作。这种反向预测在智能体训练中将当前截图与交互历史关联起来。
