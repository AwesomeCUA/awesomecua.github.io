# Ferret-UI Lite: Lessons from Building Small On-Device GUI Agents

Ferret-UI Lite 利用真实与合成混合数据、推理时的视觉工具以及强化学习开发 3B GUI 智能体，并在移动端、网页和桌面场景评估定位与导航，包括 AndroidWorld 和 OSWorld。
