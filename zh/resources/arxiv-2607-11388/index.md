# StructAgent: Harness Long-horizon Digital Agents with Unified Causal Structure

StructAgent 维护精简的任务状态，通过经核验的状态转换和进度检查点管理长程执行。其工作流支持依据证据判断完成情况并进行针对性恢复，评估涵盖桌面计算机使用及单独的 Minecraft 扩展。
