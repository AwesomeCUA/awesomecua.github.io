# Sidekick: Designing Communication for Effective Multitasking with Computer Use Agents

Sidekick 通过环境状态提示、多模态操作摘要，以及视觉和文字推理说明，帮助用户监控计算机使用智能体。用户研究考察了后台与前台交互中的进度感知、错误追溯和多任务处理。
