# GUI-Shift: Enhancing VLM-Based GUI Agents through Self-supervised Reinforcement Learning

GUI-Shift 利用无自然语言指令的轨迹训练逆动力学任务，预测连接 2 个 GUI 状态的初始动作。它结合基于规则的强化学习与数据筛选，并评估向 Android 自动化和截图定位任务的迁移。
