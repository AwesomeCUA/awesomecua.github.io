# Don't Act Blindly: Robust GUI Automation via Action-Effect Verification and Self-Correction

VeriGUI 在执行后续 GUI 操作前核查预期操作效果并推理如何恢复。训练结合合成失败轨迹与按验证结果加权的 GRPO，并在基于 AndroidControl 的抗干扰基准上评估。
