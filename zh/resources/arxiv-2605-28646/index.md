# MaskClaw: Edge-Side Personalized Privacy Arbitration for GUI Agents with Behavior-Driven Skill Evolution

MaskClaw 依据视觉证据和个性化策略记忆，在 GUI 截图离开可信环境前于本地决定放行、遮蔽或询问。其基准与设计的演化场景检验如何将纠正和编辑转为经沙箱关卡检查的隐私技能。
