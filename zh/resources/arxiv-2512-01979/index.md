# Chain-of-Ground: Improving GUI Grounding via Iterative Reasoning and Reference Feedback

Chain-of-Ground 通过迭代视觉推理和参照反馈，在无需额外训练的情况下改进 GUI 定位。论文在 ScreenSpot-Pro 上评估，并提出 TPanel-UI，以考察视觉失真条件下工业控制面板的定位能力。
