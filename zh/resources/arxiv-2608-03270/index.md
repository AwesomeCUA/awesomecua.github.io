# GUI-Lens: Coarse-to-Fine Cropping for GUI Grounding with General-Purpose VLMs

GUI-Lens 以 OCR 和检测到的界面组件为坐标参照，由通用 VLM 选择逐步放大的截图裁剪区域；通过基于指令的检查约束裁剪和点击方案，再将最终位置映射回原始屏幕。
