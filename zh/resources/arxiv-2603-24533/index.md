# UI-Voyager: A Self-Evolving GUI Agent Learning via Failed Experience

提出两阶段移动端 GUI 学习方法：先通过拒绝微调使轨迹与策略共同演进，再用 Group Relative Self-Distillation 从成功的执行分支为失败轨迹提供步骤级监督，并在 AndroidWorld 上评估。
