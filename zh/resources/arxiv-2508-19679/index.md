# InquireMobile: Teaching VLM-based Mobile Agent to Request Human Assistance via Reinforcement Fine-Tuning

InquireMobile 通过分阶段强化微调和操作前推理，训练移动智能体在关键决策时征求人类确认。InquireBench 评估安全交互和主动询问，并区分求助与完成原任务。
