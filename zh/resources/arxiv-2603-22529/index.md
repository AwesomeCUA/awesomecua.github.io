# Ego2Web: A Web Agent Benchmark Grounded in Egocentric Videos

Ego2Web 将第一人称视频与在线任务配对，要求智能体将用户所处的物理情境与网页动作联系起来。它还对照人工判断评估自动任务裁判，并分析视频理解和网页执行中的失败。
