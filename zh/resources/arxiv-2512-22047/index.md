# MAI-UI Technical Report: Real-World Centric Foundation GUI Agents

MAI-UI 是一组通过生成数据和在线强化学习训练的策略，结合 GUI 导航、原生用户交互和 MCP 工具调用。报告还研究设备与云端的任务路由、并行环境和交互预算的扩展，并评估定位与 Android 导航。
