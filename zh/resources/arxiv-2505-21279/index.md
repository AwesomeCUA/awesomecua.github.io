# XBOUND: Exploring Capability Boundaries of Device-Control Agents at the State Level

XBOUND 在单个屏幕状态层面评估 GUI 智能体，考虑其中的多条指令和可能的目标动作；研究区分动作匹配与指令统一，并比较定位数据和轨迹数据的影响。
