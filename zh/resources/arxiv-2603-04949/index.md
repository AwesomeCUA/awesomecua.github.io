# TimeWarp: Evaluating Web Agents by Revisiting the Past

TimeWarp 在同一网站的多个版本上测试网页智能体，这些版本在视觉设计、前端代码和工作流程上有所不同；TimeTraj 跨版本迁移计划以收集训练轨迹，并研究智能体对界面变化的适应能力。
