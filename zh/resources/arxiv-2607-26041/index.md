# Desktop-Delta Bench: Do Computer-Use Models Understand Desktop GUI Transitions?

Desktop-Delta Bench 通过时序排序和根据操作前后状态推断操作的任务，离线诊断 GUI 状态转换理解能力。它还包含干扰性观察，用于测试模型能否追踪屏幕变化的来源及其与任务的相关性。
