# RealGUINoise: An Interactive Cross-Platform Benchmark for GUI Agent Robustness under Real-World Interface Noise

RealGUINoise 在多种贴近真实场景的界面噪声下评估交互式 GUI 智能体，并与无噪声环境中的运行结果比较任务完成情况、安全性和行为。
