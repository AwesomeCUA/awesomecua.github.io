# WinDeskGround: A Benchmark for Robust GUI Grounding in Complex Multi-Window Desktop Environments

WinDeskGround 合成多窗口桌面布局，并控制遮挡、密度和语义相似度，以测试 GUI 定位的鲁棒性；其指令目标基准衡量界面偏离简单单层场景时定位表现的变化。
