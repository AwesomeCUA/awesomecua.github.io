# FedGUI: Benchmarking Federated GUI Agents across Heterogeneous Platforms, Devices, and Operating Systems

FedGUI 是由 6 个覆盖移动端、网页和桌面界面的数据集构建的联邦 GUI 学习基准；实验分别考察平台、设备、操作系统和数据来源的异质性对协同训练评估的影响。
