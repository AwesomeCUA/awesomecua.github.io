# Naive Visual Memory is Not Enough: A Failure-Mode Study of GUI Agents

研究发现，保存完整图像的视觉记忆虽可减少部分状态错误，却会加剧动作层面的失败。替代方法 AGMem 存储与成功操作或恢复过程相关的局部截图，并在桌面 GUI 任务中评估其用途。
