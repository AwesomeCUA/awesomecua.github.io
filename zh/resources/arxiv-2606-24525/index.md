# VisCritic: Visual State Comparison as Process Reward for GUI Agents

VisCritic 通过感知变化的视觉特征和以操作为条件的评价模型，比较操作前后的截图。它利用现有轨迹中的弱监督样本，训练对操作成功与否、进度和错误类型的判断，供 GUI 智能体核验使用。
