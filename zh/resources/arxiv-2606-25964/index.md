# WinDOM: Self-Family Distillation for Small-Model GUI Grounding

WinDOM 通过 Playwright 驱动的 Windows 11 网页复刻环境获取边界框监督，并研究面向小型 GUI 定位模型的拒绝采样蒸馏。它将监督式冷启动的训练深度视为 GRPO 中的一项选择，比较同规模 EMA 教师模型与更大的同系列教师模型。
