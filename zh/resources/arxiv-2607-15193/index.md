# Plover: Steering GUI Agents through Plan-Centric Interaction

Plover 将 GUI 智能体的计划及重新规划结果作为可持久保存的内容，供用户在执行中查看和编辑。其规划器—执行器设计支持通过修改计划、语言指导和基于截图的干预进行局部纠正，并在失败修复与工作流场景中研究这一机制。
