# MementoGUI: Learning Agentic Multimodal Memory Control for Long-Horizon GUI Agents

MementoGUI 在固定 GUI 智能体骨干模型的条件下，学习选择、压缩和检索文本及区域级视觉记忆的控制器；还将计算机使用轨迹转为控制器训练数据，在长程任务中评估语义操作、进展和记忆一致性。
