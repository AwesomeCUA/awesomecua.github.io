# OmegaUse: Building a General-Purpose GUI Agent for Autonomous Task Execution

OmegaUse 结合探索式与分类体系引导的数据合成，先进行监督微调，再用 GRPO 训练 GUI 控制。报告还提出 OS-Nav，用于离线评估 Android 和 Ubuntu，并结合现有定位与操作预测基准。
