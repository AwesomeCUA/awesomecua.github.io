# Invisible in Space, Visible in Time: Motion Vision CAPTCHA against GUI Agents

MVCAP-Bench 测试实时浏览器中的 CAPTCHA：其前景含义通过动态背景中的运动显现。仅呈现前景的对照条件用于区分时间维度伪装的难度与答案格式、浏览器交互的影响。
