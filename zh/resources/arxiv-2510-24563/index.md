# OSWorld-MCP: Benchmarking MCP Tool Invocation In Computer-Use Agents

OSWorld-MCP 评估智能体如何在计算机任务中选择 GUI 操作或 MCP 工具调用。它结合生成和筛选的工具，涵盖 7 个应用中经人工核验的 158 个工具，同时考察工具使用与任务完成情况。
