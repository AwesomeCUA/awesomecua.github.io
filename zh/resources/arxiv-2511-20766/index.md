# OpenApps: Simulating Environment Variations to Measure UI-Agent Reliability

OpenApps 是可配置的应用生态，用于衡量界面外观和内容变化时 UI 智能体的运行稳定性。评估比较同一应用多个版本上的任务成功率和失败行为。
