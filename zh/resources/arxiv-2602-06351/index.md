# Trifuse: Enhancing Attention-Based GUI Grounding via Multimodal Fusion

Trifuse 结合基于注意力的定位、OCR 文本线索和图标描述来定位 GUI 指令目标；其融合流程侧重跨模态一致性与清晰的位置峰值，并在不针对任务微调的条件下评估。
