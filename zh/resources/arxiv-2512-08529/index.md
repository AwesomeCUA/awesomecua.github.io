# MVP: Multiple View Prediction Improves GUI Grounding

MVP 通过在多个由注意力引导的裁剪视图上预测，处理 GUI 坐标不稳定的问题。它对所得坐标聚类并选择最密集簇的中心，在多种定位模型上评估这一免训练推理方法。
