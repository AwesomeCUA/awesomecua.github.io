# LabOSBench: Benchmarking Computer Use Agents for Scientific Instrument Control

LabOSBench 通过基于浏览器的科学仪器模拟器，以可配置任务和执行结果检查评估 GUI 智能体。子任务及端到端测试考察依据反馈进行调整和处理长流程的能力，不涉及控制实体仪器。
