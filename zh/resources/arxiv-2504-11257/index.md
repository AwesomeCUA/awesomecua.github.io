# UI-E2I-Synth: Advancing GUI Grounding with Large-Scale Instruction Synthesis

UI-E2I-Synth 使用 GPT-4o 合成复杂程度各异的 GUI 定位指令，涵盖小元素、元素类型不均衡和隐含请求等问题。配套的 UI-I2E-Bench 评估这些标注难题下从指令到元素的定位。
