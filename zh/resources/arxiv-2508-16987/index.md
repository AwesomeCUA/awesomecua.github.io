# WebSight: A Vision-First Architecture for Robust Web Agents

WebSight 在模块化智能体中使用基于网页界面示例训练的视觉语言模型，包含规划、操作、验证和情景记忆组件；通过视觉观察，在 Showdown Clicks 上评估元素点击，在 WebVoyager 上评估完整浏览任务。
