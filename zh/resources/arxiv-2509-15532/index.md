# GUI-ARP: Enhancing Grounding with Adaptive Region Perception for GUI Agents

GUI-ARP 利用视觉注意力裁剪截图中的相关区域，并判断目标需要单阶段还是多阶段分析；通过监督微调和后续 GRPO 训练这一自适应流程，用于高分辨率 GUI 定位。
