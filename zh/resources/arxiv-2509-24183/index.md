# Retrieval-augmented GUI Agents with Generative Guidelines

RAG-GUI 训练小型指导适配器，筛选和概括检索到的网页教程，同时保持执行操作的智能体不变。适配器经监督训练和拒绝采样训练后用于推理阶段辅助，并在离线网页、移动端任务及交互式 Android 任务上测试。
