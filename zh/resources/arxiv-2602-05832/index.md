# UI-Mem: Self-Evolving Experience Memory for Online Reinforcement Learning in Mobile GUI Agents

UI-Mem 将工作流、技能和失败模式存为可复用模板，引导在线 GUI 强化学习；它在同组执行轨迹中采用不同程度的指引，并持续更新记忆，使无指引策略也能从有指引的经验中学习。
