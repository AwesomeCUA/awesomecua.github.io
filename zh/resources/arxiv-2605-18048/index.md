# DocOS: Towards Proactive Document-Guided Actions in GUI Agents

DocOS 在交互式网页环境中评估智能体检索在线文档、将操作步骤转化为 GUI 操作的能力，并区分未能检索到有用流程与未能把检索到的指令定位为可执行操作这两类失败。
