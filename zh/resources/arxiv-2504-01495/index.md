# Are Autonomous Web Agents Good Testers?

使网页智能体执行自然语言测试步骤、核验断言并给出测试结论；提出涵盖 3 个离线网页应用的 113 个成功与失败测试用例，比较 2 种智能体实现并定性分析失败原因。
