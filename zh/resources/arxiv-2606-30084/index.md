# One Forward Beats Two: InnerZoom for Accurate and Efficient GUI Grounding

InnerZoom 保留解码器中间层的目标区域线索，并在坐标解码时重新注入压缩的证据状态。研究比较了其单次前向推理的 GUI 定位方法与裁剪后重新推理的缩放方法，以及匹配的监督学习和 RL 基线在准确率与推理成本上的表现。
