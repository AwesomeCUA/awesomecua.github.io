# OmniGUI: Benchmarking GUI Agents in Omni-Modal Smartphone Environments

OmniGUI 依据交错的手机截图、同步音频和视频评估逐步操作预测；专家示范标注多模态依赖关系，初步基线以原生多模态模型代理智能体，研究时序和音频相关的失败。
