# MUD: Towards a Large-Scale and Noise-Filtered UI Dataset for Modern Style UI Modeling

MUD 结合 LLM 引导的 Android 应用探索、噪声过滤和人工标注，收集现代风格 UI 截图；研究评估了所得数据在元素检测和 UI 检索中的用途。
