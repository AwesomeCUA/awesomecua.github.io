# Web Agents Should Adopt the Plan-Then-Execute Paradigm

主张在智能体接触不可信的运行时内容前，将网页任务编译成预定义的执行图；基于 WebArena 的任务分析指出，具备类型定义且语义完整的网站工具是前提，并将这一接口方案与响应式逐次点击控制区分开来。
