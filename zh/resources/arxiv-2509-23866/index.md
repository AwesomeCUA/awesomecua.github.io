# Efficient Multi-turn RL for GUI Agents via Decoupled Training and Adaptive Data Curation

DART 将 GUI 强化学习拆分为异步环境、轨迹生成、数据管理和训练服务。它按任务难度、成功轨迹和步骤不确定性筛选经验，同时校正轨迹生成策略与训练策略的偏差，并在 OSWorld 上评估。
