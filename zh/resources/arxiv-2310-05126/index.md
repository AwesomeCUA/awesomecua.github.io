# UReader: Universal OCR-free Visually-situated Language Understanding with Multimodal Large Language Model

提出 UReader，结合统一指令微调、辅助文本阅读任务和形状自适应图像裁剪，实现无需 OCR 的视觉语言理解；评估涵盖网页截图、文档、表格、图表和自然图像。
