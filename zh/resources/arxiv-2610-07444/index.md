# Decoupling What from Where: How Should a Small GUI Grounding Model Receive the Action Type?

在 Android in the Wild 上以相同训练条件比较向小型 GUI 定位模型提供动作类型的不同方式。研究将表面上的增益追溯到坐标序列化方式，并指出这些增益在使用预测动作类型时能否保持，证据有限。
