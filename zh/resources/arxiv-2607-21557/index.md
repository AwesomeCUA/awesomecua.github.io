# OpenForgeRL: Train Harness-native Agents in Any Environment

OpenForgeRL 通过模型调用记录代理和隔离的执行容器，将有状态智能体运行框架接入强化学习基础设施；其验证涵盖浏览器操作、计算机使用及工具型智能体，并考察运行框架选择对学得的执行稳定性的影响。
