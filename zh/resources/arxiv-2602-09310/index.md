# A11y-CUA Dataset: Characterizing the Accessibility Gap in Computer Use Agents

A11y-CUA 数据集比较盲人或低视力用户与视力正常用户完成日常计算机任务的方式，并将这些操作轨迹与智能体在默认、仅键盘和放大镜条件下的行为对照，以识别共同控制中的障碍。
