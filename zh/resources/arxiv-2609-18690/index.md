# RankGround: Efficient High-Resolution GUI Grounding via Lightweight Reranker-Guided Crop Selection

RankGround 训练轻量级重排序器，先选出有希望的截图裁剪区域，再调用一次 VLM 进行定位。排序监督采用包含关系和边界感知增强，训练分为逐项和列表两个阶段。
