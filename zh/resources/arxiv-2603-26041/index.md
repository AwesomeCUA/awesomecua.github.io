# Where and How to Prune: An Empirical Study of Visual Token Pruning for GUI Agent Navigation

研究 GUI 导航中的视觉 token 剪枝，将可复用的截图编码器嵌入与后续语言模型计算分开。分析剪枝历史截图时前景与背景的 token 分配及空间覆盖情况。
