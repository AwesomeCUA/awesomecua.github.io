# DeltaReplay: Task-Relative Memory Reuse for Mobile GUI Agents

提出 DeltaReplay，将移动端 GUI 轨迹存为状态转移图，并在每一步决定复用动作、替换任务特定参数，或交由基础智能体处理。这样可在不重写存储记忆的情况下复用部分匹配的经验。
