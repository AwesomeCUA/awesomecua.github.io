# UI-Zoomer: Uncertainty-Driven Adaptive Zoom-In for GUI Grounding

UI-Zoomer 是一种无需训练的定位方法，利用候选结果的一致程度和 token 置信度决定何时裁剪图像并重试；预测差异为每个不确定的界面目标确定单独的裁剪半径。
