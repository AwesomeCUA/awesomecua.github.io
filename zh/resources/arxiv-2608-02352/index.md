# Qwen-CUA: Native Computer Use for (almost) Everything

Qwen-CUA 通过截图及键盘、鼠标事件操作，并将较早的视觉历史压缩为可复用的上下文块。报告结合可验证任务生成、基于轨迹的训练，以及分别针对浏览器和 Bash 辅助场景的研究。
