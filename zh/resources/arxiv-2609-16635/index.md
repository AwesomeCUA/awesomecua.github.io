# EchoPath: Execution-Level Replayable Memory for GUI Agents

EchoPath 将经过验证的 GUI 轨迹转为带有明确运行前置条件的参数化重放流程。基于图像的目标匹配可调整保存的坐标，遇到有歧义的步骤则转向有限修复或重新规划。
