# Untrusted Content Masking for Web Agents with Security Guarantees

Untrusted Content Masking 利用 DOM 结构，在智能体观察前遮蔽网页中的不可信区域。沙箱化交互接口隔离权限，使浏览器操作可在所提出的信任边界模型下进行，同时不向规划器暴露受保护内容。
