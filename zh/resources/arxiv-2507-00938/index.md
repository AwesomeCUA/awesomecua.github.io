# WebArxiv: A Reproducible Benchmark for Evaluating Multimodal Web Agents on arXiv Tasks

WebArxiv 提供 510 项答案确定的静态快照任务，涵盖受约束的论文检索、内容提取和跨论文比较；还测试动态检索交互历史，以应对智能体推理重复或不完整的问题。
