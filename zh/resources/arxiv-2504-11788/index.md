# WebRollback: Enhancing Web Agents with Explicit Rollback Mechanisms

WebRollback 为网页智能体提供显式操作，使其返回导航轨迹中的较早状态，并在零样本和微调设置下，通过 2 个实时网页导航基准研究这一恢复机制。
