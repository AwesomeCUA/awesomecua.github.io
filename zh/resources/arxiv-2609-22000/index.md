# RecreationWorld: Scalable and Verifiable Environments for Hybrid Computer-Use Agents

RecreationWorld 为混合式智能体提供可运行的参考应用，供其探索并利用原生 GUI 控件和编程工具复现。其多平台基准通过程序和视觉断言检查依赖交互的行为，并单独评估轨迹训练的迁移效果。
