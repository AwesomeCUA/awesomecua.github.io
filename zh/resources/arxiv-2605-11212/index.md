# ReVision: Scaling Computer-Use Agents via Temporal Visual Redundancy Reduction

训练 GUI 智能体时，使用学习得到的选择器去除连续截图中重复的视觉图块，同时保留空间结构；ReVision 在 OSWorld、WebTailBench 和 AgentNetBench 上评估这种历史表示。
