# Breaking the Data Barrier -- Building GUI Agents Through Task Generalization

研究 GUI 感知、多模态推理和文本推理的中期训练能否迁移到 GUI 智能体规划。在 GUI 轨迹稀缺的情况下，基于 WebArena 和 AndroidWorld 比较 11 种任务来源及精选混合数据，以研究训练数据的选择。
