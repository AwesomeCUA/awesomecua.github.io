# GraphPilot: GUI Task Automation with One-Step LLM Reasoning Powered by Knowledge Graph

GraphPilot 根据探索过的页面、元素和跳转构建应用专属知识图谱，用于规划操作序列；遇到不确定情况时补充观察界面，并在修正和执行前依据图谱的跳转规则检查计划。
