# Zoom to Essence: Trainless GUI Grounding by Inferring upon Interface Elements

ZoomUI 是一种无需训练的定位方法，将指令转写为视觉元素描述，并借助模型注意力逐步放大相关界面区域。在 GUI 基准上评估从指令定位元素的能力。
