# \textsc{GUI-Spotlight}: Adaptive Iterative Focus Refinement for Enhanced GUI Visual Grounding

GUI-Spotlight 训练定位模型对图像进行推理，并调用工具逐步缩小视觉关注范围。模型使用 18,500 个样本训练后，在 ScreenSpot-Pro 上评估这一方法。
