# GUI-ReWalk: Massive Data Generation for GUI Agent via Stochastic Exploration and Intent-Aware Reasoning

GUI-ReWalk 先随机探索界面，再推断目标以生成连贯的操作轨迹；它支持跨应用的长程工作流，并通过定位和导航基准研究使用生成数据进行训练的效果。
