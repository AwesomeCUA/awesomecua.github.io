# Go-Browse: Training Web Agents with Structured Exploration

Go-Browse 将网页环境探索建模为图搜索，使信息可在不同数据收集过程中复用；它在 WebArena 上收集 10,000 条成功轨迹和 40,000 个交互步骤，并用于微调网页智能体。
