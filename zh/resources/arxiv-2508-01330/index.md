# NaturalGAIA: A Verifiable Benchmark and Hierarchical Framework for Long-Horizon GUI Tasks

NaturalGAIA 根据人类交互意图构建可验证的长程 GUI 任务，并区分任务的因果结构与文字描述。其 LightManus-Jarvis 框架将动态规划和上下文管理，与基于界面视觉及结构信息的执行分开。
