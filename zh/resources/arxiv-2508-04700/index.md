# SEAgent: Self-Evolving Computer Use Agent with Autonomous Learning from Experience

SEAgent 借助世界状态评估器和自动生成的任务课程探索陌生软件，通过对抗模仿和 GRPO 从成功与失败的交互中学习，再将专门经验整合为通用智能体，在 5 个 OSWorld 软件环境中评估。
