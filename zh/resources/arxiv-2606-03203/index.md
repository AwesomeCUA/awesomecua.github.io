# MedCUA-Bench: A Screenshot-Only Benchmark for Clinical Computer-Use Agents

MedCUA-Bench 以成对的意图级和步骤级目标，评估仅凭截图完成临床界面任务的能力。它结合重建的医疗界面、完成情况与临床安全检查，并单独报告真实 OpenEMR 系统上的结果。
