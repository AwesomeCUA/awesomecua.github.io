# AmbiBench: Benchmarking Mobile GUI Agents Beyond One-Shot Instructions in the Wild

AmbiBench 在 4 种指令清晰度下评估移动 GUI 智能体，包括需要主动澄清的任务；其 MUSE 评估器分别审查结果、执行质量和交互质量，以研究智能体与用户意图的一致性。
