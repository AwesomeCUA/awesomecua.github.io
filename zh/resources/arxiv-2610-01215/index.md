# AutoGUIWorld: Image Generators as Visual World Models for GUI Agent

AutoGUIWorld 结合任务规划与图像编辑，无需运行画面所示软件即可合成与操作对应的 GUI 轨迹。它筛选生成的状态转移，并测试用其训练能否提升智能体在真实桌面和科学应用中的表现。
