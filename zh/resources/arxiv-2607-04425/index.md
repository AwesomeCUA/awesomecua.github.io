# UI-MOPD: Multi-Platform On-Policy Distillation for Unified GUI Agents

研究提出桌面和移动端可执行轨迹集 Uni-GUI，以及利用各平台教师模型从自身执行轨迹训练共享策略的 UI-MOPD。蒸馏过程将每个到访状态交给相应教师，以保留不同平台的交互惯例。
