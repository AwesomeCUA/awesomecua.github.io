# Using GUI Agent for Electronic Design Automation

GUI-EDA 收集工程师使用 5 种 CAD 工具、涉及 5 个物理领域的 2,000 多组截图、答案和操作数据。配套基准在专门的电子设计流程中评估 30 多个 GUI 智能体。
