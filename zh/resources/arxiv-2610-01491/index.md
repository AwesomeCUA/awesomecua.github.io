# Auditing Web Agent Evaluation on WebArena-Lite: Human Review of Outcomes and Trajectories

通过人工复核 WebArena-Lite 的结果和轨迹，识别自动评估器误判失败的情况及最早产生实质影响的执行错误；还研究显式执行状态记忆和流程指导，说明最终任务得分可能掩盖智能体行为中的较大差异。
