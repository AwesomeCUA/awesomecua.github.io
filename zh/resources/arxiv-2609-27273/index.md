# CAVEAT: Towards Robust Computer-Use Agents in Incentive-Misaligned Environments

CAVEAT 是一个受控的市场基准，用于测试界面偏向其他结果时，受委托的智能体能否保持用户目标。它诊断决策失败，并研究运行框架干预和定向训练如何提高抵御市场界面引导的能力。
