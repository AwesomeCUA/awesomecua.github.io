# ConClick: Element-Wise Contrastive Learning Improves GUI Grounding

分析 GUI 定位中反复点击干扰项的问题，提出基于目标与干扰项配对的对比训练方法 ConClick。其 ReClick 推理流程重新查看候选区域并比较相互竞争的预测。
