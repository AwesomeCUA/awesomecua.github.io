# AndroidLens: Long-latency Evaluation with Nested Sub-targets for Android GUI Agents

AndroidLens 提供 571 项中英文移动端扩展任务，允许多条有效路径并保留环境异常。其动态评估利用嵌套里程碑和 Average Task Progress 衡量长流程任务的部分完成情况。
