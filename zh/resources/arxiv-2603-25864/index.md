# GUIDE: A Benchmark for Understanding and Assisting Users in Open-Ended GUI Tasks

GUIDE 评估模型能否在开放式软件任务中识别用户行为、推断意图并判断何时提供帮助。它使用新手用户的带解说屏幕录像，并研究额外用户上下文对协助决策的影响。
