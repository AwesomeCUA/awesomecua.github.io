# Do GUI Agents Believe Their Eyes? Diagnosing State-Belief Reliance on Pixels versus Structure

研究定义视觉状态依赖，探查 GUI 智能体在截图与界面结构冲突时依据像素、序列化界面结构还是既有信念判断状态。成对干预和实时多步测试将状态信念误归因与失败联系起来，并比较基于一致性的缓解方法。
