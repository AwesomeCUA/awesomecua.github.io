# SnapGuard: Lightweight Prompt Injection Detection for Screenshot-Based Web Agents

SnapGuard 结合视觉稳定性与恢复出的文本线索，检测基于截图的提示注入；评估比较攻击和正常页面场景中的检测质量及推理成本。
