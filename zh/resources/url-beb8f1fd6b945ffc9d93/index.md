# GUI-SAGE: Enhancing GUI Automation with Self-Explanatory Learning

GUI-SAGE 根据已知操作生成推理内容，并利用置信度和奖励信号对策略更新加权。实验使用 AndroidControl 和 GUIOdyssey 数据，另对交互式 AndroidWorld 任务进行评估。
