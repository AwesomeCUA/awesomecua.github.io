# Mem-W: Latent Memory-Native GUI Agents

Mem-W 将以往轨迹和当前会话片段压缩为 GUI 策略直接使用的潜在记忆 token，并通过自蒸馏与结果监督训练该记忆表示，用于网页和移动端导航。
