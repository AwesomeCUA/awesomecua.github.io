# Characterizing Unintended Consequences in Human-GUI Agent Collaboration for Web Browsing

通过社交媒体分析和访谈，研究人与 GUI 智能体协作浏览网页时的意外后果，并围绕规划、界面交互、反馈、隐私和信任梳理观察到的失误、用户影响及缓解做法。
