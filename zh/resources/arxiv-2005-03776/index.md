# Mapping Natural Language Instructions to Mobile UI Action Sequences

提出 PIXELHELP，根据指令预测移动 UI 操作序列，并提供操作短语标注和合成 UI 操作描述用于训练。两个独立的 Transformer 分别提取指令步骤，以及结合界面内容和屏幕位置定位对象描述。
