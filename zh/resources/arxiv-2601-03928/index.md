# FocusUI: Efficient UI Grounding via Position-Preserving Visual Token Selection

FocusUI 选取与指令相关的截图图块，同时保留其位置结构以供 GUI 定位。其 PosPad 方案用位置标记替换连续丢弃的 token，并在缩减的 token 预算下进行评估。
