# MirrorGuard: Toward Secure Computer-Use Agents via Simulation-to-Real Reasoning Correction

MirrorGuard 利用文本式神经符号模拟器生成的 GUI 风险轨迹，训练推理纠错防御。它将模拟训练与部署测试分开，评估纠错能否迁移到操作真实界面的计算机使用智能体。
