## 范围记录

Retriever AI describes its engine as DOM-native: a planner directs sub-agents for clicks, typing and navigation, DOM extraction, pagination and files, and the same agent runs in the Chrome extension, in Cloud headless browsers (logins carried over by Cookie Sync) and through the API. Free Mode includes supported models and cloud browser time with sponsored cards and a daily allowance; users can bring their own model keys, and schedules, triggers, Cookie Sync and API or MCP control of the user's own Chrome require a paid plan. Recordings capture DOM interactions and the page's own network calls in place of screen recordings, and can be turned into replays or into subroutines that call a site's endpoints directly. An experimental Jev option lets a separate model choose browser actions while the selected model plans. The company also offers Rover, an agent that site owners embed for their visitors, and sells browser-agent trajectories and replica business apps for evaluation. The homepage's Web Bench ranking is a publisher claim.
