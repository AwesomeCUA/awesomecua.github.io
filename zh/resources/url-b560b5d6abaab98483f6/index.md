# Rico: A Mobile App Dataset for Building Data-Driven Design Applications

Rico 先通过众包使用、再通过自动探索收集 Android 界面设计和交互轨迹。论文展示了利用学习到的表示检索 UI 布局，并介绍视觉、文本、结构和交互数据。
