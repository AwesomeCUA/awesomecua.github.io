# PlayCoder: Making LLM-Generated GUI Code Playable

PlayEval 通过 PlayTester 执行面向任务的 GUI 游玩流程，衡量生成的 GUI 应用能否在逻辑上正常游玩；PlayCoder 将感知代码仓库的生成、交互测试和针对性代码修复连接成闭环。
