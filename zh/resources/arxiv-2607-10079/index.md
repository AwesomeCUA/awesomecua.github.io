# MAG: A Web-Agent Benchmark and Harness for Multimodal Action and Guide Generation

MAG 联合评估浏览器任务操作，以及通过元素标记或像素坐标定位到截图的用户指南。其框架涵盖标注、实时评估和联合指标，并研究了加入专家轨迹的 GRPO 训练。
