# ComAct: Reframing Professional Software Manipulation via COM-as-Action Paradigm

ComAct 提出将 COM 程序合成作为操控专业软件的另一种接口，并发布包含 GUI 对比智能体的 ComCADBench。ComActor 采用分阶段训练与纠错方法，由 Windows 容器训练平台提供支持。
