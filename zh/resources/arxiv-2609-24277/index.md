# How Many Pixels Is a Digit Worth? Place-Aware Coordinate Entropy for GUI Agent Confidence Estimation

PACE 按数位权重加权坐标数字的熵，通过单次前向计算估计 GUI 点击的置信度。它在 ScreenSpot-Pro 和 ScreenSpot-v2 上，将正确性排序和选择性准确率与重复采样方法比较。
