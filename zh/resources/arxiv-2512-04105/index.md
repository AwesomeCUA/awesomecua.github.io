# LegalWebAgent: Empowering Access to Justice via LLM-Based Web Agents

LegalWebAgent 将用户需求澄清、网页浏览与表单填写或预约等操作分开处理，并通过 15 项任务，利用 HTML 和截图观察评估与魁北克民法用户相关的法律服务流程。
