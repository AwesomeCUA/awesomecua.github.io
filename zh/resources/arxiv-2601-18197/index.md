# GAIA: A Data Flywheel System for Training GUI Test-Time Scaling Critic Models

GAIA 用正反例训练 GUI 操作评判模型，再用该模型收集改进后的样例进入下一轮训练，并研究这种数据循环如何影响不同 GUI 智能体在测试时的操作选择。
