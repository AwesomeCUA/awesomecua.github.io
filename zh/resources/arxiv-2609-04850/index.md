# ElderBench: Benchmarking Autonomous Mobile Agents for Older Adults

ElderBench 用从老年人收集的智能手机请求评估移动端 GUI 智能体，其中包括间接和信息不充分的表达；线上与离线测试、指令规范化及语言分析考察这些表达如何导致失败。
