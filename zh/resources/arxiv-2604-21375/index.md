# VLAA-GUI: Knowing When to Stop, Recover, and Search, A Modular Framework for GUI Automation

VLAA-GUI 结合强制进行的基于视觉证据的完成检查、多层级循环恢复和按需工作流搜索，并可选用编码与定位智能体辅助执行；在 Linux 和 Windows 的 GUI 任务上进行组件消融实验。
