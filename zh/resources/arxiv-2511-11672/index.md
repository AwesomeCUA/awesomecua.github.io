# OSGym: Scalable OS Infra for Computer Use Agents

OSGym 提供带 GUI 的完整操作系统沙盒，支持并行收集计算机使用数据和训练。它结合副本级状态管理、硬件感知调度、写时复制虚拟机磁盘和分层故障恢复。
