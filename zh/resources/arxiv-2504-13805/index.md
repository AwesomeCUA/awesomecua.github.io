# LearnAct: Few-Shot Mobile GUI Agent with a Unified Demonstration Benchmark

LearnAct 将人类演示解析为可复用知识，检索相关示例，并在执行移动端 GUI 任务时使用。配套的 LearnGUI 基准包含 2,252 项离线任务和 101 项在线任务，用于研究从演示中学习适应。
