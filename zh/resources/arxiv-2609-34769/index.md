# LongPuzzleBench: Evaluating GUI Agents on Long-Horizon Visual Puzzles

LongPuzzleBench 通过原生 GUI 操作，在持续存在的视觉谜题棋盘上评估连贯的长期规划。它比较纯 GUI 与代码辅助智能体，并通过受控提示和记忆诊断，分析保留或排除未来解法的决策。
