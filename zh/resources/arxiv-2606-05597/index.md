# AsyncWebRL: Efficient Asynchronous Reinforcement Learning for Multi-Step Visual Web Agents

AsyncWebRL 在处理截图并维护持久化采样池的同时，交叠进行网页智能体轨迹采样、更新和策略刷新；还替换多步 GRPO 中的轨迹长度归一化，以减少冗长的失败轨迹，并评估吞吐量和分布外表现。
