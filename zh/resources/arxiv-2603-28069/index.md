# MolmoPoint: Better Pointing for VLMs with Grounding Tokens

MolmoPoint 用指向 token 替代文本坐标生成，先选取视觉区域，再通过子图块细化定位。该通用图像与视频方法除其他视觉定位任务外，还在 ScreenSpotPro 上评估 GUI 指向能力。
