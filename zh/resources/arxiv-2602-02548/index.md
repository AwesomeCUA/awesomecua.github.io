# ToolTok: Tool Tokenization for Efficient and Generalizable GUI Agents

ToolTok 用学习得到的工具 token 表示 GUI 操作，将交互组织为逐步选择工具的过程；通过语义锚定和由易到难的课程，先学习工具含义再学习视觉寻路，并在多种定位场景中评估。
