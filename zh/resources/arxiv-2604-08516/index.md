# MolmoWeb: Open Visual Web Agent and Open Data for the Open Web

提出 MolmoWebMix，整合合成浏览器轨迹、人工演示和 GUI 感知数据，并据此训练 MolmoWeb 截图到操作策略；还在浏览器基准上测试并行运行与 best-of-N 选择。
