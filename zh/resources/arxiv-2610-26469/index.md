# VeriCUA: Learning Proactive Verification for Reliable GUI Agent Rewards

VeriCUA 训练 Judge 选择验证检查项并决定何时停止，由冻结的 Probe 检查任务完成后的 GUI。单次尝试的强化学习兼顾判定正确性与 Probe 使用量。
