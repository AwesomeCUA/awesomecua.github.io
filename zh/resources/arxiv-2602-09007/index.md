# GUI-GenBench: Evaluating Image Generation Models as Interactive GUI Environments

GUI-GenBench 通过涵盖状态转换、轨迹和定位等内容的 5 组测试，评估图像生成模型作为依动作变化的 GUI 环境的能力；其基于 VLM 的 GUI-Score 分别衡量目标完成、交互逻辑、一致性和视觉属性。
