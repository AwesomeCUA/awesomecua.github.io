# WebMall -- A Multi-Shop Benchmark for Evaluating Web Agents

WebMall 提供 4 家产品数据各异的模拟网店，用于比价购物、相关商品搜索和结账任务；在固定的离线环境中，评估采用不同观察格式与记忆配置的网页智能体。
