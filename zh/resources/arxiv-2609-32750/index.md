# CUA-Sandbox: Efficient Environments for Computer-Use Agent Reinforcement Learning

CUA-Sandbox 将每次运行中可变的状态与共享的已初始化软件运行环境分离。按状态隔离的执行，以及事务式重置或分支，旨在保留原有界面和评估器的同时降低训练环境成本。
