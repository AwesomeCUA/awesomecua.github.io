# ILuvUI: Instruction-tuned LangUage-Vision modeling of UIs from Machine Conversations

ILuvUI 生成 335,000 条与 UI 截图配对的对话训练样本，涵盖提问、描述和计划；所得视觉语言模型从元素检测、回答质量和多步 UI 导航示例三个方面接受评估。
