# MAGA: Multi-Platform Self-Fusion of GUI Agents via Structured Action Distillation

MAGA 按结构化动作的正确性分配监督信号，将专用 GUI 智能体蒸馏为单一策略。仅在训练时使用的教师提示支持跨移动端、网页和桌面环境融合，且不改变学生模型的输入。
