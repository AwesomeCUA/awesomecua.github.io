## 范围记录

UiPath describes Screen Agent as the agentic framework behind the ScreenPlay activity in UiPath Studio and Studio Web: a planner turns intent into high-level action sequences, and a targeter that combines a grounder with UiPath's AI Computer Vision resolves pixel coordinates before acting; ScreenPlay adds AI-based DOM extraction. The installation guide offers out-of-the-box Screen Agent variants with Gemini 2.5 Flash, GPT-4.1, GPT-4.1 mini, GPT-5 and GPT-5 mini, as well as OpenAI Operator and Anthropic computer use, or bring-your-own-model connections to Azure OpenAI, OpenAI, Amazon Bedrock, Google Vertex or an OpenAI V1-compatible provider. The product page says credentials are managed through UiPath Orchestrator and that ScreenPlay resists prompt-injection attacks. UiPath's January 2026 press release and blog report a 67.1% OSWorld-Verified score for the Claude Opus 4.5 variant, then ranked first, and the blog says UiPath also evaluates Screen Agent on its UI-CUBE benchmark; these are publisher statements.
