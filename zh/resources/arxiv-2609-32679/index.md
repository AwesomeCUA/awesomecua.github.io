# The GUI Is Not the State: Diagnosing State Aliasing in GUI World Models

StateAliasBench 用于区分 GUI 世界模型中的歧义：相同的可见画面和操作可能导致不同的后续状态。研究为冻结的世界模型补充从交互历史恢复的结构化状态，并评估其对预测和智能体执行的影响。
