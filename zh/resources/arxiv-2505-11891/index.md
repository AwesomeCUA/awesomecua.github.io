# Mobile-Bench-v2: A More Realistic and Comprehensive Benchmark for VLM-based Mobile Agents

Mobile-Bench-v2 通过多条可接受的离线操作路径、含广告或弹窗的干扰界面，以及带脚本化澄清交互的模糊指令，评估移动端 GUI 智能体。这些任务划分分别考察步骤级执行、抗干扰能力和主动交互。
