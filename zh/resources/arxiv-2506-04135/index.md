# macOSWorld: A Multilingual Interactive Benchmark for GUI Agents

macOSWorld 涵盖 30 个应用中的 202 项交互任务，指令和操作系统界面提供 5 种语言，用于评估 GUI 智能体在 macOS 上的工作流程，并设有单独的欺骗攻击测试子集。
