# MMBench-GUI: Hierarchical Multi-Platform Evaluation Framework for GUI Agents

MMBench-GUI 在 6 个明确指定的桌面、移动和网页平台上评估界面理解、元素定位、任务自动化与协作，并提出 Efficiency-Quality Area 指标，同时考察在线 GUI 自动化的执行效率和任务质量。
