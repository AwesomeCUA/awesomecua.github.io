# ARPO:End-to-End Policy Optimization for GUI Agents with Experience Replay

ARPO 在组相对策略优化中加入回放缓冲区，跨训练迭代复用成功的 GUI 轨迹；它依据基线表现筛选任务，并在 OSWorld 上比较端到端强化学习与离线偏好优化。
