## 范围记录

The documentation describes a task as a reusable automation graph. Its Agent Action node handles browser steps (navigating, clicking, filling forms, scrolling, extracting) from a natural-language prompt, can also call integrations and inspect captured network requests, and accepts screenshots as visual references. A task can be trained from a narrated screen or tab recording of up to five minutes, which Komos turns into a plan, or built step by step in a visual builder. Runs use a fresh or persistent cloud Chromium sandbox on Daytona compute, or a self-hosted runner on a Windows or macOS host that can reuse SSO sessions; the Chrome extension path is retired. The built-in assistant Moss creates, schedules and debugs tasks from chat and is also reachable from coding agents through an MCP server. The agent's model is unspecified.
