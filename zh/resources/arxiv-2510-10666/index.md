# BrowserAgent: Building Web Agents with Human-Inspired Web Browsing Actions

BrowserAgent 经过训练，可在信息查找任务中基于 Playwright 直接滚动、点击网页并输入文字。训练结合监督微调与拒绝采样微调，并用显式记忆跨步骤保留结论。
