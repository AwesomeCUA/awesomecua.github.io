# VisionTasker: Mobile Task Automation Using Vision Based UI Understanding and LLM Task Planning

VisionTasker 将截图转为 UI 的文本解释，每次向 LLM 规划器呈现 1 个界面以选择动作；研究评估视觉表示以及在 Android 手机上执行 147 项任务的情况，其中包括与示教编程的结合。
