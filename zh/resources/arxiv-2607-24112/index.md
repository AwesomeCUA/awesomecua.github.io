# Scaling GUI Agents with Visual State Transitions

状态转换预训练同时学习根据 GUI 变化推断操作，以及根据当前屏幕和操作预测未来状态。随后通过指令轨迹微调，测试这些表征能否迁移到桌面和移动端智能体任务。
