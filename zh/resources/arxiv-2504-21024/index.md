# WebEvolver: Enhancing Web Agent Self-Improvement with Coevolving World Model

WebEvolver 训练协同演进的世界模型，用于预测网页观测并生成额外的智能体训练轨迹。同一模型还支持推理时的前瞻动作选择，并在实时网页任务基准上接受评估。
