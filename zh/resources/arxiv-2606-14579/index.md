# VISTA: View-Consistent Self-Verified Training for GUI Grounding

VISTA 对同一 GUI 实例裁剪出保留目标的视图，并精确映射目标框，以构建 GRPO 比较组。条件式、按优势加权的跨视图锚点提供额外监督，但不参与组基线计算；评估还涵盖视图一致性下的抗扰性。
