# TongUI: Internet-Scale Trajectories from Multimodal Web Tutorials for Generalized GUI Agents

TongUI 将视频、文章等多模态在线教程转化为 GUI 智能体轨迹。其 GUI-Net 数据集包含 143,000 条轨迹，覆盖 5 种操作系统和 200 多款应用，可用于定位与导航微调。
