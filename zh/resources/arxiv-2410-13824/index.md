# Harnessing Webpage UIs for Text-Rich Visual Understanding

通过网页无障碍树生成指令，并与截图配对，构建用于多模态训练的 MultiUI；评估网页界面理解能力，包括 VisualWebBench 和 Mind2Web，以及向其他富文本视觉任务的迁移。
