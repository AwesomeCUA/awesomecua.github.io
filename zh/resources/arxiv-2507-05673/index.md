# R-VLM: Region-Aware Vision Language Model for Precise GUI Grounding

R-VLM 通过放大的候选区域和考虑交并比的训练目标定位 GUI 元素；在 ScreenSpot 和 AgentStudio 上评估定位模型，并研究其对 AITW 和 Mind2Web 导航任务的影响。
