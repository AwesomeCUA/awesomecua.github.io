## 范围记录

The overview describes MobileUseAgent, an Android agent built for Wuying Cloud Phone that parses the native Android control tree, joined to the OpenClaw agent framework, with Qwen models for screen perception and instruction understanding; it also lists social-app engagement that imitates human behavior to avoid platform risk controls as a use case. The quick-start page, reached from the discovered URL whose cloud-phone-mobileclaw slug now redirects to cloud-phone-jvs-mobile, calls the service a public beta sold as monthly node plans with credits for model use, and sends tasks to the OpenClaw agent from a chat page. The X-PLUG/MobileAgent README announces Mobile-Agent-v3.5 on Wuying Cloud Phone and links that page; the linked Alibaba Cloud pages leave the Mobile-Agent-v3.5 name unstated. Receipts use the Markdown exports of the help pages because their HTML embeds a per-request tracking ID.
