# Visual Test-time Scaling for GUI Agent Grounding

RegionFocus 通过放大选定的截图区域，并维护基于图像的地标与动作地图，增加视觉测试时计算。在 ScreenSpot-Pro 和 WebVoyager 上使用 UI-TARS 与 Qwen2.5-VL 评估这一定位方法。
