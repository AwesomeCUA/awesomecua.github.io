# LocalLSTC: A Long Short-Term Control Architecture for Locally Deployed GUI Agents

LocalLSTC 是一种无需训练的控制架构，为本地部署的桌面智能体维护持续更新的任务状态，据此制定短期执行计划，并将执行结果反馈到状态中，用于检查进度、恢复执行和决定终止。
