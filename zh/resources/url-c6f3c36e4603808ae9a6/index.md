## 范围记录

The homepage targets payer-portal and EHR workflows and says every run executes in a VM with laptop-like fingerprints and human-like input, with queued concurrency, video replay, per-action screenshots and logs, and HIPAA-compliant infrastructure. The documentation says the builder agent opens a live browser preview, navigates the target site, asks clarifying questions and turns confirmed actions into a node-and-edge graph that later runs deterministically, with model calls confined to building the graph. Click nodes target elements either by XPath or through an LLM vision mode labelled AI (Screenshot). The maintenance agent classifies failures from the error screenshot, page state and selector signals, then recovers in place, asks for input, retries or hands the workflow to the builder agent. Citrix virtual desktops are automated through their HTML5 browser client using the screenshot mode. Runs start through an API with TypeScript and Python SDKs.
