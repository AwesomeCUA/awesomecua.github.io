# UI-Genie: A Self-Improving Approach for Iteratively Boosting MLLM-based Mobile GUI Agents

UI-Genie 共同改进移动 GUI 智能体与奖励模型；后者结合截图和交互历史提供动作级与任务级反馈。其数据流程利用规则验证、受损轨迹和困难负例，支持奖励引导的探索与迭代训练。
