## 范围记录

The homepage presents Beam as compute for agents: persistent, forkable microVMs that pause and resume, alongside GPU inference endpoints, task queues and sandboxes, and an MCP server whose tools create VMs, run commands and take screenshots, click and type on the desktop. The VM documentation says the default VM runs Ubuntu 24.04 with 4 CPUs and 8 GiB RAM, that `beam vm new` adds a desktop to fresh images, and that VMs are CPU-only. The desktop documentation covers screenshots, display resizing, mouse moves, clicks, X11 key presses, pasted text, scrolling, dragging, launching GUI programs and recording the guest screen from Python, JavaScript and the CLI; the desktop browser is Chrome on x86-64 and Firefox on ARM64. The homepage footer links the beam-cloud/beta9 repository (serverless GPU inference, sandboxes and background jobs, AGPL-3.0 per the GitHub API); whether it contains the VM desktop was not checked.
