# MANA: Towards Efficient Mobile Ad Detection via Multimodal Agentic UI Navigation

MANA 结合视觉、时间和探索信号，引导导航寻找移动端广告。在商用智能手机上评估广告检测效果和交互成本，包括经过混淆处理的广告。
