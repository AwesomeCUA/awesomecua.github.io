# When and What to Teach: Budget-Aware Online Adaptation for Web Agents

提出在线教学框架，决定哪些网页智能体任务过程需要更强的教师模型，以及轨迹中的哪些步骤值得用于训练；通过可解性筛选和按分数指导的裁剪，力求在降低教学与训练成本的同时保持初次尝试的表现。
