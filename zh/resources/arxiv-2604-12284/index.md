# WebAgentGuard: A Reasoning-Driven Guard Model for Detecting Prompt Injection Attacks in Web Agents

WebAgentGuard 通过并行的多模态防护模型，将提示注入检测与执行任务的网页智能体分开；该模型使用合成视觉和文本样本，先进行侧重推理的监督微调，再进行强化学习。
