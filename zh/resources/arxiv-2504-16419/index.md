# PixelWeb: The First Web GUI Dataset with Pixel-Wise Labels

提出网页 GUI 数据集 PixelWeb，包含元素图像、轮廓和像素掩码。其标注流程结合位图通道信息与基于 DOM 的可见性和层叠分析，处理遮挡和元素重叠。
