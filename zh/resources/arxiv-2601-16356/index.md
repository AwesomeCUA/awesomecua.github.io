# The Behavioral Fabric of LLM-Powered GUI Agents: Human Values and Interaction Outcomes

提出受控网页任务测试环境，研究明确表达的偏好和人的价值观如何影响 GUI 智能体决策；分析不同角色设定对导航的影响，以及醒目的界面线索如何盖过预期的偏好指引。
