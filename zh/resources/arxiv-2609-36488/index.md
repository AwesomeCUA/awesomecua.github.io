# AdaptArena: Evaluating Test-Time Personalization of Web Agents

AdaptArena 测试网页智能体能否从相关历史轨迹推断未明说的用户偏好，并将其用于新任务。其 AdaptiveAgent 基线将偏好检索难题与后续网页执行失败区分开来。
