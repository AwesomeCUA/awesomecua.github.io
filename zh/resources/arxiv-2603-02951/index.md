# CGL: Advancing Continual GUI Learning via Reinforcement Fine-Tuning

结合监督微调与强化微调进行持续 GUI 学习，利用策略熵调整两者比例，并通过梯度投影减少相互冲突的更新；AndroidControl-CL 将应用组织为顺序任务，以评估适应与保持能力。
