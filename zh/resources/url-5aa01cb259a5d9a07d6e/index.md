## 范围记录

The terms of service name Starizon Ltd as the provider of the website, browser extension and related services. Agent S6 navigates, clicks, types and fills in forms in the browser session the user is already signed in to; it stops for confirmations, sign-ins, choices between options and blocked pages, and waits for the user before irreversible actions such as submitting or paying. Chat history, the Knowledge Base and Spaces are stored in the browser profile, while prompts and task context, including page screenshots when browser actions need them, go to the chosen model service or to the user's own API key.
