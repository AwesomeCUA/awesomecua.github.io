# PrecogUI: Proactive GUI Agents via Pre-cognitive Simulation and Experience Retrieval

PrecogUI 检索以往的异常和成功模式，在选择操作前预测符号化 UI 状态转移。研究还构建 InterfereBench，用于评估存在干扰事件和恢复要求的长程 GUI 工作流程。
