# Action Conditioned Bisimulation For GUI Agent Memory

该研究定义 GUI 记忆合并规则：只有共同操作产生相符的结果和后继状态，两个状态才视为等价。该免训练方法替代基于观察相似性的合并，并在 MiniWoB++ 闭环交互中测试。
