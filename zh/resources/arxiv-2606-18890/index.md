# Skill-Guided Continuation Distillation for GUI Agents

Skill-Guided Continuation Distillation 先让策略到达自身产生的轨迹偏离状态，再借助技能指导收集成功的后续轨迹。将这些后续轨迹与专家轨迹混合，为演示中缺失的恢复状态提供监督。
