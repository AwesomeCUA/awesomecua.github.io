# RealWebAssist: A Benchmark for Long-Horizon Web Assistance with Real-World Users

RealWebAssist 以真实用户在多个网站上的连续指令评估网页辅助能力，测试智能体在指令含糊或交互中变化时对意图、用户特定流程、长期上下文和视觉定位的处理。
