# MintAct: A Unified Visual Agent for Digital Environments

MintAct 训练一组视觉智能体，处理移动端、桌面和网页环境中的定位、导航与工具使用。其共享基础设施支持轨迹收集和异步在线 RL，同时控制跨领域采样与离策略偏移。
