# PriMobiBench: Characterizing Visual Privacy Leakage in VLM-Driven Mobile GUI Agents

PriMobiBench 借助 MobiLeak 轨迹数据集，评估移动端 GUI 截图轨迹造成的直接隐私泄露和用户画像。它还测试在云端处理前遮蔽与任务无关的敏感界面元素，并衡量隐私与效用之间的权衡。
