# DAVE: A VLM Vision Encoder for Document Understanding and Web Agents

DAVE 通过自监督预训练及后续的有监督解析和定位，为文档图像与网页智能体训练视觉编码器。它结合针对不同解码器的编码器合并与特征融合，并评估网页定位、智能体基准和文档任务。
