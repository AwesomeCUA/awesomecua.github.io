# AndroidDaily: A Verifiable Benchmark for Mobile GUI Agents on Real-World Closed-Source Applications

AndroidDaily 评估移动 GUI 智能体在闭源 Android 应用中的日常工作流程。GRADE 根据视觉轨迹检查操作要求、输出质量要求和禁止事项，无需访问隐藏应用状态即可提供过程级诊断。
