# MobiBench: Multi-Branch, Modular Benchmark for Mobile GUI Agents

MobiBench 允许多条有效操作路径，对移动端 GUI 智能体进行离线评估。它将智能体流程拆分为模块，以研究各组件的作用、配置和性能瓶颈。
