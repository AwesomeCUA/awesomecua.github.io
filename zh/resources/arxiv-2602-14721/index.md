# WebWorld: A Large-Scale World Model for Web Agent Training

WebWorld 是基于交互轨迹训练的开放网页模拟器，用于生成智能体训练数据并测试候选动作；WebWorld-Bench 评估模拟的状态转换，论文还开展下游网页智能体训练实验。
