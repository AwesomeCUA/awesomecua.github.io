# StepReflect: Structured UI Transition Reflection for Mobile GUI Agents

StepReflect 根据状态转换规范和成对的视觉证据，预测每个动作的结构化反思；并区分离线状态转换标签准确率与反思模型接入移动端智能体后的在线任务成功率。
