# SafeGround: Know When to Trust GUI Grounding Models via Uncertainty Calibration

SafeGround 根据采样预测结果的空间离散程度估计 GUI 定位的不确定性，并在测试前校准决策阈值；在 ScreenSpot-Pro 上研究风险感知的选择，统计控制仅针对该阈值的错误发现率。
