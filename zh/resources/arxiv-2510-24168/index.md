# MGA: Memory-Driven GUI Agent for Observation-Centric Interaction

MGA 将与任务无关的屏幕状态读取和决策分开，并用结构化状态记忆连接各步骤。经核验的状态变化取代完整轨迹回放，方法在 OSWorld 和应用任务上评估。
