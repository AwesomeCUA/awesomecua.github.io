# MIRAGE: Stealthy Visual Prompt Injection for Vulnerability Detection in Web Agents

MIRAGE 评估将对抗图像限制在合法第三方网页区域时，针对智能体下一步操作的劫持。它结合基于扩散的图像生成与考虑执行过程的优化，并在网页智能体框架上测试这一受约束的视觉注入场景。
