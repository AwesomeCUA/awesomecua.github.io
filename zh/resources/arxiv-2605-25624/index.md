# CUA-Gym: Scaling Verifiable Training Environments and Tasks for Computer-Use Agents

CUA-Gym 通过生成器与判别器的迭代，共同生成指令、初始与目标状态及可执行的奖励检查。模拟网页应用扩展了训练环境，并在 OSWorld-Verified 和 WebArena 上评估训练所得的智能体。
