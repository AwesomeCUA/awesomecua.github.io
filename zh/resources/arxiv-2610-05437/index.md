# TeleTune: Evolving Agent Skills From Offline Telemetry

提出 TeleTune，利用目标缺失或任务交错的软件操作离线日志，通过留出数据上的动作预测来编辑文本技能库。学得的工作流程还用于指导后续网页智能体执行时检索示范。
