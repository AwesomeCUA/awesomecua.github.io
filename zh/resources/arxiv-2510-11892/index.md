# R-WoM: Retrieval-augmented World Model For Computer-use Agents

R-WoM 评估世界模型预测邻近 GUI 状态、对齐完整流程和识别里程碑转换的能力。它检索外部教程以指导未来交互的模拟，并在 OSWorld 和 WebArena 的子集上实验。
