# WEBSERV: A Full-Stack and RL-Ready Web Environment for Training Web Agents at Scale

WebServ 结合写时复制容器环境与基于 DOM 的紧凑浏览器接口，用于训练网页智能体。感知网络状态的等待机制支持单页应用中的操作执行，研究在 WebArena-Lite 上进行评估和强化学习实验。
