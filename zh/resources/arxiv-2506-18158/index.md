# Chain-of-Memory: Enhancing GUI Agents for Cross-Application Navigation

Chain-of-Memory 在短期和长期记忆中明确记录操作描述与任务相关的界面信息，用于 GUI 导航；GUI Odyssey-CoM 提供 111,000 组带记忆标注的界面与操作配对数据，用于学习和评估跨应用的信息保留能力。
