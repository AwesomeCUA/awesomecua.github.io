# VISUALSKILL: Multimodal Skills for Computer-Use Agents

VISUALSKILL 将应用专属文本和图示组织为层级技能，并通过 MCP 工具按需检索。技能结合编写的文档与实时 UI 探索；配对的多模态与纯文本对比测试其在界面识别和工作流状态核验中的用途。
