# ENVS: Environment-Native Verified Search for Long-Horizon GUI Agents

ENVS 在实时桌面虚拟机中探索 GUI 操作分支，验证成功的终点，并将其转化为均衡的步骤级训练监督。它还提出 OSWorld-Noisy，在保留原任务的同时测试动态中断后的恢复。
