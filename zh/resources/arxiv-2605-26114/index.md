# MobileGym: A Verifiable and Highly Parallel Simulation Platform for Mobile GUI Agent Research

MobileGym 是在浏览器中运行的移动应用交互模拟平台，可配置的 JSON 状态支持确定性评判和并行采样。MobileGym-Bench 提供参数化任务，实验考察在线训练及向真实设备的迁移。
