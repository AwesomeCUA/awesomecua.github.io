# BacktrackAgent: Enhancing GUI Agent with Error Detection and Backtracking Mechanism

BacktrackAgent 增加验证、判断和反思模块，以检测错误 GUI 操作并指导恢复；它构建包含操作后页面的回退训练数据，并在 Mobile3M 和 Auto-UI 上评估任务完成情况及步骤准确率。
