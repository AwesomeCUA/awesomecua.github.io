# ReuseDroid: A VLM-empowered Android UI Test Migrator Boosted by Active Feedback

ReuseDroid 利用 VLM 智能体区分共通测试意图与应用特有的交互流程，在功能相似的应用之间迁移 Android GUI 测试；并提出涵盖 39 个应用、578 项迁移任务的 LinPro 数据集用于评估测试迁移。
