# ProgRM: Build Better GUI Agents with Progress Rewards

ProgRM 预测任务在每一步的完成进度，为在线训练 GUI 智能体提供中间奖励；它用最长公共子序列识别轨迹关键步骤并生成进度标签，使最终失败的轨迹中的有效部分进展也能发挥作用。
