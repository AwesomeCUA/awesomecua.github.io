# SusBench: An Online Benchmark for Evaluating Dark Pattern Susceptibility of Computer-Use Agents

SusBench 是一个在线基准，在消费类网站中插入暗黑模式设计以评估智能体。人工研究检查干预的真实感，智能体实验则比较其对不同模式类型的易受影响程度。
