# VenusBench-GD: A Comprehensive Multi-Platform GUI Benchmark for Diverse Grounding Tasks

VenusBench-GD 是按基础和进阶任务组织的双语跨平台 GUI 定位基准。其标注流程和 6 项子任务分类支持比较通用多模态模型与 GUI 专用模型在不同定位需求下的表现。
