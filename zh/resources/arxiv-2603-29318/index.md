# PSPA-Bench: A Personalized Benchmark for Smartphone GUI Agent

PSPA-Bench 利用针对特定用户的指令，并结合对交互轨迹的过程评估，衡量智能手机 GUI 智能体的个性化行为。其智能体比较分析对工作流和偏好适应的不足。
