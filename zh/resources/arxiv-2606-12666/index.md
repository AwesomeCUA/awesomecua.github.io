# CAPED: Context-Aware Privacy Exposure Defense for Mobile GUI Agents

CAPED 结合任务需求、屏幕上下文和解析出的 UI 元素，在上传前遮盖手机截图中与任务无关的隐私内容。通过 AndroidWorld 和受控的预设隐私评估，考察信息泄露减少情况、任务效用及原型成本。
