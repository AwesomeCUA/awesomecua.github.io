# MCPWorld: A Unified Benchmarking Testbed for API, GUI, and Hybrid Computer Use Agents

MCPWorld 在源码可插桩且可扩展 MCP 支持的应用中设置 201 项任务，评估 API、GUI 及混合式计算机使用智能体；它根据应用行为核验任务完成情况，并提供支持 GPU 的容器化测试环境。
