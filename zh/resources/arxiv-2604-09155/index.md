# CORA: Conformal Risk-Controlled Agents for Safeguarded Mobile GUI Automation

CORA 通过校准风险模型，决定执行还是拒绝移动端 GUI 操作，并诊断被拒绝的操作以建议干预措施。Phone-Harm 提供步骤级安全标签，用于评估这一防护流程。
