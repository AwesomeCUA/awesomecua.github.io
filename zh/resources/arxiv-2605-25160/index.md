# ScaleWoB: Guiding GUI Agents with Coding Agents via Large-Scale Environmental Synthesis

ScaleWoB 将交互式 GUI 环境合成为无需后端、奖励可验证的网页。其面向移动端的基准评估智能体执行情况，并将部分合成任务与真实应用中的行为作比较。
