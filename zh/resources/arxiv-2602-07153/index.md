# ANCHOR: Branch-Point Data Generation for GUI Agents

ANCHOR 在有意义的分支点生成新任务并执行任务指令，以扩充经验证的桌面操作演示；通过状态感知验证和动作过滤优化所得轨迹，并用微调后的智能体在 OSWorld 和 WindowsAgentArena 上评估。
