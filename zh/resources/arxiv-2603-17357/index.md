# WebPII: Benchmarking Visual PII Detection for Computer-Use Agents

WebPII 提供合成电商截图，并对敏感信息作细粒度标注，包括部分填写的表单和交易标识符；还训练 WebRedact 检测视觉 PII，作为计算机使用智能体的隐私保护组件。
