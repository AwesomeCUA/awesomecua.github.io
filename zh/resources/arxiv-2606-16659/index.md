# FraudSMSWalker: Benchmarking Agentic Large Language Models for SMS-to-Webpage Fraud Detection

FraudSMSWalker 在隐藏 URL 和信誉捷径的条件下，测试浏览器智能体对双语短信及其链接网页的欺诈判断。受控链条包含难以判别的正常登录和支付案例，并评估分类是否有可见短信与网页证据支持。
