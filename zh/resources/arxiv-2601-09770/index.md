# GUI-Eyes: Tool-Augmented Perception for Visual Grounding in GUI Agents

GUI-Eyes 训练 GUI 定位模型判断何时以及如何使用裁剪、放大等视觉工具。其由粗到细的策略采用基于位置接近度和区域重叠的密集空间奖励，并在 ScreenSpot-Pro 上评估。
