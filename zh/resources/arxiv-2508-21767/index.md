# UItron: Foundational GUI Agent with Advanced Perception and Planning

UItron 结合 GUI 感知与规划的数据构建、监督训练和课程强化学习，在互联的移动端及 PC 环境中训练；还收集了 100 款中国应用中超过 100 万步操作，并构建离线和在线评估环境。
