## 常见问题

### Awesome CUA 是什么？

Awesome CUA 是面向计算机使用、GUI、网页和移动端智能体的资源目录，已审核 5,347 条论文、模型、数据集、评测基准、智能体、框架、工具与产品，每条都链接一手来源。

### 目录收录了多少资源？

已审核 5,347 条：论文与综述 1,718 篇，其他资源 3,629 条，其中评测基准 309 个、数据集 278 个、模型 475 个、智能体 479 个、框架 672 个、工具 1,162 个。另有 1,201 条仅有元数据的书目记录和 190 条扫描发现单独列出。

### 每条记录如何审核？

审核者阅读一手来源（论文、代码仓库、模型卡或项目主页），记录证据、审核日期，并分别记录代码、数据、权重和文档许可证，未知信息保留为空。详见[编辑方法](https://awesomecua.com/about/)。

### 如何用代码读取目录？

克隆 GitHub 仓库，下载 [catalog.jsonl](https://awesomecua.com/downloads/catalog.jsonl)，或调用 [/api/v1/ JSON 接口](https://awesomecua.com/api/)。每个页面在 index.md 提供 Markdown 版本，[llms.txt](https://awesomecua.com/llms.txt) 列出全部入口。

### 目录多久更新一次？

发现扫描每 8 小时运行一次，最近一次在 2026-11-14。详见[更新记录](https://awesomecua.com/updates/)。

### 如何引用 Awesome CUA？

使用 GitHub 仓库中的 CITATION.cff，或复制 [AGENTS.md](https://awesomecua.com/AGENTS.md) 中的 BibTeX。
