# 计算机使用智能体评测基准：第 3 页

- [GroundUI-18K](https://awesomecua.com/zh/resources/url-d206aacf01e1b7dc786d/)：AgentStudio 的完整 GUI 元素定位测试集，汇集 Mind2Web、OmniACT、MoTIF、ScreenSpot 和 AgentStudio 的网页、桌面及移动端截图，含 18,026 条指令与目标边界框样例。
- [GUI-Robust](https://awesomecua.com/zh/resources/github-chessbean1-gui-robust/)：提供评估脚本和关联数据，用于比较普通及异常界面条件下的 GUI 操作预测和任务执行。
- [GuideBench](https://awesomecua.com/zh/resources/url-37b4f525e6d7a56a9967/)：GUIDE 基准发布的数据：来自 10 款应用的新手口述屏幕录像的标注片段，用于预测用户行为状态、短期意图，以及是否提供帮助和如何帮助。
- [GUIGuard-Bench evaluation code](https://awesomecua.com/zh/resources/github-shaluoyan523-guiguard-bench/)：GUIGuard-Bench 评估代码涵盖隐私区域识别评分、基于 LLM 评判的遮挡截图规划一致性，以及受保护界面的点击定位，并附少量 Android 和 PC 示例。
- [GUIHalluBench](https://awesomecua.com/zh/resources/github-ant-research-guihallubench/)：将模型列出的界面元素边界框和描述与人工标注比对，衡量其解析 1,000 张英文和 1,000 张中文截图时的幻觉。
- [GUITestBench](https://awesomecua.com/zh/resources/github-adam-bjtu-guitestbench/)：GUITestBench 评测安卓智能体能否通过多步操作发现应用缺陷，并结合导航与触发条件检查及评判模型进行评估。
- [HealthEnv](https://awesomecua.com/zh/resources/github-possibleme2026-lang-healthenv/)：HealthEnv 将纵向临床问答任务编译为有状态、可验证的计算机使用评测环境。
- [HoloSkill Gym](https://awesomecua.com/zh/resources/github-elenaviewsynthesis-holoskill-gym/)：用于自我演进的 CLI 和计算机使用智能体技能的 Gym 环境与优化框架。
- [HumanQA](https://awesomecua.com/zh/resources/github-hotragn-humanqa/)：以证据为先的产品质量与 UX 评测测试框架，用于通过浏览器智能体测试网页应用。
- [hyprbench](https://awesomecua.com/zh/resources/github-crispwisp-hyprbench/)：hyprbench 是面向 Linux Hyprland Wayland 合成器、采用 OSWorld 风格的计算机使用评测基准，配有脚本化窗口管理验证器。
- [Inspect Evals](https://awesomecua.com/zh/resources/github-ukgovernmentbeis-inspect-evals/)：Inspect Evals 是面向 UK AISI Inspect 框架的社区评测基准套件，包含 OSWorld、GAIA、SWE-bench 以及网络安全和智能体评测。
- [Intention-in-Interaction (IN3) & Mistral-Interact](https://awesomecua.com/zh/resources/github-openbmb-tell-me-more/)：提供 Intention-in-Interaction (IN3) 评测基准和 Mistral-Interact 模型，用于在智能体任务中主动澄清用户意图。
- [Intentproof](https://awesomecua.com/zh/resources/github-egagofur-intentproof/)：由 AI 驱动的端到端验证编排工具和交互式浏览器测试框架。
- [iOSWorld](https://awesomecua.com/zh/resources/github-ljang0-iosworld/)：iOSWorld 是原生 iPhone 模拟器基准，包含共享用户数据、应用工作流程、智能体运行器和基于评分细则的评分。
- [jev-click-bench](https://awesomecua.com/zh/resources/github-arthurkatcher-jev-click-bench/)：jev-click-bench 使用官方评分方法和逐次点击日志，在 ScreenSpot-v2 和 ScreenSpot-Pro 上评测 Jev 1.14 的边界框定位。
- [Kane](https://awesomecua.com/zh/resources/github-venkat5599-kane/)：面向 AI 构建的网页应用的通俗英语浏览器验证测试框架，将 UI 故障报告给编码智能体。
- [Kernel Eval Protocol](https://awesomecua.com/zh/resources/github-kernel-kernel-eval-protocol-quickstart/)：使用 Eval Protocol、Kernel 云浏览器和可验证的任务评分器，评测并微调视觉语言浏览器智能体。
- [LAST DOOR](https://awesomecua.com/zh/resources/github-agentsimdev-last-door/)：认证韧性评测基准和 WebMCP 权限编译器，用于测试浏览器智能体在登录及权限边界处的行为。
- [LLM as a Judge for Computer-Use Agents](https://awesomecua.com/zh/resources/github-anaishowland-llm-judge-psai/)：LLM 充当评判者的评测测试框架，用于评估计算机使用智能体在网页浏览和桌面交互任务中的轨迹。
- [LongPuzzleBench](https://awesomecua.com/zh/resources/github-bingozhang-verapraxis-longpuzzlebench/)：LongPuzzleBench 通过需要多步骤空间推理的长时程视觉解谜游戏，评测 GUI 和计算机使用智能体。
- [LPS-Bench](https://awesomecua.com/zh/resources/github-tychenn-lps-bench/)：LPS-Bench 在良性及对抗性执行场景下，评测计算机使用智能体进行长程规划时的安全意识。
- [MacArena](https://awesomecua.com/zh/resources/github-macpaw-macarena/)：MacArena 在可复现的在线 macOS 虚拟机环境中，通过跨应用桌面任务评测计算机使用智能体。
- [MalURLBench](https://awesomecua.com/zh/resources/github-jiangyinger-malurlbench/)：MalURLBench 在 10 个真实网页场景中，评测基于 LLM 的网页智能体遭受网络钓鱼和恶意 URL 攻击时的脆弱性。
- [MarketBench](https://awesomecua.com/zh/resources/github-santos-sanz-marketbench/)：MarketBench 是可复现的 WebMCP 评测基准，用于评测浏览器智能体在模拟市场中跨数周的经济决策。
- [Maudslay](https://awesomecua.com/zh/resources/github-theo-ai-lab-maudslay/)：Maudslay 根据独立的后端和电子邮件真实结果，评测计算机使用智能体的发布就绪程度与 pass^k 可靠性。
- [MCPWorld](https://awesomecua.com/zh/resources/github-saagent-mcpworld/)：结合计算机交互与工具访问的评估环境。
- [MedSPOT](https://awesomecua.com/zh/resources/github-tajamul21-medspot/)：覆盖 10 款医学影像应用的连续式界面定位评测集，用于评估模型在多步骤工作流程中定位目标的能力，并提供评测脚本。
- [mimiq](https://awesomecua.com/zh/resources/github-gojiplus-mimiq/)：mimiq 是动态端到端智能体模拟和网页 UI 评测运行器，集成 Cypress、Playwright 和 Stagehand。
- [Mind2Web 2](https://awesomecua.com/zh/resources/github-osu-nlp-group-mind2web-2/)：长程智能体网页搜索基准，使用 Agent-as-a-Judge 框架评估随时间变化且有引文支持的答案，并提供开发集和测试集的评估脚本。
- [Mirage (Adversarial Web Benchmark)](https://awesomecua.com/zh/resources/github-shushant17711-mirage/)：受控的对抗性网页环境，用于衡量自主浏览器智能体如何在欺骗性 UI 和提示陷阱下失败。
- [MLA-Trust](https://awesomecua.com/zh/resources/github-thu-ml-mla-trust/)：统一评估框架，衡量多模态 LLM 智能体在交互式网页和移动 GUI 任务中的真实性、可控性、安全性与隐私表现。
- [MM-SafetyBench](https://awesomecua.com/zh/resources/github-ai45lab-mm-safetybench/)：MM-SafetyBench 在 13 种场景中，使用与查询相关的对抗性图像和排版安全提示评测多模态大语言模型。
- [MMInA](https://awesomecua.com/zh/resources/github-shulin16-mmina/)：基于 WebArena 环境的多模态网页任务，需在购物网站、Wikipedia 等站点间完成 1 至 10 跳的操作，用于测试长链推理。
- [MMSearch-Plus](https://awesomecua.com/zh/resources/github-mmsearch-plus-mmsearch-plus/)：面向多模态网页智能体的评测集，含 311 道需反复检索图像与文本的视觉推理任务；仓库链接数据集并提供加载辅助程序。
- [MobBench task definitions](https://awesomecua.com/zh/resources/url-b53e03a6e4ca4226d126/)：用于评估 MobA 的公开真机移动任务定义集，中文和英文任务材料以带版本号的 JSON 形式发布。
- [Mobile-Bench](https://awesomecua.com/zh/resources/github-xiaomi-mobilebench/)：Mobile-Bench 通过结合 UI 动作与 API 扩展、使用检查点指标的多步骤 Android 任务，评测基于 LLM 的移动端智能体。
- [Mobile-Eval-E task definitions](https://awesomecua.com/zh/resources/url-342b081c3668a8bbe155/)：用于 Mobile-Agent-E 长时程、跨应用 Android 评估的任务定义，以含 25 条记录的测试集形式提供，并附有评分标准和人工参考操作字符串。
- [MobileAgentBench](https://awesomecua.com/zh/resources/github-mobileagentbench-mobile-agent-bench/)：面向移动端 LLM 智能体的自动化基准，默认任务使用 10 个 Simple Mobile Tools Android 应用；作为 Python 库安装，并检测任务是否完成。
- [MobileBench-OL](https://awesomecua.com/zh/resources/github-xiaomi-research-mobilebench-ol/)：MobileBench-OL 提供在线评测测试框架，在真实 Android 设备上测试移动端 GUI 智能体，并动态验证任务。
- [MobileSafetyBench](https://awesomecua.com/zh/resources/github-jylee425-mobilesafetybench/)：MobileSafetyBench 是 Android 模拟器测试环境，借助 ADB 和 Appium 获取观察、执行操作并检查任务是否成功，同时评估移动设备控制智能体的安全性与有用性。
- [MobileWorldBench](https://awesomecua.com/zh/resources/github-jacklishufan-mobileworld/)：MobileWorldBench 是评估移动智能体语义世界建模的基准，包含问答任务和由 GPT 评判的生成任务，并提供基于 AitW 及 AndroidControl 屏幕构建的训练数据。
- [Nightshift](https://awesomecua.com/zh/resources/github-yayaq1-nightshift/)：运行于 Solari 的黑盒计算机使用质量检查测试框架，无需访问应用测试钩子即可评测实时用户界面。
- [OmniWebBench](https://awesomecua.com/zh/resources/github-fanxutherealone-omniwebbench/)：OmniWebBench 从端到端网页导航、动作执行、故障恢复和证据核验等方面评测智能体浏览器。
- [Open Operator Evals](https://awesomecua.com/zh/resources/github-nottelabs-open-operator-evals/)：Notte Labs 已归档的评测框架和结果，对 WebVoyager 的 30 项任务子集让网页智能体各运行八次，以 GPT-4o 截图评判器评分，并与智能体自报成功情况比较。
- [Open User](https://awesomecua.com/zh/resources/github-tiacoo-open-user/)：黑盒用户体验审查测试框架，派遣 AI 浏览器用户角色测试网页产品并记录障碍点。
- [OpenApps](https://awesomecua.com/zh/resources/github-facebookresearch-openapps/)：提供可配置的浏览器应用和任务奖励，用于测试计算机使用智能体在内容、布局和外观变化下的表现。
- [OS-Critic Bench](https://awesomecua.com/zh/resources/url-c73ba0618d1b3c505887/)：跨平台 GUI 评判基准，包含移动端、桌面端和网页的 JSONL 数据划分及截图资源，并附公开的推理与准确率评分脚本。
- [OS-Map](https://awesomecua.com/zh/resources/github-os-copilot-os-map/)：源自 OSWorld 的桌面基准，提供 Ubuntu 虚拟机环境和扩展的任务配置，用于衡量计算机交互的广度与深度。
- [OSReward](https://awesomecua.com/zh/resources/github-os-copilot-osreward/)：OSReward 的评估器与采集代码，检验 VLM 评判器对人工标注的计算机使用轨迹所给 SUCCESS/FAIL 结论，并提供网页、Windows、Android 和 Ubuntu 轨迹采集流水线。
- [OSUniverse](https://awesomecua.com/zh/resources/github-agentsea-osuniverse/)：OSUniverse 是面向任务的桌面评测基准，用于评测视觉驱动的多模态 GUI 导航智能体在操作系统应用中的表现。
- [OSWorld GPT-4o-mini Benchmark Evaluation](https://awesomecua.com/zh/resources/github-suraj-ranganath-osworld-gpt4o-mini-benchmark/)：在 OSWorld 桌面自动化任务上评测 GPT-4o-mini，对比仅截图、辅助功能树和 Set-of-Mark 三种观察模式。
- [OSWorld-Human](https://awesomecua.com/zh/resources/github-wuklab-osworld-human/)：提供人类参考轨迹和评分代码，用于衡量计算机使用智能体完成 OSWorld 任务时的操作效率。
- [OSWorld-Science](https://awesomecua.com/zh/resources/github-discoailab-osworld-science/)：在按领域划分的虚拟机中运行科学软件操作智能体，并通过任务专用的可执行评估器检查应用状态和交付成果的基准框架。
- [pantheon-webarena](https://awesomecua.com/zh/resources/github-pantheon-auto-pantheon-webarena/)：pantheon-webarena 将容器化 WebArena 环境与重置、健康检查和并行评测工具打包，供网页智能体使用。
- [Pathproof](https://awesomecua.com/zh/resources/github-mikulabc-pathproof/)：优先在本地运行的 AI 辅助网站回归问题发现套件，支持确定性的 Playwright 重放。
- [Persona UX Test](https://awesomecua.com/zh/resources/github-ericwong5021-persona-ux-test/)：使用仅通过渲染画面交互的隔离 AI 用户角色，对网页和桌面用户界面进行盲测。
- [pms-race](https://awesomecua.com/zh/resources/github-lgoyal6-pms-race/)：面向操作传统物业管理网页 UI 的计算机使用智能体的并发评测基准，用于衡量竞态条件和重复预订。
- [Pointerbench](https://awesomecua.com/zh/resources/github-warmwindos-pointerbench/)：Pointerbench 评测计算机使用模型能否根据指令在截图中定位目标，三个子集涵盖电子表格、文本和专业应用界面。
- [PoisonPage](https://awesomecua.com/zh/resources/github-redbotster-poisonpage/)：对抗性测试平台，展示针对 AI 购物网页智能体的间接提示词注入和 API 密钥外泄。
- [pptxgym (CUA-Gym.pptx)](https://awesomecua.com/zh/resources/github-lyt060814-cua-gym-pptx/)：从真实 PowerPoint 演示文稿中合成可验证的计算机使用强化学习任务，并对其评分。
- [Precision CUA Bench](https://awesomecua.com/zh/resources/github-microsoft-precision-cua-bench/)：用于评估代码编辑器中像素级精确光标定位的资源。
- [Preflight-Bench](https://awesomecua.com/zh/resources/github-multimodal-ai-engineering-preflight-bench/)：Preflight-Bench 评测计算机使用智能体在异步 UI 更新情况下的点击前过时状态检查和页面加载同步能力。
- [REFRACT-PPTX](https://awesomecua.com/zh/resources/github-haikong-lu1206-refract-pptx/)：面向可编辑 PowerPoint 演示文稿的智能体引导生成与多维视觉评测基准。
- [Resurf](https://awesomecua.com/zh/resources/github-lightfeed-resurf/)：Resurf 是确定性、可复现的测试环境，用于在真实的网页故障模式下评测 AI 浏览器智能体。
- [RLG-ALE](https://awesomecua.com/zh/resources/url-0596dd7e97fd30abaadc/)：RLG-ALE 用可检查的 Android 任务评估移动端图形界面智能体。页面展示了包含任务提示、截图、评估记录和可重置环境的示例过程。

- [SafeArena](https://awesomecua.com/zh/resources/github-mcgill-nlp-safearena/)：SafeArena 是将良性与有害任务配对、用于研究蓄意滥用风险的网页智能体基准。
- [Screen Point-and-Read / Tree-of-Lens](https://awesomecua.com/zh/resources/github-ucsb-ai-screen-point-and-read/)：提供屏幕阅读基准和 Tree-of-Lens 实现，用于理解用户指示的区域及其布局上下文。
- [ScreenLeak](https://awesomecua.com/zh/resources/github-screenpipe-screenleak/)：ScreenLeak 是多模态评测基准，用于衡量连续屏幕录制数据中的敏感信息检测和个人身份信息脱敏。
- [SCUBA (Salesforce Computer Use Benchmark)](https://awesomecua.com/zh/resources/github-salesforceairesearch-scuba/)：SCUBA 在企业 Salesforce CRM 工作流上评测计算机使用智能体，涵盖管理员配置、销售运营和服务任务。
- [showdown-clicks](https://awesomecua.com/zh/resources/url-863cc1744cd5d40418be/)：General Agents 的离线点击基准：557 次 macOS 截图上的人工左键点击，分别配有指令和有效点击位置边界框，以预测点是否落框评分。
- [Simulation Labs](https://awesomecua.com/zh/resources/github-satyamdave-simulation-labs/)：行为 CI 关卡，让计算机使用智能体在每次部署时测试注册、结账和新用户引导流程。
- [SMAN-Bench](https://awesomecua.com/zh/resources/github-gezelligheid0314-sman-bench/)：SMAN-Bench（Mobile-Bench-v2）评估代码：AppAgent 和 Mobile-Agent-v2 运行器重放录制的 Android 页面，执行单路径、多路径、含噪和模糊任务，以步骤和任务成功率评分。

- [SWE-bench Multimodal](https://awesomecua.com/zh/resources/url-cb7f3bdb832d533c96b0/)：针对视觉 JavaScript 和 TypeScript 软件的问题解决基准；每项任务的问题描述或补丁包含截图、设计稿或渲染图，并用仓库单元测试检查修复结果。

- [TestPilot](https://awesomecua.com/zh/resources/github-h0ngza1-testpilot/)：智能体驱动的端到端网页测试平台，在实时浏览器中执行自然语言测试用例。
