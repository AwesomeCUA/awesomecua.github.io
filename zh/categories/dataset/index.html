计算机使用智能体数据集

计算机使用数据集提供截图、指令、界面元素标注和动作轨迹，用于训练或评估 GUI 智能体。监督信号从单个元素的定位到完整的多步轨迹不等。目录收录 278 条已审核数据集，每条都链接到一手证据。

常见问题

目录中被提及最多的数据集有哪些？

ScreenSpot-Pro data（12 条记录）、OS-Genesis（11 条记录）和 AMEX dataset release（7 条记录）在其他目录记录的已审核来源中被提及最多。

这些数据集覆盖哪些平台？

在 278 条已审核数据集中，网页 122 条、桌面 78 条、手机 74 条、跨平台 34 条；36 条未记录平台。标注多个平台的条目在每个平台下各计一次。

哪些数据集记录了监督信号和规模？

278 条数据集中有 125 条附有数据集档案，记录监督信号、模态、格式、划分以及带单位的计数。最常见的监督信号是 element grounding（6 条）、agent-generated trajectories（5 条）和 interaction trajectories（4 条）。数据集对比页可逐项比较。

数据集使用哪些许可证？

最常见的声明许可证是 Apache-2.0（72 条）、MIT（45 条）和 CC-BY-4.0（35 条）。278 条中有 90 条未记录声明的许可证。

这个列表按什么排序？

按在已审核来源中提及该条目的目录记录数排序，多者在前，数量相同时按名称排序。列表上方的排序菜单可切换为 A–Z。
