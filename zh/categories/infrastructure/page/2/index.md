# 计算机使用智能体基础设施：第 2 页

HTML 页面：https://awesomecua.com/zh/categories/infrastructure/page/2/ · [English](https://awesomecua.com/categories/infrastructure/page/2/index.md)

完整类别注释：https://awesomecua.com/zh/categories/infrastructure/index.md

- [Latere Sandbox Images](https://awesomecua.com/zh/resources/github-latere-ai-sandbox-images/)：面向编码智能体和计算机使用桌面智能体的容器镜像，兼容 Docker、Podman 和 Cella 沙箱。
- [Lume](https://awesomecua.com/zh/resources/github-trycua-lume/)：用于本地计算机使用环境的虚拟机管理工具。
- [Mobile Env](https://awesomecua.com/zh/resources/github-x-lance-mobile-env/)：基于 AndroidEnv 的 GUI 智能体基准构建与训练平台；任务定义文件根据屏幕文本、视图层级或日志事件生成指令、奖励和回合结束信号。
- [modal-computer-use](https://awesomecua.com/zh/resources/github-ashtonchew-modal-computer-use/)：提供以守护进程为核心的计算机使用基础功能，用于在 Modal 云沙箱中配置和控制 GUI 桌面。
- [Nehemiah](https://awesomecua.com/zh/resources/github-boringcomputers-nehemiah/)：Nehemiah 按需创建配备浏览器和桌面环境的 Linux Firecracker 微型虚拟机，供 AI 智能体使用。
- [Neo Lab](https://awesomecua.com/zh/resources/github-belarusian-neo-lab/)：Neo Lab 是 macOS 计算机使用沙箱，可用于录制示范、重放技能和测试 GUI 自动化方案。
- [OSWorld VirtualBox Ubuntu image](https://awesomecua.com/zh/resources/url-ce775111626bae220596/)：托管 OSWorld 的 Ubuntu 虚拟机归档，供其 VirtualBox 提供程序在 x86 主机上下载并通过 VBoxManage 导入；仓库没有数据卡或许可声明。
- [OSWorld Windows VM images](https://awesomecua.com/zh/resources/url-232a1698849e2fea425c/)：托管 OSWorld 预构建的 Windows 10 虚拟机：含 VMware 和 QEMU qcow2 归档，供 OSWorld 的 VMware 和 Docker 提供程序首次运行 Windows 任务时下载。
- [Phi Browser](https://awesomecua.com/zh/resources/github-phibrowser-phibrowser-mac/)：Chromium 浏览器的原生 macOS 客户端；其智能体 Spaces 允许内置助手或外部智能体在用户授权后通过 DevTools Protocol 套接字控制窗口，用户可观看并接管。
- [qdesk](https://awesomecua.com/zh/resources/github-jackwangfeng-qdesk/)：qdesk 是开源的 AI 智能体桌面沙箱，提供可通过 HTTP 控制的隔离 Linux 和 Chromium 环境。
- [Qubicl](https://awesomecua.com/zh/resources/github-eldanring-qubicl/)：创建隔离的本地虚拟计算机，让 AI 智能体操作私有桌面，而不触及主机会话。
- [QuickDesk](https://awesomecua.com/zh/resources/github-barry-ran-quickdesk/)：QuickDesk 是面向 AI 的远程桌面客户端和主机，内置 MCP 服务器，用于传输屏幕画面和控制远程计算机。
- [Relay AI Virtual Desktop](https://awesomecua.com/zh/resources/github-jahrulnr-virtual-desktop/)：通过浏览器串流的 Docker Linux 桌面，供人类和 AI 智能体共用，并配有 Go MCP 计算机使用服务器。
- [Rocuronium](https://awesomecua.com/zh/resources/github-kageroumado-rocuronium/)：将 macOS 计算机使用智能体隔离在单独的登录会话中，同时在主机屏幕上显示实时可见的智能体叠加层。
- [Sandbar](https://awesomecua.com/zh/resources/github-jdrolls-sandbar-public/)：Sandbar 为计算机使用智能体配置隔离的云端 Ubuntu 桌面虚拟机，配备 OpenClaw 和 VNC 串流。
- [Sandbox0](https://awesomecua.com/zh/resources/github-sandbox0-ai-sandbox0/)：Sandbox0 是面向 AI 智能体的开源云沙箱平台，提供持久化存储卷以及亚秒级 microVM 和容器恢复。
- [SentinelDesk](https://awesomecua.com/zh/resources/github-sentineldesk-desktop/)：向浏览器流式传输的协作式 Linux 桌面，供人和 AI 智能体共享工作区。
- [SpaceO](https://awesomecua.com/zh/resources/github-parthjadhav-spaceo/)：为 AI 计算机使用智能体提供专用的虚拟 macOS 显示器，使其能操作真实应用，而无需接管用户的屏幕或光标。
- [Tailorec Browser Orchestrator](https://awesomecua.com/zh/resources/github-tailorec-tailorec-browser-orch/)：按运行实例隔离的浏览器编排服务，将网页转换为带稳定元素引用的语义快照。
- [Twiko](https://awesomecua.com/zh/resources/github-ezocomp118-source-twiko/)：自托管平台，为自主 AI 队友配置配有浏览器和终端的专用虚拟计算机。
- [UseAgent](https://awesomecua.com/zh/resources/github-useagenthq-useagent/)：开源云端和本地沙箱平台，可在完整桌面和浏览器环境中运行 Claude Code、Codex 或 OpenCode。
- [Vessel Browser](https://awesomecua.com/zh/resources/github-unmodeled-tyler-vessel-browser/)：基于 Electron/Chromium 的浏览器，为智能体提供可见运行环境；本地 MCP 服务器和内置助手将页面读取为带索引的元素，并执行点击、输入和导航，支持限定范围的审批、检查点与撤销。
