# 计算机使用智能体：第 5 页

HTML 页面：https://awesomecua.com/zh/categories/agent/page/5/ · [English](https://awesomecua.com/categories/agent/page/5/index.md)

完整类别注释：https://awesomecua.com/zh/categories/agent/index.md

- [WebQA Agent](https://awesomecua.com/resources/github-migoxlab-webqa-agent/)：WebQA Agent 是自主多模态网页测试智能体，无需测试脚本即可检查网页功能、性能和视觉用户体验。
- [WebTactix](https://awesomecua.com/resources/url-40795d2c86388ae89f43/)：一款网页智能体，将无障碍树简化后并行探索候选操作，并用语义树保存已访问页面，支持后续决策和失败恢复。
- [WinAgent-Lite](https://awesomecua.com/resources/github-zyydi1959-winagent-lite/)：WinAgent-Lite 是本地视觉驱动的 Windows GUI 智能体和 MCP 服务器，附带可复现的桌面评测套件。
- [winter40611 Browser Agent](https://awesomecua.com/resources/github-winter40611-browser-agent/)：基于 Spring Boot、LangChain4j 和 MCP 的智能体后端，通过 WeChat iLink 实现远程 PC 和浏览器自动化。
- [Workday Expense & Invoice Assistant (tnehelper)](https://awesomecua.com/resources/github-guoyuqi2002-tnehelper/)：桌面与浏览器自动化智能体，将发票文档与 Workday 差旅及费用网页门户进行核对。
- [Workroom (MLX Computer-Use Agent)](https://awesomecua.com/resources/github-iamibrahimmemon-mlx-llm-workroom/)：Workroom 是完全在本地运行的 macOS 计算机使用智能体，使用 Apple Silicon MLX 视觉语言模型读取屏幕并执行命令。
- [Xiaoshe Agent (小蛇 Agent)](https://awesomecua.com/resources/github-jackygilbert498-debug-xiaoshe-agent/)：基于 DeepSeek Harness 构建的本地优先桌面智能体，具备插件治理、权限审批和完成回执功能。
- [XiaoShuang (小双桌面女神)](https://awesomecua.com/resources/github-daixin315-xiaoshuang/)：跨平台桌面 AI 伴侣，具备屏幕读取、实时翻译和与 Hermes 关联的应用自动化功能。
- [Xiryn](https://awesomecua.com/resources/github-souravberaakaspeed-xiryn/)：可自行托管的个人智能体应用，为每个智能体提供独立的 Docker Linux 桌面和 Chromium，通过截图及 xdotool 点击和按键操作，并支持实时接管、记忆、保险库和 Telegram 控制。
- [Yad (يد)](https://awesomecua.com/resources/github-holistis-al-yad/)：可自托管、以隐私为先的本地 AI 浏览器自动化智能体和 Chrome 扩展程序。
- [Yunkai](https://awesomecua.com/resources/github-solplum-yunkai/)：Android 手机助手，将模型驱动的工具调用与无障碍树读取、截图及点击、滑动、文本输入等基本操作结合；文档中的交互流程会向用户展示操作计划以供确认。
- [Ziweixing (紫微星)](https://awesomecua.com/resources/github-xiaozhe7772222-ziweixing/)：以意图为先的 Android 手机自动化智能体，具备类人触控轨迹和屏幕感知能力。
- [Zoom Search](https://awesomecua.com/resources/github-goofrey-zoom-search/)：Zoom Search 是分层网页搜索智能体，先预览简要页面摘要，再有选择地获取完整网页内容。
