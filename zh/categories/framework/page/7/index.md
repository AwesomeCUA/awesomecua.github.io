# 计算机使用智能体框架：第 7 页

HTML 页面：https://awesomecua.com/zh/categories/framework/page/7/ · [English](https://awesomecua.com/categories/framework/page/7/index.md)

完整类别注释：https://awesomecua.com/zh/categories/framework/index.md

- [VideoCAD training and evaluation code](https://awesomecua.com/resources/github-ghadinehme-videocad/)：提供 VideoCADFormer 训练、操作日志预处理和评估代码，用于从浏览器版 Onshape 的屏幕录像中学习 CAD 界面操作序列。
- [VillagerAgent & VillagerBench](https://awesomecua.com/resources/github-cnsdqd-dyb-villageragent/)：VillagerAgent 提供基于有向无环图的多智能体协调器，以及 Minecraft 中的 VillagerBench 评测套件。
- [ViMo code](https://awesomecua.com/resources/github-ai-agents-2030-vimo/)：ViMo GUI 世界模型的代码，包括基于 Gemini 的下一屏文本预测、AITW 和 AndroidControl 数据处理、InstructPix2Pix 风格的图像推断，以及调用该模型的 AndroidWorld 智能体。
- [Vision Browser Agent](https://awesomecua.com/resources/github-zbcs-studiocr-cn-vision-browser-agent/)：纯视觉浏览器自动化框架，内置本地 Moondream3 推理，完全不依赖 DOM，并支持类人鼠标轨迹。
- [VisionGrid AI](https://awesomecua.com/resources/github-mohsinjutt62-autoplay-cv-engine-bot/)：基于 OpenCV 和 ADB 构建的计算机视觉 Android UI 自动化及启发式游戏操作引擎。
- [visual-agent](https://awesomecua.com/resources/github-cloudsbeyond-visual-agent/)：协议优先的框架，使视觉模型宿主能够安全地检查和操作软件 GUI 界面。
- [VLAA-GUI](https://awesomecua.com/resources/github-ucsc-vlaa-vlaa-gui/)：VLAA-GUI 提供模块化 GUI 自动化框架，教会智能体何时停止、如何从错误中恢复以及搜索替代方案。
- [vnc-use](https://awesomecua.com/resources/github-mayflower-vnc-use/)：vnc-use 是基于 LangGraph 的计算机使用框架，通过 VNC 操作远程桌面环境，并配备多模型 LLM 规划器和 hitl 关卡。
- [Voice2Task Post-Training](https://awesomecua.com/resources/github-raidriar7170-voice2task-posttraining/)：后训练与评测流水线，将中文语音的 ASR 指令映射为符合模式定义的浏览器智能体动作计划。
- [VoltageInputMcp](https://awesomecua.com/resources/github-casualkre-voltage-input-mcp/)：面向 MCP 的双层本地输入引擎，由前沿规划模型将高频动作程序分派给本地执行器。
- [VSC-RL code](https://awesomecua.com/resources/github-ai-agents-2030-vsc-rl/)：面向 Android in the Wild 任务的 VSC-RL 训练代码：Gemini 生成的子目标引导 Auto-UI 策略在模拟器中结合学习得到的评判器与 Gemini 终态评估器进行在线训练，基于 DigiRL 构建。
- [Vuser Protocol](https://awesomecua.com/resources/github-openvuser-vuser/)：Vuser 是开放的前端交互协议，为浏览器使用、桌面计算机使用和移动端使用中的虚拟用户动作制定统一标准。
- [Weave WebMCP](https://awesomecua.com/resources/github-doom2quake-weave/)：浏览器原生的 WebMCP 构想到计划画布，供用户和网页智能体协同编辑结构化任务计划。
- [Web Agent Proxy (WAP) SDK](https://awesomecua.com/resources/github-52191314-web-agent-proxy-sdk/)：面向 AI 智能体的浏览器基础设施 SDK，支持用户同意机制下的路由和端到端加密的会话中继。
- [Web Context Interface (WCI)](https://awesomecua.com/resources/github-amirrezaalasti-webcontextinterface/)：Web Context Interface（WCI）是三层规范和工具包，通过结构化语义元数据增强 HTML，供 AI 网页智能体使用。
- [web-pilot](https://awesomecua.com/resources/github-vinimabreu-web-pilot/)：浏览器使用框架，模型从封闭的动作集合中提出单个动作，再由确定性代码验证并执行。
- [WebAgent-R1](https://awesomecua.com/resources/github-weizhepei-webagent-r1/)：为与 WebArena 交互的浏览器智能体提供环境配置、多轮强化学习和评估工具。
- [WebAgents Protocol](https://awesomecua.com/resources/github-betterwright-webagents/)：开放协议规范和工具包，向浏览器智能体提供原生支持批量处理的网站动作。
- [WebDroid](https://awesomecua.com/resources/github-loyality7-webdroid/)：采用 Playwright 风格的浏览器自动化库，用于驱动 Android 应用中的实时 Chromium 页面。
- [WebEvolver code component](https://awesomecua.com/resources/component-tencent-selfevolvingagent-webevolver/)：用于收集网页智能体轨迹、准备监督数据，以及基于世界模型合成轨迹的组件。
- [WebMCP Deadbolt](https://awesomecua.com/resources/github-faxanfm-webmcp-deadbolt/)：面向 WebMCP 浏览器商务智能体的中间件，提供默认拒绝的能力门控、结构化拒绝和对抗性防护。
- [WebMCP Stack](https://awesomecua.com/resources/github-souravinsights-webmcp-stack/)：直接从现有 OpenAPI 和后端契约生成经过人工审核的类型化 WebMCP 浏览器工具。
- [WebMCPcss](https://awesomecua.com/resources/github-cochinoraptor-webmcpcss/)：通过 CSS 规则直接声明可供智能体调用的网站动作和语义操作线索，扩展 WebMCP 标准。
- [WebMirage](https://awesomecua.com/resources/github-moontea0416-webmirage/)：WebMirage 是一个对抗性红队测试框架，通过构造视觉扰动，在网页智能体从定位到浏览器执行的过程中劫持它们。
- [WebRL](https://awesomecua.com/resources/github-thudm-webrl/)：从先前尝试中演化网页任务，并利用结果奖励模型改进浏览器操作策略的训练流程。
- [WebVLN research implementation](https://awesomecua.com/resources/github-webvln-webvln/)：面向问题引导的网站导航，提供结合视觉观察与网页专有 HTML 信息的训练和评估代码。
- [WellSet WebMCP](https://awesomecua.com/resources/github-kinhikars-wellset-webmcp/)：基于 WebMCP 的共享 96 孔实验室实验画布，供科学家和浏览器智能体共同设计实验方案。
- [WinDOM code](https://awesomecua.com/resources/github-chenghengli-windom/)：使用 Windows 风格网页环境的 GUI 定位训练与评估代码，包含同系列模型蒸馏、GRPO 训练方案和框内点位评分。
- [WinWright](https://awesomecua.com/resources/github-alegauss-winwright/)：受 Playwright 启发的 Windows 桌面自动化与测试框架，可操控原生应用并报告经过验证的 UI 状态。
- [WKAppBot SDK](https://awesomecua.com/resources/github-kiexpert-wkappbot-sdk/)：WKAppBot 是开源的 Windows Computer Use 和 AppBot SDK，为 AI 智能体提供结构化 UI 感知和动作执行能力。
- [Workflow Use](https://awesomecua.com/resources/github-browser-use-workflow-use/)：将录制的浏览器会话或 Browser Use 智能体运行转为参数化工作流文件，由 Playwright 确定性重放，并在步骤失败时回退至 LLM 智能体。
- [Workflow-Guided Exploration research code](https://awesomecua.com/resources/github-stanfordnlp-wge/)：通过演示归纳的工作流程约束探索，以学习浏览器控制策略的研究代码，包含基于 Selenium 的 MiniWoB 环境和实验框架。
- [WorkForceAgent-R1](https://awesomecua.com/resources/github-night-chen-workforceagent-r1/)：为面向推理的语言智能体提供网页任务奖励函数、WorkArena 数据处理流程和 GRPO 训练配置。
- [Worldline](https://awesomecua.com/resources/github-artemyx-datascientist-worldline/)：模块化、由用户控制的 AI 浏览器内核，用于结构化网页解析、导航和工作流自动化。
- [Xihe Agent (羲和)](https://awesomecua.com/resources/github-jiugao-yi-xihe-agent/)：单进程工具调用智能体运行时，可跨 CLI、企业聊天网关、桌面 GUI 和真实浏览器运行。
- [ZetaTron](https://awesomecua.com/resources/github-itsmarcels-zetatron/)：面向 Windows 的自主运行、本地优先的自主智能体测试框架，具备桌面和浏览器操作能力。
- [Zhaozuo (照做)](https://awesomecua.com/resources/github-dongsheng123132-zhaozuo/)：由演示驱动的 Windows 桌面自动化框架，兼容面向第三方 GUI 软件的 ActionParity 协议。
- [ZoomClick](https://awesomecua.com/resources/github-princeton-ai2-lab-zoomclick/)：ZoomClick 实现迭代放大的 GUI 定位，并在高分辨率界面上进行基于行为的定位评测。
