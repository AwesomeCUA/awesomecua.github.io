# 计算机使用智能体框架：第 7 页

HTML 页面：https://awesomecua.com/zh/categories/framework/page/7/ · [English](https://awesomecua.com/categories/framework/page/7/index.md)

完整类别注释：https://awesomecua.com/zh/categories/framework/index.md

- [TopoClaw](https://awesomecua.com/zh/resources/github-madeagents-topoclaw/)：TopoClaw 是具备拓扑感知能力的多智能体数字助手，支持技能验证，并在桌面、网页和移动端执行沙箱化操作。
- [Touchline](https://awesomecua.com/zh/resources/github-edenbuilds-touchline/)：多智能体浏览器团队，基于证据检查网站并重建前端。
- [Touchpoint](https://awesomecua.com/zh/resources/github-touchpoint-labs-touchpoint/)：Touchpoint 是跨平台桌面无障碍 API 和 MCP 服务器，为 AI 智能体提供统一的 UI 检查与控制能力。
- [TraceFact](https://awesomecua.com/zh/resources/github-alex0ai-tracefact/)：面向编程和浏览器智能体、以证据为先的可靠性报告与确定性回放框架。
- [TreeCUA](https://awesomecua.com/zh/resources/github-uitron-hub-treecua/)：通过树状探索和验证生成 GUI 操作轨迹的框架。
- [Trope CUA](https://awesomecua.com/zh/resources/github-tropeai-trope-cua/)：Trope CUA 支持在 Windows 和 macOS 上进行后台桌面检查与 GUI 操作，同时不打断用户的前台工作。
- [Trusted WebMCP Actions](https://awesomecua.com/zh/resources/github-markneville-trusted-webmcp-actions/)：参考架构，用于在有重大后果的 WebMCP 浏览器智能体动作中，以密码学方式验证用户授权。
- [Tsaagan](https://awesomecua.com/zh/resources/github-michaelolmos-tsaagan/)：Tsaagan 是面向 AI 智能体、先验证再继续的浏览器控制框架，在进入下一步前验证每次点击和表单动作是否成功。
- [TuriX-CUA](https://awesomecua.com/zh/resources/github-turixai-turix-cua/)：TuriX-CUA 是面向 macOS 和 Windows 的多智能体桌面自动化框架，结合规划者、执行者、反思者和记忆技能。
- [UI-Voyager](https://awesomecua.com/zh/resources/github-ui-voyager-ui-voyager/)：UI-Voyager 是自我演进的移动端 GUI 智能体框架，通过组相对反思从失败的执行轨迹中学习。
- [Ui.Vision RPA](https://awesomecua.com/zh/resources/github-a9t9-rpa/)：Ui.Vision 结合了兼容 Selenium 的浏览器命令、基于视觉的桌面 OCR 和模板自动化，以及面向 AI 智能体的 MCP 服务器。
- [UI2API](https://awesomecua.com/zh/resources/github-merezarezaei-ui2api/)：对网站的 UI 和网络流量进行一次分析，为 AI 智能体生成可复用且无需浏览器的 API 工具。
- [uia-agent](https://awesomecua.com/zh/resources/github-supermarioyl-uia-agent/)：uia-agent 定义开源 LLM 智能体的动作空间，通过 UI Automation 树驱动传统 Windows 桌面应用。
- [Unattended Android Automation Toolkit](https://awesomecua.com/zh/resources/github-chuanchihsu1219-unattended-android-automation-toolkit/)：面向无人值守 Android 应用自动化、崩溃恢复和 UI 状态采集的可靠性优先构建组件。
- [Understudy](https://awesomecua.com/zh/resources/github-understudy-ai-understudy/)：Understudy 观察人类在桌面和浏览器中的操作演示，并将其编译为可参数化、可重放的计算机使用技能。
- [Universal AI Studio (OmniAI Desktop)](https://awesomecua.com/zh/resources/github-osamalvzx-universal-ai-studio/)：一体化桌面 AI 工作室，集成多模型 LLM 聊天、计算机使用和浏览器自动化。
- [UXAgent](https://awesomecua.com/zh/resources/url-2f73fe78c423e263d451/)：一套可用性测试系统：生成模拟用户画像，让大模型智能体通过浏览器连接器在目标网站上完成任务，并在结果查看界面中展示其问卷回答与操作日志。
- [V-Droid](https://awesomecua.com/zh/resources/github-v-droid-agent-v-droid/)：V-Droid 将移动端 GUI 执行者与生成式验证器配对，在 Android 设备上执行候选动作前为其评分。
- [VACT (Vector Agent Context Transport)](https://awesomecua.com/zh/resources/github-fy2ne-vact/)：面向桌面计算机使用智能体的高频 GPU 屏幕感知和低延迟输入传输协议。
- [vco (Visual Computer Operate)](https://awesomecua.com/zh/resources/github-lo2589-vco/)：由 Shell 驱动的可视化计算机使用工具包，使 LLM 能够查看和点击网页及桌面屏幕。
- [Vedanshu7 Operant](https://awesomecua.com/zh/resources/github-vedanshu7-operant/)：通过 LLM 探索一次如何在没有 API 的应用中完成任务，并将轨迹编译为可重复执行的形式。
- [VEM GUI-Agent-RL](https://awesomecua.com/zh/resources/github-microsoft-gui-agent-rl/)：训练代码从离线 Android 交互数据中学习价值环境模型，并用冻结的价值估计指导 GUI 策略优化。
- [Venxuix Dccide](https://awesomecua.com/zh/resources/github-venxuix-dccide-venxuix/)：位于 Windows 之上的 2D/3D 智能体操作环境，供人类和 AI 智能体共同编排桌面任务。
- [VeriOS](https://awesomecua.com/zh/resources/github-wuzheng02-verios/)：用于人与 GUI 智能体主动验证的研究代码，包括离线交互循环、双智能体评估脚本及 LLaMA-Factory 微调配置。
- [VeriSafe Agent](https://awesomecua.com/zh/resources/github-verisafeagent-verisafeagent/)：面向 Android GUI 智能体的运行时验证框架，依据从用户指令和开发者定义的应用状态中推导出的逻辑规则检查拟执行的操作。
- [VG-GUI-TASKER](https://awesomecua.com/zh/resources/github-vg-gui-tasker-vg-gui-tasker/)：VG-GUI-TASKER 从教学演示视频中提取有用的关键帧，用于指导多模态 GUI 智能体。
- [Video2GUI](https://awesomecua.com/zh/resources/github-weiminxiong-video2gui/)：Video2GUI 通过逆向动力学和 VLM 标注，从未标注的屏幕录制视频中合成大规模 GUI 交互轨迹。
- [VideoCAD training and evaluation code](https://awesomecua.com/zh/resources/github-ghadinehme-videocad/)：提供 VideoCADFormer 训练、操作日志预处理和评估代码，用于从浏览器版 Onshape 的屏幕录像中学习 CAD 界面操作序列。
- [VillagerAgent & VillagerBench](https://awesomecua.com/zh/resources/github-cnsdqd-dyb-villageragent/)：VillagerAgent 提供基于有向无环图的多智能体协调器，以及 Minecraft 中的 VillagerBench 评测套件。
- [ViMo code](https://awesomecua.com/zh/resources/github-ai-agents-2030-vimo/)：ViMo GUI 世界模型的代码，包括基于 Gemini 的下一屏文本预测、AITW 和 AndroidControl 数据处理、InstructPix2Pix 风格的图像推断，以及调用该模型的 AndroidWorld 智能体。
- [Vision Browser Agent](https://awesomecua.com/zh/resources/github-zbcs-studiocr-cn-vision-browser-agent/)：纯视觉浏览器自动化框架，内置本地 Moondream3 推理，完全不依赖 DOM，并支持类人鼠标轨迹。
- [VisionGrid AI](https://awesomecua.com/zh/resources/github-mohsinjutt62-autoplay-cv-engine-bot/)：基于 OpenCV 和 ADB 构建的计算机视觉 Android UI 自动化及启发式游戏操作引擎。
- [visual-agent](https://awesomecua.com/zh/resources/github-cloudsbeyond-visual-agent/)：协议优先的框架，使视觉模型宿主能够安全地检查和操作软件 GUI 界面。
- [VLAA-GUI](https://awesomecua.com/zh/resources/github-ucsc-vlaa-vlaa-gui/)：VLAA-GUI 提供模块化 GUI 自动化框架，教会智能体何时停止、如何从错误中恢复以及搜索替代方案。
- [vnc-use](https://awesomecua.com/zh/resources/github-mayflower-vnc-use/)：vnc-use 是基于 LangGraph 的计算机使用框架，通过 VNC 操作远程桌面环境，并配备多模型 LLM 规划器和 hitl 关卡。
- [Voice2Task Post-Training](https://awesomecua.com/zh/resources/github-raidriar7170-voice2task-posttraining/)：后训练与评测流水线，将中文语音的 ASR 指令映射为符合模式定义的浏览器智能体动作计划。
- [VoltageInputMcp](https://awesomecua.com/zh/resources/github-casualkre-voltage-input-mcp/)：面向 MCP 的双层本地输入引擎，由前沿规划模型将高频动作程序分派给本地执行器。
- [VSC-RL code](https://awesomecua.com/zh/resources/github-ai-agents-2030-vsc-rl/)：面向 Android in the Wild 任务的 VSC-RL 训练代码：Gemini 生成的子目标引导 Auto-UI 策略在模拟器中结合学习得到的评判器与 Gemini 终态评估器进行在线训练，基于 DigiRL 构建。
- [Vuser Protocol](https://awesomecua.com/zh/resources/github-openvuser-vuser/)：Vuser 是开放的前端交互协议，为浏览器使用、桌面计算机使用和移动端使用中的虚拟用户动作制定统一标准。
- [Weave WebMCP](https://awesomecua.com/zh/resources/github-doom2quake-weave/)：浏览器原生的 WebMCP 构想到计划画布，供用户和网页智能体协同编辑结构化任务计划。
- [Web Agent Proxy (WAP) SDK](https://awesomecua.com/zh/resources/github-52191314-web-agent-proxy-sdk/)：面向 AI 智能体的浏览器基础设施 SDK，支持用户同意机制下的路由和端到端加密的会话中继。
- [Web Context Interface (WCI)](https://awesomecua.com/zh/resources/github-amirrezaalasti-webcontextinterface/)：Web Context Interface（WCI）是三层规范和工具包，通过结构化语义元数据增强 HTML，供 AI 网页智能体使用。
- [web-pilot](https://awesomecua.com/zh/resources/github-vinimabreu-web-pilot/)：浏览器使用框架，模型从封闭的动作集合中提出单个动作，再由确定性代码验证并执行。
- [WebAgent-R1](https://awesomecua.com/zh/resources/github-weizhepei-webagent-r1/)：为与 WebArena 交互的浏览器智能体提供环境配置、多轮强化学习和评估工具。
- [WebAgents Protocol](https://awesomecua.com/zh/resources/github-betterwright-webagents/)：开放协议规范和工具包，向浏览器智能体提供原生支持批量处理的网站动作。
- [WebDroid](https://awesomecua.com/zh/resources/github-loyality7-webdroid/)：采用 Playwright 风格的浏览器自动化库，用于驱动 Android 应用中的实时 Chromium 页面。
- [WebEvolver code component](https://awesomecua.com/zh/resources/component-tencent-selfevolvingagent-webevolver/)：用于收集网页智能体轨迹、准备监督数据，以及基于世界模型合成轨迹的组件。
- [WebMCP Deadbolt](https://awesomecua.com/zh/resources/github-faxanfm-webmcp-deadbolt/)：面向 WebMCP 浏览器商务智能体的中间件，提供默认拒绝的能力门控、结构化拒绝和对抗性防护。
- [WebMCP Stack](https://awesomecua.com/zh/resources/github-souravinsights-webmcp-stack/)：直接从现有 OpenAPI 和后端契约生成经过人工审核的类型化 WebMCP 浏览器工具。
- [WebMCPcss](https://awesomecua.com/zh/resources/github-cochinoraptor-webmcpcss/)：通过 CSS 规则直接声明可供智能体调用的网站动作和语义操作线索，扩展 WebMCP 标准。
- [WebMirage](https://awesomecua.com/zh/resources/github-moontea0416-webmirage/)：WebMirage 是一个对抗性红队测试框架，通过构造视觉扰动，在网页智能体从定位到浏览器执行的过程中劫持它们。
- [WebRL](https://awesomecua.com/zh/resources/github-thudm-webrl/)：从先前尝试中演化网页任务，并利用结果奖励模型改进浏览器操作策略的训练流程。
- [WebVLN research implementation](https://awesomecua.com/zh/resources/github-webvln-webvln/)：面向问题引导的网站导航，提供结合视觉观察与网页专有 HTML 信息的训练和评估代码。
- [WellSet WebMCP](https://awesomecua.com/zh/resources/github-kinhikars-wellset-webmcp/)：基于 WebMCP 的共享 96 孔实验室实验画布，供科学家和浏览器智能体共同设计实验方案。
- [WinDOM code](https://awesomecua.com/zh/resources/github-chenghengli-windom/)：使用 Windows 风格网页环境的 GUI 定位训练与评估代码，包含同系列模型蒸馏、GRPO 训练方案和框内点位评分。
- [WinWright](https://awesomecua.com/zh/resources/github-alegauss-winwright/)：受 Playwright 启发的 Windows 桌面自动化与测试框架，可操控原生应用并报告经过验证的 UI 状态。
- [WKAppBot SDK](https://awesomecua.com/zh/resources/github-kiexpert-wkappbot-sdk/)：WKAppBot 是开源的 Windows Computer Use 和 AppBot SDK，为 AI 智能体提供结构化 UI 感知和动作执行能力。
- [Workflow Use](https://awesomecua.com/zh/resources/github-browser-use-workflow-use/)：将录制的浏览器会话或 Browser Use 智能体运行转为参数化工作流文件，由 Playwright 确定性重放，并在步骤失败时回退至 LLM 智能体。
- [Workflow-Guided Exploration research code](https://awesomecua.com/zh/resources/github-stanfordnlp-wge/)：通过演示归纳的工作流程约束探索，以学习浏览器控制策略的研究代码，包含基于 Selenium 的 MiniWoB 环境和实验框架。
- [WorkForceAgent-R1](https://awesomecua.com/zh/resources/github-night-chen-workforceagent-r1/)：为面向推理的语言智能体提供网页任务奖励函数、WorkArena 数据处理流程和 GRPO 训练配置。
- [Worldline](https://awesomecua.com/zh/resources/github-artemyx-datascientist-worldline/)：模块化、由用户控制的 AI 浏览器内核，用于结构化网页解析、导航和工作流自动化。
- [Xihe Agent (羲和)](https://awesomecua.com/zh/resources/github-jiugao-yi-xihe-agent/)：单进程工具调用智能体运行时，可跨 CLI、企业聊天网关、桌面 GUI 和真实浏览器运行。
- [ZetaTron](https://awesomecua.com/zh/resources/github-itsmarcels-zetatron/)：面向 Windows 的自主运行、本地优先的自主智能体测试框架，具备桌面和浏览器操作能力。
- [Zhaozuo (照做)](https://awesomecua.com/zh/resources/github-dongsheng123132-zhaozuo/)：由演示驱动的 Windows 桌面自动化框架，兼容面向第三方 GUI 软件的 ActionParity 协议。
- [ZoomClick](https://awesomecua.com/zh/resources/github-princeton-ai2-lab-zoomclick/)：ZoomClick 实现迭代放大的 GUI 定位，并在高分辨率界面上进行基于行为的定位评测。
