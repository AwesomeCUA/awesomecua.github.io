- [LlamaTouch Evaluator](https://awesomecua.com/zh/resources/github-llamatouch-evaluator/)：LlamaTouch Evaluator 根据标注的界面状态检查移动端智能体执行轨迹，并提供动作序列完全匹配及子序列匹配基线。
- [MaaCtl](https://awesomecua.com/zh/resources/github-tanyashue-maactl/)：MaaFramework 的命令行客户端，加载 ProjectInterface v2 项目，查看其控制器、资源和任务，并在 ADB 设备或桌面窗口上运行任务或流水线节点。
- [MaaEvidenceKit](https://awesomecua.com/zh/resources/github-windsland52-maaevidencekit/)：一个命令行工具和 TypeScript SDK，从 MaaFramework 日志和项目中提取带定位信息的运行时与静态证据，提供稳定的证据 ID、时间线以及 JSON 或文本视图，供智能体框架使用。
- [maafw-cli](https://awesomecua.com/zh/resources/github-otowa-kotori-maafw-cli/)：MaaFramework 的命令行界面，让人、脚本和编程智能体连接 ADB 或 Win32 目标，执行 OCR 与模板匹配，并按引用点击识别出的元素。
- [MaaFwApp](https://awesomecua.com/zh/resources/github-aliothmoon-maafwapp/)：一个 Android 应用，在手机本机运行以 Project Interface V2 描述的 MaaFramework 自动化项目，通过 Shizuku 或 root 进程截屏和点击，并可在虚拟屏上运行任务。
- [MaaInspector](https://awesomecua.com/zh/resources/github-tanyashue-maainspector/)：一个基于 Tauri 的 MaaFramework 5 流水线桌面节点编辑器，通过拖拽构建工作流，并在运行和调试节点时显示其执行状态。
- [MaaLogAnalyzer](https://awesomecua.com/zh/resources/github-maaxyz-maaloganalyzer/)：一个 MaaFramework 应用日志的可视化分析工具，展示任务执行过程及识别与动作详情，支持关键字和正则搜索、带回放的 ELK 节点流程图以及运行统计。
- [MaaOWM](https://awesomecua.com/zh/resources/github-sunyink-maaowm/)：一个面向含多个适配包的 MaaFramework 项目的 Python 工作区管理器：挂载时把 base 与 mod 流水线合并为可编辑工作区，卸载时将其差分还原为最小 mod。
- [MaaPipelineEditor](https://awesomecua.com/zh/resources/github-kqcoxn-maapipelineeditor/)：一个基于浏览器的 MaaFramework Pipeline JSON 可视化编辑器，以相连节点构建自动化流程，提供 OCR 与截图辅助工具、节点模板、流程调试以及可选的本地服务。
- [MaaTouch](https://awesomecua.com/zh/resources/github-maaassistantarknights-maatouch/)：minitouch 输入协议的 Android 原生实现，接收按行发送的指令来执行触点按下、移动与抬起、等待、按键事件和文本输入，从而操控设备。
- [macbot-mcp](https://awesomecua.com/zh/resources/github-anomalous3-macbot-mcp/)：一个 MCP 服务器，让 AI 智能体读取带有元素坐标的 macOS 无障碍树，并通过 Quartz CGEvents 和 AppleScript 执行操作，提供 17 个用于观察、点击、输入和滚动的工具。
- [magpie Computer Use](https://awesomecua.com/zh/resources/github-wbb6517-magpie-computer-use/)：一款 Magpie 插件，通过 MCP 工具让智能体查看 macOS 应用屏幕，并执行点击、输入、滚动和拖动。
- [Maxim](https://awesomecua.com/zh/resources/github-zhangzhao4444-maxim/)：一个适用于模拟器和真机的 Android Monkey 压力测试工具，通过无障碍服务解析屏幕控件，并以随机、深度优先或按优先级引导的策略遍历应用。
- [MCP for Blender](https://awesomecua.com/zh/resources/github-ahujasid-blender-mcp/)：MCP for Blender 通过插件和 MCP 服务器将 AI 客户端连接到 Blender，支持编辑场景、执行 Python 命令，并利用视图和渲染结果进行视觉核验。
- [MCP Link](https://awesomecua.com/zh/resources/github-aurafriday-mcp-link/)：一个浏览器扩展，让 ChatGPT、Claude 等聊天 AI 调用用户批准的 MCP 工具；配合 MCP Link Server 使用时，可实现自动浏览和网页交互。
- [MCP Link Server](https://awesomecua.com/zh/resources/github-aurafriday-mcp-link-server/)：一款本地 MCP 服务器，让智能体调用获准的系统和浏览器工具，并通过已连接的浏览器扩展执行网页自动化。
- [mcp-patchright](https://awesomecua.com/zh/resources/github-maestrojeong-mcp-patchright/)：一个基于 Patchright 的 MCP 服务器，向智能体提供 64 个浏览器工具，涵盖带元素引用的无障碍快照、点击、表单填写、Cookie 与网络控制。
- [mcp-pyautogui](https://awesomecua.com/zh/resources/github-hathibelagal-dev-mcp-pyautogui/)：一个通过 PyAutoGUI 为 AI 客户端提供桌面鼠标和键盘控制、截图及屏幕查询功能的 MCP 服务器。
- [MCP-Slicer](https://awesomecua.com/zh/resources/github-zhaoyouj-mcp-slicer/)：MCP-Slicer 让模型客户端通过节点检查、Python 执行和截图使用 3D Slicer，在医学影像与场景任务中获得视觉反馈。
- [Mechanize](https://awesomecua.com/zh/resources/github-sparklemotion-mechanize/)：Mechanize 是一个 Ruby 库，可自动执行网站交互，包括页面导航、Cookie 处理和表单提交。
- [MFW-ChainFlow Assistant](https://awesomecua.com/zh/resources/github-overflow65537-mfw-pyqt6/)：基于 PySide6 的 MaaFramework 项目桌面运行器，实现 interface v2 协议，提供配置管理、定时运行、通知以及自定义动作。
- [minicap](https://awesomecua.com/zh/resources/github-devicefarmer-minicap/)：一个 Android 组件，通过本地 socket 以 JPEG 格式实时推送屏幕画面，使用 NDK 构建，被 STF 用于远程控制设备；较新的设备可达到 30-40 FPS。
- [Mjolnir](https://awesomecua.com/zh/resources/github-mjolnirapp-mjolnir/)：一个 macOS 应用，加载 Lua 环境，用户配置和 LuaRocks 模块可借此绑定全局快捷键、显示提示，并检查或移动正在运行的应用和窗口。
- [Mobile Harness](https://awesomecua.com/zh/resources/github-droidrun-mobile-harness/)：提供可移植的智能体指令和集成工具，通过 mobilerun-core 控制本地或云端手机。
- [Mobile JSON Wire Protocol Specification](https://awesomecua.com/zh/resources/github-seleniumhq-mobile-spec/)：一份用于自动化原生与混合移动应用的 WebDriver 扩展草案，定义了会话、能力参数、定位策略、触摸手势、屏幕方向、旋转、网络模式和 WebView 上下文。
- [MobileBuildMCP](https://awesomecua.com/zh/resources/github-getsentry-xcodebuildmcp/)：一个 MCP 服务器和命令行工具，让编程智能体构建、运行和调试 iOS 与 macOS 应用，并通过点击、滑动、输入、界面快照和截图操作 iOS 模拟器。
- [Mobilerun Portal (formerly Droidrun Portal)](https://awesomecua.com/zh/resources/github-droidrun-mobilerun-portal/)：Android 无障碍服务，为移动端自动化智能体提供 UI 元素检查、设备控制接口和屏幕反馈。
