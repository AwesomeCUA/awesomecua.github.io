For agents and developers

The whole catalog is open data. Pull it into a notebook, a retrieval index or your own agent; every record keeps its evidence links and review state.

  • llms.txtA map of the site for language models
  • Download dataJSONL, SQLite and a schema, every record with its evidence
  • Hugging Face datasetSynced from GitHub
  • Atom feedNew records as they are reviewed

# Every record, one JSON object per line
curl -s https://awesomecua.com/downloads/catalog.jsonl \
  | jq -r 'select(.kind=="benchmark" and .review_status=="curated") | .name'

ds = load_dataset("TIGER-Lab/AwesomeCUA", "resources", split="train")
