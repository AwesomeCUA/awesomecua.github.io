## Newest reviewed resources

- [Adept Fuyu-Heavy](https://awesomecua.com/resources/url-1a20a291c766bd4e6861/) — Models and checkpoints · reviewed 2026-11-10: Adept multimodal model that scales up the Fuyu architecture for digital agents, aimed mainly at UI understanding; Adept reports MMMU, VQAv2, AI2D and ChartQA scores against Gemini models.
- [GPT-6 Astra](https://awesomecua.com/resources/url-039a4975e102cb538c36/) — Models and checkpoints · reviewed 2026-11-10: General OpenAI model whose launch post covers computer use and browsing; OpenAI reports 72.6% on OSWorld 2.0 at about 40 minutes per task, plus ScreenSpot-Pro and Mind2Web results.
- [Indeed-UI-8B](https://awesomecua.com/resources/url-26157e2cda7fb73cf99c/) — Models and checkpoints · reviewed 2026-11-10: GUI grounding model fine-tuned from GUI-Owl 1.5-8B with grounding data and high-resolution training; the card reports 73.4 on ScreenSpot-Pro, 94.4 on ScreenSpot-V2 and 68.3 on OSWorld-G.
- [Muse Spark 1.1](https://awesomecua.com/resources/url-f8a956094e526a92caf3/) — Models and checkpoints · reviewed 2026-11-10: Meta Superintelligence Labs multimodal reasoning model for agentic work, trained to choose between writing scripts and clicking in computer-use workflows that span several applications.
- [UXAgent](https://awesomecua.com/resources/url-2f73fe78c423e263d451/) — Frameworks · reviewed 2026-11-10: Usability-testing system that generates simulated user personas, has LLM agents work through a target website via a browser connector, and shows their survey answers and action logs in a result viewer.
- [CUA_World_State_Model](https://awesomecua.com/resources/url-f0ffbdc41c9dca4c585f/) — Models and checkpoints · reviewed 2026-11-10: SEAgent's World State Model, a Qwen2.5-VL-7B-Instruct fine-tune that assesses computer-use trajectories step by step from screenshots, used to label successes and failures and to drive curriculum task generation.
- [InternVL3_5-2B](https://awesomecua.com/resources/url-feaad5e9f2497d1ed9ca/) — Models and checkpoints · reviewed 2026-11-10: InternVL3.5-2B checkpoint with a 0.3B vision encoder and 2.0B language model, from a multimodal family trained with Cascade RL that lists GUI interaction among its capabilities.
- [OpenPhone_dataset](https://awesomecua.com/resources/url-e7ea65893ab264517d83/) — Datasets · reviewed 2026-11-10: Training data for the OpenPhone mobile agent: the AndroidLab training archive plus a Hugging Face vision-language set with LLM-generated reasoning and reflection chains, formatted for GRPO training.
- [OpenWebVoyager-opt-2](https://awesomecua.com/resources/url-f4f6f5bfe051e6ba3d94/) — Models and checkpoints · reviewed 2026-11-10: The second optimization-iteration checkpoint of OpenWebVoyager, an idefics2-8b multimodal web agent trained by imitation learning and then refined on successful real-website trajectories kept by GPT-4o feedback.
- [Qwen3-VL-8B-Instruct-MobileWorld-SFT](https://awesomecua.com/resources/url-e58270c90ea4fa83cfb4/) — Models and checkpoints · reviewed 2026-11-10: Qwen3-VL-8B-Instruct fine-tuned on the MobileWorld dataset as a semantic world model that describes in natural language how a mobile GUI screen changes after an action, for planning by mobile agents.
- [TianXi_Action_Grounding_7B](https://awesomecua.com/resources/url-f644200c18bea88da7b3/) — Models and checkpoints · reviewed 2026-11-10: A 7B GUI action-grounding model from the SEA computer-use agent work, released as Qwen2_5_VL safetensors weights; its GitHub repository runs it on ScreenSpot-Pro across instruction styles and languages.
- [TimeWarp-GPT5-Traces](https://awesomecua.com/resources/url-fa8fd2873571ab1b3556/) — Datasets · reviewed 2026-11-10: GPT-5 teacher trajectories on the TimeWarp web benchmark, grouped by UI version, with SoM-annotated screenshots for each step and experiment logs, used to fine-tune web agents with LlamaFactory.
- [webarena-world-model-rlvr](https://awesomecua.com/resources/url-e02a165e76cd7c43e2ca/) — Models and checkpoints · reviewed 2026-11-10: A language world model for web page state prediction on WebArena, post-trained with RLVR from an SFT checkpoint and used for model predictive control of web agents.
- [ACT-SOP](https://awesomecua.com/resources/url-ab4587d17c4f541bb94c/) — Models and checkpoints · reviewed 2026-11-10: LoRA adapter for Llama-2-7b from MobileAgent, a mobile device control agent that adds Standard Operating Procedure (SOP) context and predicts actions on AitW screens.
- [Aguvis-7B-720P](https://awesomecua.com/resources/url-ac62da857db91f68376b/) — Models and checkpoints · reviewed 2026-11-10: Aguvis-7B-720P, the released Aguvis checkpoint: a vision-only GUI agent model trained first for grounding and then for planning and reasoning, acting from screenshots on web, desktop and mobile.
- [asil-qwen35-9b-rl](https://awesomecua.com/resources/url-c5cedb2f95336a8e48aa/) — Models and checkpoints · reviewed 2026-11-10: ASIL RL checkpoint of Qwen3.5-9B for operating desktop applications from JSON state observations with semantic actions written as code, trained on 320 task prompts after SFT.
- [InternVL3_5-2B-HF](https://awesomecua.com/resources/url-d1f0e13ad96c108ef09b/) — Models and checkpoints · reviewed 2026-11-10: HF-format 2.3B-parameter InternVL3.5 checkpoint, a multimodal model whose card lists GUI interaction among its trained skills and reports GUI task results for the family.
- [InternVL3_5-GPT-OSS-20B-A4B-Preview-HF](https://awesomecua.com/resources/url-c09ce6d4ca2ddaf02fae/) — Models and checkpoints · reviewed 2026-11-10: HF-format InternVL3.5 preview checkpoint built on a GPT-OSS language model (21.2B total, A4B), a multimodal model whose card lists GUI interaction among its trained skills and reports GUI results.
- [LFM2-350M-ComputerUse](https://awesomecua.com/resources/url-b68b02b47c87f006533e/) — Models and checkpoints · reviewed 2026-11-10: LoRA adapter for LFM2-350M trained with GRPO to click a button on the MiniWoB click-test task, reading the page as a BrowserGym accessibility tree and acting in a sandboxed browser.
- [lora_qformer_uitars_test_V1-400_merged](https://awesomecua.com/resources/url-b144605ae24674ffb917/) — Models and checkpoints · reviewed 2026-11-10: UI-TARS-V1.5-7B checkpoint with CoMEM continuous memory merged in, where a LoRA-tuned Q-Former compresses retrieved GUI trajectories into fixed-length embeddings for the web agent.
