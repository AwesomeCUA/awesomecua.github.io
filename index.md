## Newest reviewed resources

- [WildClawBench](https://awesomecua.com/resources/github-internlm-wildclawbench/) — Benchmarks · reviewed 2026-11-09: WildClawBench evaluates agents on 60 tasks in a live tool environment that includes browser use, email, files and coding. It releases evaluation code and links to task data and trajectories.
- [OpenAdapt Agent](https://awesomecua.com/resources/github-openadaptai-openadapt-agent/) — Tools · reviewed 2026-11-09: OpenAdapt Agent exposes demonstrated application workflows as callable tools for AI agents. It enters values in an app and checks the record before and after saving.
- [Rico Dataset](https://awesomecua.com/resources/url-0c845d69c9498dd4e20c/) — Datasets · reviewed 2026-11-09: Rico Dataset is a collection of mobile app interaction and design data presented through Interaction Mining, with 70k screens and 10k user flows across 5k apps.
- [Cerner PowerChart Browser Automation](https://awesomecua.com/resources/github-browser-automation-hub-cerner-powerchart-browser-automation/) — Tools · reviewed 2026-11-09: A browser automation scaffold for Cerner PowerChart with actions for login, patient search, results, orders, and documentation export, plus a selector reference.
- [Code2World](https://awesomecua.com/resources/github-amap-ml-code2world/) — Tools · reviewed 2026-11-09: Code2World provides code for predicting the next Android GUI screen from a screenshot and proposed action through renderable code, with an AndroidWorld agent integration.
- [MiniMax M3](https://awesomecua.com/resources/url-50089323623ee780a426/) — Models and checkpoints · reviewed 2026-11-09: MiniMax M3 is a multimodal model whose release page describes desktop operation from visual input and cross-application tasks through MiniMax Code.
- [ToL Hierarchical GUI region detection](https://awesomecua.com/resources/github-llv22-tol-gui-region-detection/) — Tools · reviewed 2026-11-09: Code and configurations for training a hierarchical Android GUI region detector with DINO and running region inference on the ScreenPR benchmark.
- [AI Agents for Computer Use](https://awesomecua.com/resources/github-sagerpascal-agents-for-computer-use/) — Learning resources · reviewed 2026-11-09: A browsable list of agents for desktop and mobile GUI control, with agent and dataset overviews linked from a companion survey repository.
- [AppSim-UberEats](https://awesomecua.com/resources/github-acrab-agentic-labs-appsim-ubereats/) — Infrastructure · reviewed 2026-11-09: AppSim-UberEats is an Android app replica with interactive shopping screens, seeded data and scripts for checking task events and answers during mobile-agent evaluation.
- [Browser Use Pi](https://awesomecua.com/resources/github-browser-use-browser-use-pi/) — Frameworks · reviewed 2026-11-09: Browser Use Pi is a TypeScript SDK for a browser agent that writes JavaScript to control Chrome through CDP and reads accessibility trees and screenshots for feedback.
- [Claude Fable 5.1](https://awesomecua.com/resources/url-e0f1ebb59adf2f6c500c/) — Products · reviewed 2026-11-09: Claude Fable 5.1 is a hosted model offering whose agent uses include operating a browser; its product page also discusses evaluation on OSWorld 2.0.
- [HiconAgent](https://awesomecua.com/resources/github-ilearn-lab-cvpr26-hiconagent/) — Frameworks · reviewed 2026-11-09: HiconAgent provides GUI-policy training code that samples histories of varied lengths and compresses past interactions during policy optimization.
- [LlamaTouch Evaluator](https://awesomecua.com/resources/github-llamatouch-evaluator/) — Tools · reviewed 2026-11-09: LlamaTouch Evaluator checks mobile-agent execution traces against annotated interface states and provides exact-match and subsequence action baselines.
- [OpenGVLab/MMBench-GUI](https://awesomecua.com/resources/url-339e28b1f939ae45f9fe/) — Datasets · reviewed 2026-11-09: MMBench-GUI releases annotations and offline images for evaluating interface understanding and grounding within a GUI-agent benchmark spanning desktop, mobile and web platforms.
- [SE-GUI](https://awesomecua.com/resources/github-yxb-nku-se-gui/) — Frameworks · reviewed 2026-11-09: SE-GUI provides training and evaluation code for a GUI-grounding model refined with location-based rewards and attention feedback; its README links separate weights and seed data.
- [SkillPacks](https://awesomecua.com/resources/github-agentsea-skillpacks/) — Tools · reviewed 2026-11-09: SkillPacks records and approves agent tool actions for retrieval and later training, illustrated with a desktop-control example.
- [The OS X Accessibility Model](https://awesomecua.com/resources/url-30901b60f8d142805b77/) — Learning resources · reviewed 2026-11-09: Apple's OS X guide explains how accessibility clients inspect an app's element hierarchy, read control properties, invoke actions and receive interface-change notifications.
- [WAREX Supplementary Code](https://awesomecua.com/resources/github-sumanknath-waber/) — Tools · reviewed 2026-11-09: WAREX supplementary code uses mitmproxy add-ons to inject popups or server and network errors into web-agent tests and record token use and latency.
- [Action-Type-Conditioned Grounding for GUI Agents](https://awesomecua.com/resources/github-aadcha-action-conditioned-gui-agent/) — Frameworks · reviewed 2026-11-09: Research code for GUI grounding that predicts an action type and then conditions coordinate prediction on it. It compares six conditioning methods and includes training and evaluation scripts.
- [AppSim-Eleme](https://awesomecua.com/resources/github-acrab-agentic-labs-appsim-eleme/) — Infrastructure · reviewed 2026-11-09: An Android food-delivery app built as a local test environment for AI interaction. It supplies shopping workflows, predefined tasks, action logging and evaluation scripts.
