## Newest reviewed resources

- [Hermes Jev Skills](https://awesomecua.com/resources/github-kerpopule-hermes-jev-skills/) — Tools · reviewed 2026-11-10: SKILL.md skills for Hermes, Claude Code and Codex agents that pass small decisions to the Jev model, including desktop and browser skills in which Jev picks each next action from a caller-built table.
- [AI GameStore](https://awesomecua.com/resources/github-lance-ying-aigamestore/) — Benchmarks · reviewed 2026-11-10: A benchmark of 100 games adapted from App Store and Steam charts into web-playable versions, with a Playwright harness that sends game screenshots to vision-language models and executes their key presses.
- [idevice](https://awesomecua.com/resources/github-jkcoxson-idevice/) — Tools · reviewed 2026-11-10: A Rust library that talks to iOS device services over lockdownd, usbmuxd and RSD, with features for screenshots, SpringBoard control, app installation and launching WebDriverAgent runners.
- [MCP Link](https://awesomecua.com/resources/github-aurafriday-mcp-link/) — Tools · reviewed 2026-11-10: A browser extension that lets chat AIs such as ChatGPT and Claude call user-approved MCP tools; with the companion MCP Link Server it adds automated browsing and web interactions.
- [Operit2](https://awesomecua.com/resources/github-aaswordman-operit2/) — Agents · reviewed 2026-11-10: A cross-device personal agent in preview that continues conversations and tasks across phones, desktops and cloud nodes, with file, terminal and browser tools that click, type and snapshot web pages.
- [Scrapling](https://awesomecua.com/resources/github-d4vinci-scrapling/) — Tools · reviewed 2026-11-10: A Python scraping framework with HTTP and stealth browser fetchers and spiders, plus an MCP server whose seventeen tools let AI agents click, fill forms, type and take screenshots in browser sessions.
- [Nakama](https://awesomecua.com/resources/github-ahmadrosid-nakama/) — Agents · reviewed 2026-11-10: A team AI agent platform, run as managed cloud or one Docker container, whose agents can drive a per-user Kernel cloud browser or Chrome on the server to open pages, click and fill forms.
- [OmniJev](https://awesomecua.com/resources/url-6bdda64c5782f03b0f54/) — Models and checkpoints · reviewed 2026-11-10: OmniJev v1.1 is a 4B LoRA adapter with decision heads for Qwen3.5-4B that answers typed questions about screens and other images with probabilities; its task families include androidcontrol and web.
- [Patchright .NET](https://awesomecua.com/resources/github-deventerprisesoftware-patchright-dotnet/) — Tools · reviewed 2026-11-10: Patchright .NET is the .NET package of Patchright: a patched Playwright that replaces the Microsoft.Playwright package and drives Chromium with automation leaks removed.
- [Patchright NodeJS](https://awesomecua.com/resources/github-kaliiiiiiiiii-vinyzu-patchright-nodejs/) — Tools · reviewed 2026-11-10: Patchright NodeJS is the Node.js package of Patchright: a patched Playwright that drives Chromium through the standard JavaScript API with automation leaks removed.
- [Patchright Python](https://awesomecua.com/resources/github-kaliiiiiiiiii-vinyzu-patchright-python/) — Tools · reviewed 2026-11-10: Patchright Python is the Python package of Patchright: a patched Playwright that drives Chromium through the usual sync and async APIs with automation leaks removed.
- [@mcp-b](https://awesomecua.com/resources/github-webmcp-org-npm-packages/) — Frameworks · reviewed 2026-11-10: TypeScript packages that connect pages registering tools through the WebMCP document.modelContext API to MCP, so agents in an extension, the browser or desktop clients can call them.
- [AgentGym-RL-Data-ID](https://awesomecua.com/resources/url-9140ca5ba8252d373b8d/) — Datasets · reviewed 2026-11-10: Train and eval task splits for AgentGym-RL multi-turn reinforcement learning, listing task IDs for WebArena web navigation alongside search, game, embodied and science environments.
- [go-ios](https://awesomecua.com/resources/github-danielpaulus-go-ios/) — Tools · reviewed 2026-11-10: A Go CLI and module that automates iOS devices from Linux, Windows or macOS: installing and launching apps, running XCTest and WebDriverAgent, taking screenshots and driving the UI.
- [MCP-B](https://awesomecua.com/resources/github-miguelspizza-webmcp/) — Frameworks · reviewed 2026-11-10: The earlier MCP-B codebase: a Chrome extension that discovers and calls tools websites expose as MCP servers, a Cloudflare Workers backend and a native server that relays those tools to desktop MCP clients.
- [PTFakeTouch](https://awesomecua.com/resources/github-ret70-ptfaketouch/) — Tools · reviewed 2026-11-10: An iOS framework that injects simulated touch events from inside an app, with calls for touch begin, move and end phases that produce taps at a point and swipes.
- [WebMCP](https://awesomecua.com/resources/github-jasonjmcghee-webmcp/) — Frameworks · reviewed 2026-11-10: An early WebMCP proposal and code: a script widget on a website registers its tools, resources and prompts, which MCP clients reach through a token-secured localhost WebSocket server.
- [AXe](https://awesomecua.com/resources/github-cameroncooke-axe/) — Tools · reviewed 2026-11-10: A command-line tool for iOS Simulator automation that reads the UI through accessibility APIs and sends HID taps, swipes and text input, with screenshot and video capture.
- [SnapEye](https://awesomecua.com/resources/github-zumerlab-snapeye/) — Tools · reviewed 2026-11-10: A SnapDOM-based toolkit that lets coding agents capture, diff and record elements of a running web app through a CLI, an in-page API or URL triggers, with JSON results and exit codes.
- [CUBE Standard](https://awesomecua.com/resources/github-the-ai-alliance-cube-standard/) — Frameworks · reviewed 2026-11-10: A Python protocol for wrapping agent benchmarks behind shared Tool, Task, Benchmark, Observation and Action types, with optional browser sessions, VM backends and browser and desktop computer tools.
